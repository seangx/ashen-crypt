# Astroloot 参考分析

来源：`/mnt/project-files/Astroloot.zip`（未改动原文件），即用户 Steam 里的 macOS 版 `Astroloot.app/Contents`。
分析方式：只做静态读取（配置文件、资源目录名、简体中文本地化 CSV），没有运行任何文件。
仅作设计参考，不使用其代码、美术或文本。

**BD（构筑）详细分析见 [astroloot-builds.md](astroloot-builds.md)**：模组系统、武器标签、词条分档数值、骰子掉率、独特装备规则、技能树结构、典型 BD。

## 技术构成
- Java + libGDX（LWJGL3/OpenGL），jpackage 打包自带 JRE，主类 `astroloot.app.Main`，JVM 固定 3GB 堆。
- `astroloot.jar` 约 43MB，游戏逻辑类名已混淆（`astroloot/a/g` 这类包），数值平衡写在代码里，读不出来。
- 集成 Steamworks（成就/联机）、Sentry（崩溃上报）、miniaudio 音频。
- `app/asset/`：约 1100 张 PNG（物品图标、粒子、UI、头像）、233 个 OGG、130 个 CSV（全是 11 种语言的本地化文本，有简繁中文）。
- 有联机：加入别人的任务、按对方进度/深渊深度判断能否加入。

## 核心形态
俯视角飞船割草刷宝（类似 Vampire Survivors 的移动 + 自动射击），外层是 PoE / Diablo 式的装备、词条和制造系统。主循环：在“弹珠机”上放入星区 → 进入任务刷怪 → 掉装备/骰子 → 回基地制造、升级技能树 → 开更难的星区。

## 装备结构
- 装备槽类别：武器、护盾、核心、引擎（冲刺时触发）、枢纽、模组（有等级，“所有模组等级 +X”词条）、芯片（插技能树芯片槽）。
- 稀有度：普通 → 罕见 → 稀有 → 独特，另有“追逐独特”（chase，顶级目标装备）和“扭曲”版（被 Boss 奥创扭曲的变异独特）。
- 底材品质（Intrinsic Quality）11 档：废料、锈蚀、强化、增强、卓越、重型、精英、圣物、长者、远古、永恒。这是独立于稀有度的第二维度。
- “轮回遗物”：往世周期打造的旧装备，消耗 1 个空白骰升级成现版本（说明有赛季/周期重置）。
- 仓库分页：骰子、装备、模组、独特、其他、星区。

## 词条与伤害体系（约 960 条属性文本）
- 5 种伤害类型：动能、爆炸、等离子、电能、核能（核能无视护盾）。爆炸/等离子/电能合称“热能”。
- 每种类型都有命中效果：动能→破片（AoE）、爆炸→余波（重复）+灼烧（叠加池衰减）、电能→感电（降抗叠层）、等离子→致盲、核能→辐射（DoT 叠加）。
- 修饰符分“提高/降低”（加法）和“总增/总降”（乘法），游戏里有词汇表专门解释。
- 有伤害转换（动能→核能等）、承伤转换、多重暴击（连续判定直到失败）、多重幸运（多次判定取最好）、死亡阈值（低于直接秒杀）。
- 三种主属性：质量（护甲+动能伤害-加速度）、能量（护盾+冲刺+热能伤害）、时间（周围时间流速）。
- 机制标签：投射物（穿透/连锁/分裂）、近战、AoE、DoT、召唤物（无人机/堡垒）、寄生体、病毒、力场、诡雷、反射。
- 增幅层数类 Buff：剧毒、涡轮、护盾、专注、锻造。

## 制造：骰子 = 通货（PoE 通货石的翻版）
| 骰子 | 作用 |
|---|---|
| 空白骰 | 非独特物品变回普通（清词条） |
| 等离子骰 | 普通 → 罕见（最多 2 词条） |
| 太阳骰 | 罕见 → 稀有 |
| 厄运骰 | 给罕见/稀有加词条 |
| 月亮骰 | 提升一个随机词条 |
| 虚空骰 | 抹去一个随机词条 |
| 槽位骰 | 重骰修饰符槽数量 |
| 星界骰 | 摧毁物品，萃取一条词条存起来；“星界词条”再贴到别的物品上 |
| 无限骰 | 重骰独特物品，可能时升阶 |
| 命运骰 | 重掷“预言”词条 |
- 制造时可先预览骰子结果，只有真正制造才消耗。
- “命运之轮”：一次多掷几次，自动保留最好结果（比如更高秒伤）。
- 制造手册：复制已装备的非独特武器。
- 奖励箱：入门/进阶/专家骰子包、模组箱、扭曲战利品箱。
- 商人卡洛：用骰子交易，店铺随机刷新，有“秘密交易”。

## 进度系统
- 角色技能树（约 500 条技能文本）：小节点 + 大型 keystone（巨像堡垒、时空神盾、闪避堡垒等），带芯片槽。有“战力报告”帮玩家找最适合流派的节点，以及秒伤预览（可模拟 Boss、当前怪物等级）。
- 弹珠机技能树（地图层的元进度，约 120 条）：投资在掉落和地图本身，而不是战斗。比如稀有度、经验、星区阶级、怪物等级、“XX之召唤”（偏向某类装备掉落）、扭曲物品几率、特殊 NPC 任务几率、独特怪物强度换经验、深渊相关加成。星区芯片插在这棵树上。
- 星区 = 可制造的地图物品（PoE 地图石），能有“预言”词条；打开后“命运已定”不可再改。
- 深渊：按深度无限往下推的终局。
- 任务树：剧情任务 + 多种玩法任务（找蛋、小行星带、竞技场、腐化之潮、寻宝、生存试炼、Boss 巢穴等）。
- Boss 祝福（Boon）：击败 4 个 Boss（月王、格鲁瓦克王、维斯玛拉、拉祖瑞斯）各得 3 种永久祝福。
- 灵魂动物（9 只宠物伙伴，有灵魂石）、外观装扮、Boss 疲惫机制（打太久 Boss 受伤增加，防卡关）。

## 对我们游戏可借鉴的点
1. **骰子式通货制造**：把“改稀有度 / 加词条 / 删词条 / 重骰数值”拆成独立的可掉落通货，每种都是一次小赌博，天然适合增量游戏的“攒资源 → 消耗 → 变强”循环。“命运之轮多掷取最优”可以做成可升级的增量项。
2. **稀有度 × 底材品质两条轴**：同一件装备可以既刷稀有度又刷品质档，延长装备追求寿命，比单一稀有度更耐刷。
3. **地图层元进度（弹珠机树）**：一棵树只加掉落、经验、怪物等级、特定装备掉率。这和增量游戏的“产出倍率树”完全对得上，可以作为点击/挂机产出的升级树。
4. **伤害类型 + 专属命中效果**：每种元素一种特殊效果，词条围绕“几率 / 伤害 / 范围 / 转换”展开，build 多样性来自少量规则的组合。
5. **加法 vs 乘法修饰符分开显示**：增量游戏数字膨胀快，明确区分“提高”和“总增”，玩家能理解为什么某个词条更值钱。
6. **秒伤预览 / 战力报告**：换装和点技能时直接显示 DPS 变化，增量游戏玩家很需要这种即时反馈。
7. **星界萃取（毁一件，取一条词条，贴到另一件）**：给废装备一个去处，也是很好的资源回收点。
8. **Boss 疲惫**：打越久伤害越高，防止卡死，适合自动战斗。
9. **轮回遗物**：转生/赛季后旧装备不作废，花一点通货升级到新周期，降低重置带来的挫败感。
