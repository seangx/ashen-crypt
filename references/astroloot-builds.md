# Astroloot 构筑（BD）体系详解

配套总览：[astroloot.md](astroloot.md)。
来源：`Astroloot.zip` 里的简中本地化表，加上对 `astroloot.jar` 的静态读取（`javap` 反汇编枚举表，`.alg` 二进制树布局）。没有运行游戏。代码混淆过，但枚举常量名和构造参数（数值）都还在，所以下面的数字基本是真实配置。
仅作设计参考，不复制其代码、美术和文本。

---

## 0. 一句话结论

Astroloot 的 BD 深度不是来自“装备数值更大”，而是 **五层可以互相改写的规则**：

1. **武器决定攻击形态**（投射物 / 近战 / 诡雷 / 激光 / 力场），用 **标签** 描述。
2. **模组（Mod）= 辅助宝石**，插进装备的模组槽，按标签判定能不能用，改写攻击行为（穿透、连锁、分裂、变召唤物、变寄生体……），并且会升级。
3. **伤害类型 + 命中效果**：5 种元素各有专属异常，还有转换和“X 也能触发 Y”的规则。
4. **技能树 1067 个节点**，几百个大型 keystone 带“代价换收益”的规则改写，芯片插技能树槽位。
5. **独特装备**大多是“一条规则改写 + 一个明显代价”，专门为某种玩法开门。

Bones and Coins 只有第 4 层的数值版本，这正是我们原型“没有 BD”的原因。

## 1. 装备槽和物品结构

**槽位**：左武器、右武器（两把，可以叠同类加成，有“只装一把时得到额外好处”的规则）、护盾（有“右侧护盾”的说法，可能两个）、核心、引擎（冲刺时触发的“技能”）、枢纽（放力场和病毒类模组）、芯片（插在技能树上）。

**每件物品 = 底材 + 品质 + 稀有度 + 词条 + 模组槽**

### 1.1 品质档（11 档，代码里的配置）
| 品质 | 序号 | 物品等级范围 | 掉落权重 |
|---|---|---|---|
| 废料 Scrap | 1 | 1–5 | 1000 |
| 锈蚀 Rusty | 2 | 4–10 | 950 |
| 强化 Augmented | 3 | 8–15 | 900 |
| 增强 Enhanced | 4 | 14–20 | 850 |
| 卓越 Exceptional | 5 | 18–25 | 800 |
| 重型 Heavy | 6 | 24–31 | 750 |
| 精英 Elite | 7 | 30–55 | 650 |
| 圣物 Relic | 8 | 36–60 | 600 |
| 长者 Elder | 9 | 54+ | 500 |
| 远古 Ancient | 10 | 68+ | 150 |
| 永恒 Eternal | 11 | 80+ | 50 |

品质同时决定 **底材基础伤害**（例：加农炮 废料 8–22，接近 80–240 的上限）和部分 **固有属性**（例：加农炮的穿透次数，废料/锈蚀 2 次 → 永恒 7 次）。模组槽数是每件物品单独随机的（见下一节）。

### 1.2 模组槽数的随机权重（槽位骰重骰的就是这个）
1 槽 1000，2 槽 800，3 槽 600，4 槽 300，5 槽 100，6 槽 25。
另外还有“模组升级槽” 1–8 个（权重 1000 → 200），模组插在升级槽里才吃经验升级。

### 1.3 稀有度
普通 → 罕见（最多 2 词条）→ 稀有 → 独特（固定）→ 追逐独特（chase，顶级目标）→ 扭曲（被奥创扭曲的独特，多一条“奥创词条”）。

### 引擎（冲刺即技能）
推进器（纯移动）、折跃（起点和终点各一个新星）、黑洞折跃、加力推进器（爆炸轨迹）、聚变引擎（目标点核爆）、EMP（周围落雷，电能 300–5000）、歼灭者（消耗所有增幅层数，释放大爆炸）。
冲刺有“冲刺槽 + 充能速度”，所以“冲刺流 / 引擎伤害流”是一个独立的 BD 方向。

## 3. 模组（Mod）：BD 的核心，相当于 PoE 辅助宝石

模组插进装备的模组槽。每个模组声明 **需要哪个标签**，满足才生效。模组有等级，效果随等级成长（例：穿透 = 1 + 等级/5 次穿透，伤害系数 ×1.2 → ×1.4）。

| 类别 | 模组 | 需要的标签 | 作用 |
|---|---|---|---|
| 投射物 | 穿透 / 连锁 / 分裂 / 回旋镖 / 急速投射物 | 可穿透 / 可连锁 / 可分裂 / 可返回 / 投射物 | 改弹道 |
| 攻击 | 额外攻击、攻速、射程、AoE | 攻击 / 攻速 / 射程 / AoE | |
| 元素 | 动能 / 热能 / 等离子 / 电能 / 核能 / 地狱火 / 蒸汽锤 | 武器 | 附加或转换元素伤害 |
| 命中效果 | 破片、余波、感电、致盲、辐射、击退、碾压 | 命中 | 加异常几率 |
| 生存 | 命中护甲、护甲汲取、命中冲刺 | 武器 + 命中 | |
| 增幅 | 剧毒 / 涡轮 / 护盾 / 专注 / 锻造 | 引擎 / 核心 / 武器 | 叠层 buff |
| 召唤 | 守护者 / 追猎无人机，泰坦 / 死神堡垒；暗影无人机；曙光堡垒 | 非引擎的武器；暗影无人机要引擎；曙光要核心 | **把武器或引擎变成召唤器** |
| 召唤强化 | 召唤物伤害 / 护甲 / 抗性 / 冲刺，死灵法师，格拉夫 | 召唤物 | |
| 寄生 | 寄生体，感染 | 寄生体：非引擎、非召唤物的武器；感染：带寄生体标签 | **武器不再由你发射，而是附着在敌人身上，让你的武器打它** |
| 病毒 | 崩解、爆发、增幅器、闪焰、核弹、克罗诺斯、腐蚀 | 无（放枢纽） | 每个敌人默认只能中 1 种病毒，削弱它 |
| 力场 | 神盾、钻石、日蚀、法拉第、防爆、三叶草（幸运）、时间 / 能量 / 质量、致命、韧性、充能 | 无（放枢纽） | 光环，同类不叠加，只取最高级 |
| 近战 | 近战、隐秘打击、碾压、跃传 | 武器 + 近战（跃传还要引擎） | 跃传：冲刺 = 传送到敌人身边并触发引擎 |
| 诡雷 | 磁力诡雷、诡雷护盾 | 诡雷 | |
| 规则 | 纯净 / 不洁、严苛、致死、死亡阈值、过载、超频 | 武器 | 例如纯净：只保留单一元素换大倍率 |

**为什么这层最关键**：同一把加农炮，插 穿透 + 连锁 + 分裂 是清屏流；插 寄生体 + 感染 就变成“把炮挂到敌人身上”的召唤流；插 守护者无人机 就变成召唤器。**换几个模组，玩法就变了**，而不只是数字变了。

## 4. 伤害公式和元素异常

### 4.1 三类修饰符
- **固定附加**（Flat）：武器上的“附加 X–Y 伤害”。
- **提高 / 降低**（Increased，加法）：同类相加。
- **总增 / 总降**（More，乘法）：彼此相乘，主要来自芯片、keystone、扭曲词条，所以最值钱。
游戏内词汇表专门解释了 1.5 × 1.2 = 1.8 的区别。

### 4.2 元素和专属异常
| 元素 | 异常 | 机制 |
|---|---|---|
| 动能 | 破片 | 命中后造成小范围 AoE，破片不能再触发破片 |
| 爆炸 | 余波 + 灼烧 | 余波按上一击的比例重复多次；灼烧累积成伤害池，每跳衰减 |
| 电能 | 感电 | 叠层降低全部抗性 |
| 等离子 | 致盲 | 敌人伤害和速度总降，随时间减弱 |
| 核能 | 辐射 | 按初始命中比例持续伤害，可叠加；核能伤害无视偏转护盾 |

热能 = 爆炸 + 等离子 + 电能，有一整套“热能”节点同时作用于三种。

### 4.3 规则改写类词条（BD 的分叉点）
- **转换**：动能 → 核能，承受电能 → 核能，爆炸 → 电能……
- **跨元素触发**：“核能伤害可以造成余波”“动能伤害可以造成感电”“持续伤害可以暴击”“持续伤害可以触发命中效果，普通命中不能触发”。
- **多重暴击**：暴击后继续判定，直到失败为止，伤害累加。
- **多重幸运**：概率判定多掷几次取最好；“幸运作用于暴击 / 伤害判定”。
- **死亡阈值**：护甲低于阈值直接秒杀。
- **代价型**：“你的战舰没有护甲”“你无法冲刺”“非暴击攻击无法造成伤害”“只有辐射能造成核能伤害”“你的战舰无法造成伤害（只靠召唤物）”。
- **属性重定向**（奥创之缠结）：质量改为提供热能伤害，时间改为提供动能伤害，能量改为提供核能伤害。

### 4.4 三主属性
- 质量：护甲、动能伤害，但加速度降低（越重越慢）。
- 能量：偏转护盾、冲刺充能、热能伤害。
- 时间：让周围一定范围内的时间流速变快（包括敌人和子弹）。
大量节点和独特装备写成“每点 X 提供 Y”，于是属性本身成了 BD 选择（重型撞击 vs 能量热能 vs 时间攻速）。

### 4.5 增幅层数（5 种）
剧毒（DoT 总增）、涡轮（行动速度）、护盾（承伤总降）、专注（暴击）、锻造（护甲回复）。来源是“暴击时 / 击杀时几率获得”；消耗端有“每消耗一层获得 X 元素伤害”和“歼灭者引擎消耗全部层数爆炸”。相当于一套资源循环 BD。

## 5. 词条池和分档（代码里的真实数值）

约 726 个词条族，1040 个具体词条，最多分 9 档（T1 最高）。

| 词条 | 档数 | T9（最低） | T1（最高） |
|---|---|---|---|
| 附加动能 / 爆炸 / 等离子 / 核能伤害 | 9 | 2–3 至 4–6 | 63–80 至 140–180 |
| 附加电能伤害 | 9 | 1 至 5–8 | 1 至 170–225（下限恒为 1） |
| 武器某元素基础伤害提高 % | 9 | 4–8 | 142–170 |
| 热能基础伤害提高 % | 9 | 2–4 | 71–85 |
| 基础攻速提高 % | 9 | 2–4 | 56–70 |
| 暴击率提高 % | 9 | 4–10 | 91–120 |
| 暴击伤害提高 % | 9 | 4–8 | 63–80 |
| 持续伤害提高 % | 9 | 2–4 | 56–70 |
| 召唤物伤害 / 攻速 | 9 | | 71–85 / 31–40 |
| 单元素抗性 | 5 | 5–10 | 41–50 |
| 最大抗性 | 2 | +1 | +2 |
| 护甲 / 偏转护盾（固定） | 5 | 4–10 | 81–120 |
| 闪避 | 5 | 1–4 | 17–20 |
| 质量 / 能量 / 时间 | 5 | 1–2 | 9–10 |
| 冲刺槽 | 2 | +1 | +2–3 |
| 所有模组等级 | 2 | +1 | +2 |
| 召唤物等级 | 3 | +1 | +3 |

规律：
- 武器词条是“基础 / 局部”（只作用于这把武器），防御词条在护盾和核心上。
- **芯片专属词条族**（ChipMoreXDamage、ChipDoubleDamage、Chip 力场 / 寄生 / 病毒模组等级）提供“总增”，是乘法收益的主要来源。
- **奥创（扭曲）词条**：额外一条强力词条（总增某元素、多重暴击、+最大抗性、病毒命中附带等），只在扭曲物品上出现。

## 8. 技能树

- **主技能树**（`st.alg`）：1067 个节点，六边形网格，坐标约 x −29～30、y −23～24，节点类型 571 种。前三种小节点（各约 40–50 个）是通用属性点，其余大多只出现一次。
- 节点三层：小节点（属性），中节点（复合属性，如“动能伤害与质量”“闪避与偏转护盾”），**大型节点约 370 个**（MajorSkill*）。
- 大型节点按主题聚成团：动能 / 质量重型（泰坦之拳、千兆震荡、超重型、推土机），核能 / 辐射（瘟疫、放射性沉降物、伽马衰减），电能感电（电鳗、雷霆震击），召唤物（召唤物指挥官、无人机集群、护卫堡垒、死灵之力），寄生 / 病毒（宿主支配、侵入感染、无尽瘟疫），闪避 / 时间（幻影、闪避堡垒、时空神盾），增幅层数（Venom/Shield/Focus BoostMax / Min / Apex / Anchor），诡雷（诡雷编织者、厄运诡雷），暴击（致命精准、终极专注），幸运（概率扭曲、头奖）……
- 很多节点带代价（“降低 X”“无法 Y”），形成“走这一支就放弃那一支”的选择。
- **芯片插槽**散在树上，配合奇点 / 混沌回路这种改写树结构的独特芯片。
- 游戏提供“战力报告”和秒伤预览（可以模拟 Boss、当前怪物等级），帮玩家判断节点价值。

**灵兽**（`wt.alg`，149 个节点）：9 只灵兽（雪伊、琳恩、巴尔的摩、沃拉克、巴鲁、波奇、胡利、艾维、领主鸡），选一只，各有约 70 个签名技能。很多是极端规则：独行者、和平主义、受虐狂、狂信者、时间领主、阴 / 阳、巨像、守护者等。相当于“职业 / 升华”层。

**Boss 祝福**：4 个 Boss 各掉 3 种永久祝福。

## 11. 给我们游戏的建议（把这套搬进增量 / 点击游戏）

1. **先做“标签 + 模组”这一层**，这是投入产出比最高的 BD 来源。武器只需要 4–6 种形态（单发 / 散射 / 持续光束 / 范围脉冲 / 召唤 / 陷阱），每种带一组标签；模组 15–25 个，按标签判定能否生效。自动战斗的增量游戏里，“这把武器插了什么模组”完全可以替代操作深度。
2. **模组会升级**：放进装备挂机吃经验，这本身就是一个增量进度条，而且每升 N 级解锁质变（例如每 5 级 +1 穿透）。
3. **元素 3–5 种，每种一个专属异常**，再加少量“跨元素触发 / 转换”的稀有词条作为 BD 枢纽。
4. **乘法修饰符稀缺且集中**（芯片 / keystone / 稀有词条），加法修饰符随处可见。这样数字膨胀可控，玩家也有明确的“追求件”。
5. **独特装备 = 一条规则 + 一个代价**，不要只是“更大的数字”。每件独特都应该为某个 BD 开门。
6. **keystone 带代价**（“没有护甲”“不能冲刺”“只有召唤物造成伤害”），让技能树出现真正的分叉。
7. **掉落偏向放在元进度树里**（某槽位 / 某类模组更容易掉），让玩家可以有目标地刷自己 BD 需要的东西，这比纯随机更适合增量游戏的长期目标。
8. **用骰子通货代替金币做制造**：等离子 / 太阳 / 厄运 / 虚空 / 星界的分工可以直接借鉴思路，数量做少一些（5–6 种）就够。
