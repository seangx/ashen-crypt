## 1. 结构一句话
**技能石定形态和本源元素，装备上数值最高的附加元素给攻击挂上它的特效。** 辅助符文可以换本源元素，天赋树给通用的元素组合玩法，独特改规则，也负责某一种元素的特效改造。三层合起来顶替技能树。

```
技能石（形态 + 本源元素 + 本源异常）
  + 装备“附加 X 伤害”（6 种元素各一族）
      └─ 数值最高的那种 = 主附加元素 → 挂它的“附加特效”
  + 辅助符文：元素转化（把本源元素整个换掉）
  + 天赋树：通用的元素玩法（纯色 / 杂糅 / 异变 / 余波），不给某一种元素
  + 独特：改规则（双特效、轮换、纯色共鸣……）
```

## 2. 元素表：6 种，每种一个身份

| 元素 | 异常（本源和特效共用） | 身份 | 和别的元素怎么分开 |
|---|---|---|---|
| 物理 | **碎骨**：命中后在周围溅射 | 清怪（范围） | 唯一的纯范围异常 |
| 火焰 | **灼烧**：伤害进伤害池，逐跳衰减 | 单体持续（打 Boss） | 池子大、单体；瘟疫是叠层、群体 |
| 闪电 | **感电**：叠层降低全部抗性 | 增伤（削抗） | 唯一让“别的伤害”也变高的 |
| 寒霜 | **冰缓 → 冻结** | 控制 | 让怪停下来 |
| 圣光 | **致盲**：敌人伤害降低 | 防御（削弱） | 寒霜让怪不动，圣光让怪打不痛 |
| 瘟疫 | **疫病**：叠层持续伤害，死亡时传染 | 群体持续 | 传染让它适合怪海 |

改动：
- **火焰只留灼烧。** 余震不再是火焰异常，改成不分元素的辅助符文“余震”（现有的余震符文去掉“火焰”限定，效果改为“命中有几率按比例重复命中”）。
- **瘟疫新增“死亡时传染”**：带疫病层死亡的敌人，把一半层数传给 60 像素内最近的 2 个敌人。
- **取消“元素”分组**（代码里的 thermal：火、圣、电、冰四种）。
  - “元素伤害提高”删除。
  - “元素抗性”改成“全抗”，对 6 种都生效。
  - “元素基础伤害提高”改成不分元素的“基础伤害提高”。
  - 理由：“元素”既像总称又只指 4 种，最容易误解；6 种元素已经各有身份，不需要分组。

## 3. 技能石的本源元素
每颗技能石固定一种本源元素。原来由武器底子决定的，按下表定死。

| 元素 | 技能石 |
|---|---|
| 物理 | 旋风斩、突刺、冲撞、骨矢、飞镰、散射 |
| 火焰 | 火油罐、喷火、陨火、陷阱·爆裂 |
| 闪电 | 雷符、游雷 |
| 寒霜 | 霜环、寒魄球 |
| 圣光 | 圣光束、新星、圣盾掷 |
| 瘟疫 | 疫星、瘟疫光环、陷阱·毒池 |

- 陷阱·射击归物理。
- 本源元素决定：
  - 基础伤害的类型。
  - 本源异常的基础几率（沿用现在武器底子的 `ail_*`）。
  - 技能特效的主色。
- 分布不均（闪电、寒霜各 2 颗）先不补技能石，用 §5 的转化符文弥补：任何技能都能转成任何元素。

## 4. 附加元素特效（核心改动）

### 4.1 规则
1. 装备上“附加 X–Y [元素] 伤害”照常加到技能的基础伤害上。
2. 6 种附加伤害分别求和（按平均值），**最高的那种 = 主附加元素**。
   - 平局时本源元素优先，其次按表 2 的顺序。
3. 主附加元素给每次命中挂上**附加特效**，强度按“该元素的附加伤害平均值”算。所以附加伤害越高，特效越强，不是开关。
4. **共鸣**：主附加元素和本源元素相同时，附加特效 ×1.5。
   - 单元素纯色构筑有奖励。
   - 混色构筑同时有本源异常和另一种特效，各有取舍。
5. 面板和装备悬浮说明里显示“附加特效：火焰 · 点燃（共鸣）”。换装备时如果主附加元素会变，对比里写出来。

### 4.2 六种附加特效（第一版数值，A = 该元素附加伤害的平均值）

| 主附加元素 | 附加特效 | 数值 |
|---|---|---|
| 物理 | 碎骨溅射：命中点周围 40 像素造成 A × 0.6 物理伤害 | 每次命中 |
| 火焰 | 点燃：灼烧池 + A × 0.5 | 每次命中 |
| 闪电 | 雷爆：命中 0.5 秒后在目标处爆炸，50 像素内造成 A × 0.8 闪电伤害 | 同一目标每 0.5 秒最多一次 |
| 寒霜 | 霜咬：叠 1 层冰缓；冻结中的敌人额外受到 A × 1.5 寒霜伤害 | 每次命中 |
| 圣光 | 圣印：致盲 2 秒；命中致盲敌人回复 A × 0.1 护盾 | 回盾计入续航上限 |
| 瘟疫 | 疫种：叠 1 层疫病，每层每秒 A × 0.15，持续 4 秒 | 每次命中 |

- 持续施放类（旋风斩、喷火、光束）按结算跳数计算，每跳的系数 ×0.3。
- 特效伤害吃 ③ 伤害提高和 ⑥ 总增，**不吃暴击**。这样特效是稳定的底，暴击仍然是主手和副手的追求。
- 美术：特效是 6 套全技能共用的小效果（溅射骨片、火苗、电球、霜纹、光印、毒雾），不用每个技能画 6 遍。

## 5. 辅助符文：元素转化
- 新增 6 颗转化符文：骨化、焚化、雷化、霜化、圣化、疫化。插上后，技能的本源元素整个换成该元素：伤害、本源异常、特效主色都换。
  - 例：旋风斩 + 焚化 = 火焰旋风，本源异常变成灼烧，配一身附加火就能共鸣。
- 现有的圣辉、雷纹、骨锻、骨钢（平加 + 额外获得）合并进对应的转化符文，平加部分删掉（平加交给装备）。
- 感电符文、余震符文保留，去掉元素限定的地方按 §2 改。
- 纯净符文（只保留本源元素、总增 ×1.5–2.0）保留。和“共鸣”搭配是纯色路线的核心。

## 6. 天赋树：只给通用的元素玩法，不给某一种元素
用户 03:25：“天赋环不该给这么限定的东西”。和 10-23 定的原则一致：天赋树不按技能、元素划分。

- **元素环取消“按元素分 6 段”**，改成一圈通用的“元素玩法”节点。小节点：
  - 附加伤害提高 %（对所有附加元素）
  - 附加特效效果提高 %
  - 本源异常几率 / 效果提高 %
- **大天赋：通用的，改的是“元素怎么组合”**，对任何元素都成立：

| 大天赋 | 效果 | 代价 |
|---|---|---|
| 纯色 | 共鸣倍率 ×1.5 → ×2.2 | 和本源元素不同的附加伤害只算一半 |
| 杂糅 | 附加伤害第二高的元素也挂特效（×0.6） | 不再有共鸣 |
| 异变 | 附加特效对目标同时触发本源异常（几率 = 本源异常几率） | 直接命中伤害 −20% |
| 余波 | 附加特效有 25% 几率再触发一次 | 附加伤害 −25% |

- 原先写的“某元素专属”改造（焚地、连爆、冰棺、瘟潮、骨裂、圣罚）不放天赋树，移到 §7 的独特装备。

## 7. 独特（第一批，改规则）

| 独特 | 部位 | 规则 |
|---|---|---|
| 双生冠 | 头冠 | 附加伤害前两高的元素都挂特效（第二种 ×0.6） |
| 棱镜法阵 | 法阵 | 每次命中按顺序轮换 6 种附加特效，强度按附加伤害总和 ×0.4 |
| 纯色之心 | 副手 | 共鸣倍率从 ×1.5 提到 ×2.5；非本源元素的附加伤害无效 |
| 余烬之握 | 主手 | 火焰附加特效对所有元素生效（任何主附加元素都同时点燃） |

**元素专属的特效改造放在独特上**（原先写在天赋元素环，用户 03:25 否决）。每件在主附加元素是该元素时生效：

| 独特 | 部位 | 规则 |
|---|---|---|
| 碎颅之锤 | 主手 | 骨裂：碎骨溅射命中的敌人有 30% 几率再溅射一次（×0.5） |
| 焚野法阵 | 法阵 | 焚地：点燃的敌人死亡时留下火圈，持续 3 秒 |
| 雷链冠 | 头冠 | 连爆：雷爆会传给最近的 2 个敌人（×0.6） |
| 冰棺之心 | 副手 | 冰棺：冻结时间 +50%；冻结的敌人死亡时迸出 4 片冰片 |
| 审判之盾 | 盾牌 | 圣罚：致盲的敌人受到的伤害 +20% |
| 瘟潮靴 | 遁靴 | 瘟潮：传染不减半，范围 +50% |

- 名字可能和现有独特重名，实现时查一下 uniques.json 再定。

## 8. 词条变化（相对 chase-clarity.md）

| 现在 | 改成 |
|---|---|
| 附加 X 伤害（6 族，主手局部） | **保留，带元素**。主手、副手前缀；法阵小档。不再是主手局部词条，而是加到技能上 |
| X 基础伤害提高（6 族）+ 元素基础伤害提高 | 基础伤害提高（不分元素，主手局部） |
| X 穿抗（6 族） | 穿抗（对你的所有元素） |
| X 异常效果（7 族） | 异常效果提高（不分元素）+ 附加特效效果提高（新） |
| X 抗性（6 族）、元素抗性 | 单抗（一族，掷出时随机元素）+ 全抗 |
| X 抗性上限（6 族） | 全抗上限 |
| 元素伤害提高 | 删除 |

带元素的词条族从 26 族降到 7 族：附加伤害 6 族 + 单抗 1 族。

## 9. 待定
1. 主附加元素按“附加伤害平均值”比，还是按“附加伤害占总伤害的比例”比？建议前者，好算也好理解。
2. 共鸣 ×1.5 是否足够让纯色和混色各有市场。要等模拟。
3. 转化符文要不要占孔？建议占。这样转元素有代价，少一个辅助。
4. 元素专属独特只认主附加元素，还是也认本源元素？建议只认主附加元素，让装备决定方向。

## 10. 验收（实现后）
- 六个现有流派在不换装备的情况下，迁移后 DPS 变化 ±10%（现有平加词条直接变成附加伤害）。
- 同一个技能，主附加元素分别是 6 种时，`tools/bis.js` 物品等级 70 的 DPS 相差 ±20% 以内：各元素强在不同地方，不能有一个碾压。
- 打 Boss（单体）时火焰、闪电领先；怪海时物理、瘟疫领先；生存指标寒霜、圣光领先。
