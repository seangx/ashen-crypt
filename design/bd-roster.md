## 3. 陨火（陨石术）

- **形态**：选怪最密的地方（按怪的移动预判落点），地上先亮落点圈，**延迟 1.0 秒**后陨石砸下，大范围一次命中，留下 3 秒火地（持续伤害）。
- **跃迁**
  - 符文“陨火”：武器的攻击变成陨石（延迟、大范围、慢攻速）。
  - 大天赋“星坠雨”：每次施放改成 3 颗小陨石散落，每颗 ×0.45 伤害，范围 ×0.6。延迟变短（0.6 秒）。
  - 独特“末日冠”：延迟越长伤害越高（每多 0.1 秒 +12% 总增），延迟 +1 秒；陨石变大一圈。玩法变成“一锤定音”。
- **特殊增伤**：延迟换伤害（延迟类的总增）；火地叠加（同一块地方的火地伤害叠层）。
- **特殊防御**：落点震退 + 眩晕 0.5 秒；火地里的怪伤害降低。前提是砸中，砸偏了就没有。
- **魂火**：每次施放花得多（大额消耗），一次砸死 3 只以上返还一部分。
- **AI**：远程，保持距离；挑最密的群；被包围时往外撤再砸。
- **标签**：范围、延迟、持续（火地）、火焰。

## 4. 圣盾掷（飞盾圣骑）

- **形态**：把盾扔向最近的怪，命中后转向附近另一只没打过的怪，**敌人之间弹射** N 次，最后飞回手上。
- **跃迁**
  - 符文“圣盾掷”：装在盾上，盾变成一把投射武器。基础伤害 = 盾的护甲 × 系数（防御就是输出）。
  - 大天赋“回响圣盾”：每弹一次，在命中点炸一个小圣光爆（范围，×0.4）。
  - 独特“殉道者之盾”：弹射次数翻倍；每次命中给自己回护盾；代价：盾在飞的时候自己不吃盾的护甲。
- **特殊增伤**：每弹一次伤害 +%（弹射递增）；盾的护甲越高伤害越高。
- **特殊防御**：命中回护盾；盾在手上时格挡（护甲额外减伤）。“扔出去”和“拿在手上”之间要取舍。
- **魂火**：每次投掷一笔，每次弹射返还一点（弹得越多越省）。
- **和穿透的规则**：弹射和穿透互斥（spec-pierce-chain.md），这个流派不走穿透。
- **AI**：中距离，站在怪群边上，让盾有得弹。
- **标签**：投射物、弹射、盾（伤害按盾的属性算）、圣光。

## 5. 寒魄球（冰封球）

- **形态**：慢速冰球直线飞出，飞行途中每 0.15 秒向四周**派生冰片**（次级投射物，小伤害），到头炸开成一圈冰环。
- **跃迁**
  - 符文“寒魄球”：攻击变成冰球。
  - 大天赋“碎冰连锁”：冰片命中后再派生 2 片（只派生一层，不无限）。
  - 独特“冬之心”：冰球不再飞出，绕着自己转（像护身法球），持续喷冰片。玩法从“远程放球”变成“贴身绞肉”。
- **特殊增伤**：派生物继承“投射物 +N”（每 +1 多喷一个方向）；冻结的怪受到的伤害提高。
- **特殊防御**：冰缓（被冰片打中的怪移速、攻速降低），冻结的怪不能攻击。
- **魂火**：每次施放；冰片命中冻结的怪时返还。
- **AI**：远程，把球往怪群里送；冬之心时改成近战打法。
- **标签**：投射物、派生、范围（终点冰环）、寒霜。

## 6. 霜环（冰霜新星）

- **形态**：以自己为中心放一圈冰环，命中叠冰缓，叠满冻结。
- **跃迁**
  - 符文“霜环”：攻击变成新星（可以用现有的圣钟形态改元素）。
  - 大天赋“碎冰”：杀死冻结的怪时，尸体碎成冰片向四周飞（派生投射物）。怪海里会一圈一圈连锁。
  - 独特“永冬”：不用施放，身边每 0.5 秒自动脉冲一次，留下冰地；代价：移速降低。
- **特殊增伤**：冻碎（击杀冻结的怪时爆炸）；冻结的怪受到的伤害提高。
- **特殊防御**：冻结的怪不能攻击；新星击退。打法是冲进怪堆，冻住就安全。
- **魂火**：每次新星一笔，每冻结一只返还。
- **AI**：近战，冲进最密的群放环。
- **标签**：范围、新星（以自身为中心）、寒霜；有“碎冰”时多了派生。

## 提炼出的标签

**交付方式**（技能怎么打到怪，一个技能一到两个）

| 标签 | 含义 | 流派 |
|---|---|---|
| 近战 | 贴身命中 | 旋风斩 |
| 投射物 | 飞出去的东西（受投射物 +N、弹速影响） | 游雷、圣盾掷、寒魄球、小旋风、冰片 |
| 范围 | 一次打一片（受范围提高影响） | 旋风斩、陨火、霜环、寒魄球终点 |
| 新星 | 范围的一种：以自身为中心 | 霜环 |
| 延迟 | 先预警，后命中；延迟越长越痛 | 陨火 |
| 持续施放 | 开着就一直生效、叠层 | 旋风斩 |

**投射物行为**（只对投射物生效）

| 标签 | 含义 | 流派 |
|---|---|---|
| 穿透 | 无限穿过敌人（和弹射互斥） | 冰片可选 |
| 弹射 | 敌人之间转向 | 圣盾掷 |
| 反弹 | 撞墙反射 | 游雷 |
| 派生 | 投射物生出次级投射物 | 寒魄球、碎冰、旋风之心的小旋风 |

**伤害方式**

| 标签 | 含义 | 流派 |
|---|---|---|
| 持续 | 地面效果、点燃、毒（受持续时间影响） | 陨火火地、永冬冰地 |
| 盾 | 伤害按盾的属性算 | 圣盾掷 |

**元素**：物理、火焰、闪电、圣光、瘟疫，**新增寒霜**（见下方待定）。异常：寒霜 → 冰缓，叠满冻结。

## 标签之间怎么串（跨流派的通用件）

- “投射物 +N”同时喂游雷（颗数）、圣盾掷（同时扔几面盾）、寒魄球（冰片方向）、小旋风。
- “派生”是新的乘法层：每个派生物都吃投射物加成，所以派生 × 投射物 +N 是一条链。
- “范围提高”喂旋风斩半径、陨火、霜环、寒魄球终点冰环、回响圣盾的小爆。
- “冻结的怪受到的伤害提高”是寒霜两系共用的总增；碎冰的冰片又是投射物，所以霜环可以借投射物的装备。
- “延迟”目前只有陨火，后面延迟引爆类（爆炸箭）可以共用。

## 待定

1. **寒霜元素**：游戏现在只有物理 / 火焰 / 圣光 / 闪电 / 瘟疫五种元素。冰系两个流派需要寒霜。建议新增第六种元素“寒霜”，异常为冰缓 / 冻结（偏防御的异常，和其它五种都不重）。代价：加抗性、元素伤害词条、天赋元素环多一格。
2. 圣盾掷要不要占武器槽：建议符文装在盾上，盾同时算防具和武器，左右手照常放两把武器。
3. 陨火、寒魄球、霜环用新底子还是现有底子加符文改形态（像旋风斩的回旋骨刃）。建议新底子各一把，符文管形态跃迁。
4. 数值和模拟目标沿用 BD 体系稿：各流派毕业天梯差 ≤10%，成型和乱配差距前期 ≥3 倍。
