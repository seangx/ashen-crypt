# 推层模拟（设计线程用）

- `sim.js <none|tree|gear> <模拟分钟> [html]`：无头推层机器人。none = 不换装不点天赋；tree = 只点天赋（贪心）；gear = 天赋 + 自动换更好的装备。输出每局：模拟分钟、层、胜负、用时、等级、秒伤、护甲、灵障。
- `curve.js`：按物品等级随机掉落 400 件，统计单把武器秒伤和防具数值的中位数、P90、30 件里最好的一件。
- `mk.py <怪物生命成长> <怪物伤害成长> <输出名>`：从 game.html 生成改了数值的副本（也带上独特装备词条档位修正），给 sim.js 用。
- 运行需要 Playwright；Phaser 要换成本地文件（CDN 在这个环境里访问不了）。
