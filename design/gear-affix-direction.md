## 现状问题（按 data 盘点）
1. **防具只能刷防御。** 盾 / 头冠 / 遁靴 / 法阵能出的词条，大约一半是抗性和抗性上限，其余主要是平加护甲、护盾、生命、闪避。同部位不同底子只差一条自带属性（护甲 / 闪避 / 护盾）。标签加成很少，只有 IncreasedArea、IncreasedDuration、SparkAdd、SparkChain、SpinCap。
2. **武器有效前缀只有两条。** 6 种元素各有平加和百分比，但一把武器只吃自己的元素，最优解是固定的。
3. **没有取舍。** 暴击、更多伤害等乘区只在印记（chip / chipE）上；装备词条全是“加数值”，提示又直接显示秒伤差，选装备等于比一个数。
4. **空词条。** FlatMass、FlatTime、IncreasedMinion*/MinionMod（还没有召唤流派）、DashDamage/DashRecharge/DashSlot 的价值存疑。

## 改版方向
1. **部位分工。** 头冠 = 标签核心（投射物 +N、弹射、暴击）；遁靴 = 移速、冲刺、灯火；法阵 = 元素、抗性；盾 = 防御。
2. **防具加标签词条。** 近战 / 范围 / 持续 / 投射物 / 弹射伤害提高等，让每件防具都能为某个流派刷（文字只写标签，见 spec-tags.md）。
3. **条件 / 代价词条。** 参考 Astroloot 改规则的稀有词条，例如“满护盾时伤害提高”“暴击率 +，护甲 −”，让选择有取舍。
4. **清理空词条。** 换成上面的新词条，老存档的 id 做映射。
