# 竖屏移动端 UI/UX（草案）

这套稿用 Open Design 生成：项目 `ashen-crypt-mobile-ui`，agent 用 cursor-agent，模型 grok-4.7-high（套餐内 Grok 4.x）。
- 原型位置：`design/mobile/*.html`，画布 390×844。
- 截图：`/workspace/mobile-{hud,gear,tree,forge,runes,ladder,settings,index}.png`。

## 原则
- 视觉：像素边框、暗紫/余烬配色（底色 #2a2433，金边 #c8913a，余烬 #ff9a3c）。文字用系统无衬线字体（PingFang / Noto Sans SC），不用像素字体。
- 可点目标 ≥44px。非战斗屏底部固定 7 格导航：装备 / 天赋 / 铁砧 / **【战斗】** / 符文 / 天梯 / 设置。正中是战斗主线：一个加大、凸起的金色主按钮（宽 76px，上浮 14px），点它回到局内 HUD。
- 详情一律用底部抽屉，代替 hover tooltip：长按物品或点节点就弹出。

## 各屏
- **HUD**（移动默认用浮动虚拟摇杆）：
  - 顶部：层数和 Boss 进度。中间：战斗区。
  - 左下：浮动摇杆。在左下热区任意处按下，摇杆中心就出现在拇指下；对应桌面版"指针移动接管角色"，松手几秒后回到自动。
  - 右下：沿用桌面版底栏：自动/手动、推层/锁层、开始/继续/暂停，加一个菜单入口。
  - 游戏**没有主动技能**，攻击全自动，所以不放技能键，也不放药水键（游戏里没有药水）。
  - 血球在左下，灯火球在右下，通用防御标签"贴/远 −x%"紧挨着血球。
  - "热区"按钮可以显示/隐藏拇指热区标注。左右手模式在设置里切换。设置里另有"移动方式"开关，可改成全自动。
- **装备**：上面纸娃娃，下面格子背包。长按物品弹出底部抽屉，内容有词条 T 级、符文槽，以及"装备/对比"按钮。
- **天赋树**：
  - 星空图，单指拖动、双指缩放，带回中按钮。
  - 顶部：天赋点、搜索、标签筛选（横向滚动）。
  - 点节点弹出底部抽屉，显示详情和点亮/退回按钮。
- **铁砧**：选物品（横排卡片）→ 选词条 → 操作网格（升一档/洗数值/移除/拆解）。"立誓 ×6"是全宽主按钮，点了先弹确认。
- **符文**：物品的符文槽配符文列表，点选镶嵌（拖放作为增强）。
- **阶梯/地图**：层数卡片列表，带词缀标签，底部固定"开始"按钮。
- **设置**：音量、画质、震屏、伤害数字、自动拾取、左右手模式、语言。

## 待定
- 竖屏下战斗区只占约 50% 高度，需要调整镜头和游戏逻辑分辨率（比如 270×480）；这牵涉 Phaser 缩放策略。
- 已定：手机端默认用浮动虚拟摇杆。
- 已定：手机端没有冲刺键，冲刺由自动战斗处理。
- 天赋树的手势要和 Phaser 输入层打通。

## 已核对的游戏输入（src/85_ui.js、src/80_world.js）
- 移动：指针或触摸在场地上移动时接管角色，几秒不动就回到自动。触摸按下会立即接管。
- 冲刺：空格、Shift 或右键。自动战斗也会自己冲刺。已定：手机端不加冲刺键，冲刺完全交给自动战斗。
- 回车：开始/暂停自动循环。Esc：关窗。1–7：打开 7 个菜单。
- 底栏按钮：自动/手动、推层/锁层、开始/继续/暂停、音效，还有层数 < >。
- 没有：主动技能、药水、灯火按键（灯火只是资源球）。
