# 灰烬地窖 · 出手站定（非引导技能攻击时不能移动）

2026-10-26 · 设计线程 · 状态：**搁置**（用户 03:35：“感觉是细枝末节，后面再看吧”）
基于 main 105540b。用户 03:28：“非引导式技能攻击时不应该能移动”。

## 1. 现状
- 出手是纯冷却：`src/50_combat.js:670`，`player.wcd[i]` 归零就 `fire()`，和移动完全无关。所以远程流派可以一边风筝一边满攻速输出。
- 移动在 `50_combat.js:569–572`（目标速度 → 加速度 → 位移）。
- 已有“站着不动”的判定 `isStill()`（:90，移速 < `rules.still.speed`），供“磐石”“游击”类规则使用（`rules.json` still / kite）。

## 2. 规则

### 2.1 哪些技能算引导
| 类型 | 技能石 | 出手时 |
|---|---|---|
| 引导 | 旋风斩（orbit）、喷火（cone）、圣光束（beam） | 照常移动。旋风斩保持现在的移速系数，喷火、光束移速 ×0.5 |
| 常驻 | 瘟疫光环（aura） | 照常移动（没有出手动作） |
| 非引导 | 其余全部：突刺、冲撞、骨矢、雷符、游雷、飞镰、火油罐、散射、疫星、新星、霜环、陨火、寒魄球、陷阱、圣盾掷 | **站定** |

- 在 gems.json 每颗技能石上加字段 `cast: "channel" | "aura" | "root"`，代码不按形态猜。
- 冲撞（ram）是“撞上去”，出手本身就是位移：算非引导，但它的位移由技能自己控制，玩家输入和 AI 移动在动作期间无效。

### 2.2 出手动作
- 每次出手有一个动作，时长 `T = clamp(0.8 / 攻速, 0.12, 0.6)` 秒。
- 动作分两段：
  - **前摇**：占 T 的 40%。
  - **释放**：在前摇结束时，即现在 `fire()` 的时刻。
  - **后摇**：占剩下的 60%。
- **整个动作期间速度归零**：`player.vx = vy = 0`，忽略移动目标。角色仍可转向，朝向目标。
- 攻速越快，站定时间越短。所以攻速同时也是机动性，这是有意的。
- 参数放 `mechanics.cast: { tMul: 0.8, tMin: 0.12, tMax: 0.6, windup: 0.4 }`。

### 2.3 取消
| 情况 | 结果 |
|---|---|
| 冲刺（dash） | 任何时刻都能取消。前摇中取消则这一下不放，冷却只记 0.1 秒 |
| 手动移动输入（鼠标、摇杆） | 前摇中：取消，不放。后摇中：取消后摇，立即可以走（动画取消） |
| 自动战斗的躲避（重击预警） | 等同冲刺或移动，同样可以取消 |
| 被冻结、击退 | 打断，这一下不放 |

- 有移动输入时不开始新的出手。手动模式下“想走就能走”，按住不动才会打。
- 冷却仍然从释放时刻开始算。前摇被取消时，冷却不重置成满值。

### 2.4 自动战斗
现在 AI 是“一直移动 + 冷却好就打”，要改成“站定输出 / 换位”两个状态：
- **站定输出**：目标在射程内、身边没有危险（没有重击预警圈、近身敌人数没超过阈值）时，停下来连续出手。
- **换位**：
  - 出现重击预警、被包围（远程流派 `danger.closeN`）、或者射程内没目标时，移动。
  - 移动时不出手。
  - 到位后回到站定。
- 远程流派的风筝变成“打几下，退一步，再打”，而不是边退边打。
- 近战非引导（突刺、冲撞）：贴上去，站定出手。
- 参数放 `auto.json`：`root.closeN`（远程被几个敌人贴身就换位，默认 2）、`root.minHold`（每次站定至少打 1 下）。

### 2.5 显示
- 出手时角色有一个 2–3 帧的出手姿势（举弩、挥手、举杖），前摇结束时放出。没有新美术时，先用现有立绘做一个前倾位移 + 闪白。
- 手动模式下，前摇期间脚下出现一个淡色小圈，提示“正在出手，移动会取消”。

## 3. 连带影响
1. **远程流派更难**：不能边退边打，生存要靠远离减伤、控场、站位。正好和通用防御里“远离”的设计对上。
2. **攻速的价值上升**（更短的站定）；移速对远程的价值下降。
3. **“磐石”类规则**（站着不动时减伤、增伤，`rules.still`）会更容易触发，强度可能要降。“游击”（移动时增伤，`rules.kite`）对非引导流派变弱，可能要改成“出手后 1 秒内移动增伤”。
4. **新的天赋 / 独特机会**：通用大天赋“疾行施法”：非引导技能出手时可以以 40% 速度移动；代价：伤害 −15%。这个不限定技能，符合天赋树的原则。
5. **模拟**：`tools/sim.js` 和 `bis.js` 用同一套自动战斗，改完后要重跑六个流派。预计远程流派推层下降。

## 4. 验收
1. 手动：非引导技能站着不动时正常出手；按住移动时不出手；前摇中按移动，这一下不放；后摇中按移动，立刻能走。
2. 自动：远程流派在怪海里表现为“站定打几下 → 换位 → 再打”，被重击预警时能取消出手躲开。
3. 旋风斩、喷火、光束、瘟疫光环的移动不受影响（喷火、光束 ×0.5 除外）。
4. `node tools/sim.js --seeds 1..3` 六个流派跑通，记录推层和阵亡次数的变化，交给设计线程调参。

## 5. 待定
1. 动作时长系数 0.8：越大越“重”，越小越接近现在。建议先 0.8，手感不对再调。
2. 喷火、光束边走边放要不要也限制（现在写 ×0.5）。
3. “疾行施法”放天赋还是独特。建议天赋，因为它是通用的。
