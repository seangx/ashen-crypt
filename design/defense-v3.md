# 灰烬地窖 · 防御 v3（参考暗黑 3）

2026-10-27 · 设计线程 · 状态：**方案稿，未开工**
基于 main 1104e7c。词条的部位和档位以 gear-v2.md 为准。不兼容老存档。用户 06:51：“参考暗黑 3 来做防御体系”。暗黑 3 的部分凭记忆整理，细节以游戏为准。

## 1. 暗黑 3 的防御是怎么做的
1. **几层减伤，全部相乘**：
   - 护甲减所有伤害。
   - 抗性减对应元素的伤害（全抗加到每一种上）。
   - 再加各种“X 伤害降低”：近战、远程、精英、职业被动。
2. **护甲和抗性都按怪物等级算，越堆收益越低，但没有硬上限**：
   - 护甲减伤 = 护甲 ÷ (护甲 + 50 × 怪物等级)
   - 抗性减伤 = 抗性 ÷ (抗性 + 5 × 怪物等级)
   - 所以“全抗 1000”在任何难度都有意义，也永远到不了 100%。
3. **生命 + 回复**：
   - 生命来自体能和生命百分比。
   - 回复有每秒回复、命中回复、击杀回复、**生命球**（怪掉的红球，碰到就回血）。
4. **面板上两个数**：坚韧（等效生命，所有减伤折算进来）和恢复（每秒等效回复）。玩家一眼知道自己硬不硬、续不续得上。
5. **闪避在资料片里被拿掉了**：随机性太大，挂机看不出效果。
6. 格挡只在盾上：几率 + 挡掉的固定数值。

## 2. 我们现在的问题
（数值见 data/mechanics.json `defense`，40_stats.js:58、:286）
- **抗性是流放式的百分比 + 上限**（maxRes，硬顶）。堆满上限之后就没用了，所以抗性词条要么“缺了必须补”，要么“满了全是废词条”。刚拆成 6 单抗 + 全抗之后，这个问题更明显。
- **护甲按“这一下的伤害”算**（护甲 ÷ (护甲 + 5 × 这一下伤害)，最多 85%）。对小怪很强、对重击很弱，玩家看面板算不出自己有多硬。
- **生命几乎不回**：只靠吸血（有上限）和打 Boss 回 15%。生命掉了就是掉了，挂机时只能靠撤回。
- **闪避**：随机，挂机看不出效果，和暗黑 3 拿掉它的理由一样。
- 面板上没有“我有多硬”的总数。

## 3. 新防御结构

### 3.1 结算顺序（全部相乘）
```
受到伤害 = 原始伤害
         × (1 − 格挡)              只有盾，挡住时减固定值
         × (1 − 护甲减伤)           所有伤害
         × (1 − 抗性减伤[元素])      该元素的单抗 + 全抗
         × (1 − 条件减伤)           近战 / 远程 / 精英 / 通用防御四种，各自相乘
         → 先扣护盾，再扣生命
```

### 3.2 护甲和抗性改成按层数算（暗黑 3 公式）
- 护甲减伤 = 护甲 ÷ (护甲 + **armorK × 怪物等级**)，`armorK` 第一版 50。
- 抗性减伤 = 抗性 ÷ (抗性 + **resK × 怪物等级**)，`resK` 第一版 5。
- 怪物等级 = 推层层数（天梯按天梯层数换算）。
- 两个都**没有硬上限**，只有递减。
- 抗性上限词条（maxRes）**删除**。06:49 定的“盾牌和法阵出抗性上限”这条撤回，用新公式代替。
- 全抗：加到 6 种单抗上，数值约为单抗的 40%（06:49 定的不变）。
- 效果：
  - 抗性永远有用，只是越堆收益越低。
  - 抗性词条从“补到上限”变成“哪个元素的怪多就堆哪个”。
  - 层数越深需要的护甲和抗性越多，这本身就是推层的难度曲线。

### 3.3 条件减伤（暗黑 3 的“X 伤害降低”）
| 词条 | 部位 | 档位 T1 → 顶 | 说明 |
|---|---|---|---|
| 近战伤害降低 | 盾牌、法阵 | 3% → 12% | 近战怪、Boss 近身攻击 |
| 远程伤害降低 | 盾牌、法阵 | 3% → 12% | 弓手、法师、投射物 |
| 精英伤害降低 | 头冠、盾牌 | 4% → 15% | 精英和 Boss |
| 通用防御四种（控场、贴身、远离、续航） | 保留 | — | 已经是条件减伤，原样保留 |

- 每种各自相乘，单种上限 50%。

### 3.4 生命和回复
| 来源 | 在哪 | 说明 |
|---|---|---|
| 生命、生命提高 | 所有防具类、填充词条 | 已有 |
| **每秒回复生命**（新） | 头冠、遁靴、法阵；血石（防具） | 推层里也生效，取代“生命几乎不回” |
| 命中回复（已有“命中回复生命”） | 武器类 | 保留每秒上限 |
| **击杀回复生命**（新） | 主手、遁靴；血石（武器） | |
| **生命球**（新） | 精英 100% 掉、普通怪 2% 掉 | 碰到回 20% 生命；自动战斗顺路拾取（60 像素内） |
| 打 Boss 回生命 | 已有 15% | 保留 |

- 吸血保留，但只作为“命中回复”的一种，不再是唯一的回血手段。

### 3.5 闪避 → 删除
- 闪避词条、影石（闪避）、天赋闪避节点删除。
- 换成：
  - 影石 → “远程伤害降低”。
  - 天赋闪避节点 → “移速 + 远离减伤”。
- 闪避相关的独特和规则（闪避尖刺、闪避上限）改成格挡版本。

### 3.6 格挡（只在盾）
- 格挡几率 5–20%（盾底子 + 词条）+ 格挡值：挡住时减去一个固定数值（随物品等级成长）。
- 和现在盾上的“格挡”词条合并。

### 3.7 护盾（保留，作为我们自己的一层）
- 每秒回复 8%（不变），先于生命扣。
- 魂力、法阵、续航相关的都不变。
- 和暗黑 3 的区别：暗黑 3 的护盾来自技能，我们的护盾是常驻的一层。这是本作的特色，保留。

## 4. 面板：坚韧和恢复
- **坚韧** = (生命 + 护盾) ÷ [(1 − 护甲减伤) × (1 − 平均抗性减伤) × (1 − 平均条件减伤)]。
  - 平均抗性按“当前层的怪物元素分布”加权。
  - 平均条件减伤按近战、远程怪的比例加权。
- **恢复** = 每秒回复 + 护盾每秒回复 + 预计命中回复 + 预计击杀回复。
- 角色面板上放在“秒伤”旁边：秒伤、坚韧、恢复三个大数。悬停展开每一层减伤。
- 装备对比显示三项的变化：“秒伤 +3% / 坚韧 −5% / 恢复 +10%”。

## 8. 自动战斗下怎么给威胁
用户 06:54：“我们的自动走位和闪避的体系下如何给玩家威胁”。

原则：挂机游戏的威胁**不考手速，考构筑**。
- 每一种威胁对应一种防御属性，玩家回营地后知道该补什么。
- 目标结果是：阵亡很少，但“撤回 / 灯灭提前”很常见。威胁的表现是“这一趟走得不够深”，而不是“我没反应过来”。

### 8.1 三类威胁

| 类别 | 是什么 | 考的属性 | AI 能做的 |
|---|---|---|---|
| **持续压力**（躲不掉） | 怪海贴身伤害、远程齐射、地面火圈 / 毒池、光环怪 | 坚韧（护甲、抗性、条件减伤）、恢复 | 走位只能减少，不能免掉 |
| **有代价的躲避**（能躲，躲有成本） | 精英 / Boss 的预警重击、冲锋、弹幕 | 冲刺槽、冲刺回复、移速、控场、清怪速度 | 用冲刺躲；冲刺用完、被堵住就躲不了 |
| **构筑检定**（逼你改装备） | 精英词缀、天梯层词缀 | 对应的单项防御 | 无法靠走位解决 |

### 8.2 有代价的躲避：具体规则
- **AI 躲预警必须冲刺**（现在是自动躲，改成消耗冲刺槽）。冲刺槽空了就只能走位，走不出圈就吃满伤害。
- **预警会叠**：从 30 层起，精英重击有 30% 几率连放两次（间隔 0.6 秒），Boss 每个招式后接一次范围预警。冲刺槽少的构筑会明显吃亏。
- **被堵住**：路径上怪太密（前方 30 像素内 ≥ 6 只）时，AI 的冲刺距离减半。清得快、有击退或控场的构筑更安全。
- **光圈限制**（灯火 v2）：AI 只能看见光圈里的预警。残灯时光圈小，光圈外砸下来的重击，预警时间只剩一半。残灯的风险就有了具体的样子。

### 8.3 精英词缀（新，精英生成时随机 1 个，30 层起 2 个，60 层起 3 个）

| 词缀 | 效果 | 考什么 |
|---|---|---|
| 炎魂 / 霜魂 / 雷魂 / 圣魂 / 疫魂 / 骨魂 | 攻击全部变成该元素，伤害 +30%，死亡时留一个该元素的地面效果 | 对应单抗 |
| 噬光 | 命中吸 3 灯火 | 灯火上限、回灯火 |
| 破盾 | 对护盾的伤害 ×2 | 生命、护甲（不能只靠护盾） |
| 枯血 | 附近 120 像素内你的生命回复无效 | 护盾、击杀回复（要先杀它） |
| 冲锋 | 每 5 秒冲向你，造成 2 倍伤害并击退 | 近战伤害降低、冲刺 |
| 弹幕 | 每 4 秒向你扇形射出 7 发投射物 | 远程伤害降低 |
| 坚壁 | 受到的伤害 −50%，直到它身边的普通怪死光 | 范围清怪 |
| 召魂 | 每 6 秒召唤 4 只骷髅 | 清怪速度 |
| 镜反 | 反弹 10% 伤害 | 生命、吸血 |

- 精英名字前面显示词缀，例如“炎魂·冲锋 骨甲战士”。
- 天梯层词缀从同一张表里抽，对整层所有精英生效。
- 数据：`progression.elite.affixes: [{id, w, from, fx}]`，`from` 是最早出现的层数。

### 8.4 受伤来源统计（每趟结束给）
- 结算面板加一页“这趟是怎么受伤的”。按 **元素** 和 **来源**（普通怪近战 / 远程 / 精英词缀 / Boss 招式 / 地面效果）分别列出占比。
- 自动给出一句建议，取占比最大且相关防御最低的那一项，例如：
  - “45% 伤害来自火焰远程：火焰抗性 120（当前层减伤 38%），远程伤害降低 0%”
  - “阵亡前 5 秒有 3 次重击没躲开：冲刺槽 1，建议增加冲刺槽或冲刺回复”
- 数据：战斗中每次受伤记录 `{el, src, raw, after}`，结算时汇总。sim.js 同样输出，方便调平衡。

### 8.5 手动接管仍然保留
打 Boss 时愿意自己操作的玩家，可以手动躲重击、走位，多走几层。这是可选的技术上限，不是必须。

## 9. 验收
1. 面板显示秒伤、坚韧、恢复；换一件抗性装备，坚韧的变化和实测承伤一致（误差 10% 内）。
2. 推层 1–80：同一套装备的坚韧随层数平滑下降，没有“过了某层突然秒死”的断崖。
3. 生命球和每秒回复上线后，自动战斗的“紧急撤回”次数下降一半以上。
4. 威胁：模拟里每小时阵亡 ≤ 1 次；30 层以后每趟至少一半因为撤回或灯灭结束，而不是一直走到底；受伤来源统计给出的建议，照做后下一趟的推层更深（抽查 20 趟）。
