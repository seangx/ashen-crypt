# 灰烬地窖 · 防御 v3（参考暗黑 3）

2026-10-27 · 设计线程 · 状态：**方案稿，未开工**
基于 main 1104e7c，接 system-v2.md §7。用户 06:51：“参考暗黑 3 来做防御体系”。暗黑 3 的部分凭记忆整理，细节以游戏为准。

## 1. 暗黑 3 的防御是怎么做的
1. **几层减伤，全部相乘**：
   - 护甲减所有伤害。
   - 抗性减对应元素的伤害（全抗加到每一种上）。
   - 再加各种“X 伤害降低”：近战、远程、精英、职业被动。
2. **护甲和抗性都按怪物等级算，越堆收益越低，但没有硬上限**：
   - 护甲减伤 = 护甲 ÷ (护甲 + 50 × 怪物等级)
   - 抗性减伤 = 抗性 ÷ (抗性 + 5 × 怪物等级)
   - 所以“全抗 1000”在任何难度都有意义，也永远到不了 100%。
3. **生命 + 回复**：
   - 生命来自体能和生命百分比。
   - 回复有每秒回复、命中回复、击杀回复、**生命球**（怪掉的红球，碰到就回血）。
4. **面板上两个数**：坚韧（等效生命，所有减伤折算进来）和恢复（每秒等效回复）。玩家一眼知道自己硬不硬、续不续得上。
5. **闪避在资料片里被拿掉了**：随机性太大，挂机看不出效果。
6. 格挡只在盾上：几率 + 挡掉的固定数值。

## 2. 我们现在的问题
（数值见 data/mechanics.json `defense`，40_stats.js:58、:286）
- **抗性是流放式的百分比 + 上限**（maxRes，硬顶）。堆满上限之后就没用了，所以抗性词条要么“缺了必须补”，要么“满了全是废词条”。刚拆成 6 单抗 + 全抗之后，这个问题更明显。
- **护甲按“这一下的伤害”算**（护甲 ÷ (护甲 + 5 × 这一下伤害)，最多 85%）。对小怪很强、对重击很弱，玩家看面板算不出自己有多硬。
- **生命几乎不回**：只靠吸血（有上限）和打 Boss 回 15%。生命掉了就是掉了，挂机时只能靠撤回。
- **闪避**：随机，挂机看不出效果，和暗黑 3 拿掉它的理由一样。
- 面板上没有“我有多硬”的总数。

## 3. 新防御结构

### 3.1 结算顺序（全部相乘）
```
受到伤害 = 原始伤害
         × (1 − 格挡)              只有盾，挡住时减固定值
         × (1 − 护甲减伤)           所有伤害
         × (1 − 抗性减伤[元素])      该元素的单抗 + 全抗
         × (1 − 条件减伤)           近战 / 远程 / 精英 / 通用防御四种，各自相乘
         → 先扣护盾，再扣生命
```

### 3.2 护甲和抗性改成按层数算（暗黑 3 公式）
- 护甲减伤 = 护甲 ÷ (护甲 + **armorK × 怪物等级**)，`armorK` 第一版 50。
- 抗性减伤 = 抗性 ÷ (抗性 + **resK × 怪物等级**)，`resK` 第一版 5。
- 怪物等级 = 推层层数（天梯按天梯层数换算）。
- 两个都**没有硬上限**，只有递减。
- 抗性上限词条（maxRes）**删除**。06:49 定的“盾牌和法阵出抗性上限”这条撤回，用新公式代替。
- 全抗：加到 6 种单抗上，数值约为单抗的 40%（06:49 定的不变）。
- 效果：
  - 抗性永远有用，只是越堆收益越低。
  - 抗性词条从“补到上限”变成“哪个元素的怪多就堆哪个”。
  - 层数越深需要的护甲和抗性越多，这本身就是推层的难度曲线。

### 3.3 条件减伤（暗黑 3 的“X 伤害降低”）
| 词条 | 部位 | 档位 T1 → 顶 | 说明 |
|---|---|---|---|
| 近战伤害降低 | 盾牌、法阵 | 3% → 12% | 近战怪、Boss 近身攻击 |
| 远程伤害降低 | 盾牌、法阵 | 3% → 12% | 弓手、法师、投射物 |
| 精英伤害降低 | 头冠、盾牌 | 4% → 15% | 精英和 Boss |
| 通用防御四种（控场、贴身、远离、续航） | 保留 | — | 已经是条件减伤，原样保留 |

- 每种各自相乘，单种上限 50%。

### 3.4 生命和回复
| 来源 | 在哪 | 说明 |
|---|---|---|
| 生命、生命提高 | 所有防具类、填充词条 | 已有 |
| **每秒回复生命**（新） | 头冠、遁靴、法阵；血石（防具） | 推层里也生效，取代“生命几乎不回” |
| 命中回复（已有“命中回复生命”） | 武器类 | 保留每秒上限 |
| **击杀回复生命**（新） | 主手、遁靴；血石（武器） | |
| **生命球**（新） | 精英 100% 掉、普通怪 2% 掉 | 碰到回 20% 生命；自动战斗顺路拾取（60 像素内） |
| 打 Boss 回生命 | 已有 15% | 保留 |

- 吸血保留，但只作为“命中回复”的一种，不再是唯一的回血手段。

### 3.5 闪避 → 删除
- 闪避词条、影石（闪避）、天赋闪避节点删除。
- 换成：
  - 影石 → “远程伤害降低”。
  - 天赋闪避节点 → “移速 + 远离减伤”。
  - 已有的闪避装备迁移成远程伤害降低（数值 ×0.6）。
- 闪避相关的独特和规则（闪避尖刺、闪避上限）改成格挡版本。

### 3.6 格挡（只在盾）
- 格挡几率 5–20%（盾底子 + 词条）+ 格挡值：挡住时减去一个固定数值（随物品等级成长）。
- 和现在盾上的“格挡”词条合并。

### 3.7 护盾（保留，作为我们自己的一层）
- 每秒回复 8%（不变），先于生命扣。
- 魂力、法阵、续航相关的都不变。
- 和暗黑 3 的区别：暗黑 3 的护盾来自技能，我们的护盾是常驻的一层。这是本作的特色，保留。

## 4. 面板：坚韧和恢复
- **坚韧** = (生命 + 护盾) ÷ [(1 − 护甲减伤) × (1 − 平均抗性减伤) × (1 − 平均条件减伤)]。
  - 平均抗性按“当前层的怪物元素分布”加权。
  - 平均条件减伤按近战、远程怪的比例加权。
- **恢复** = 每秒回复 + 护盾每秒回复 + 预计命中回复 + 预计击杀回复。
- 角色面板上放在“秒伤”旁边：秒伤、坚韧、恢复三个大数。悬停展开每一层减伤。
- 装备对比显示三项的变化：“秒伤 +3% / 坚韧 −5% / 恢复 +10%”。

## 7. 迁移

## 8. 验收
1. 面板显示秒伤、坚韧、恢复；换一件抗性装备，坚韧的变化和实测承伤一致（误差 10% 内）。
