# 设计规格：技能盘（触发器 + 技能石）与装备镶嵌（属性石）

> 状态：设计稿（方案 3，Sean 已定），未实现。取代 spec-skill-gems.md 里的“技能格”。参考 Hero Siege 遗物触发。

## 0. 代码核对（2026-10-26）
- 装备部位（`src/10_data.js` SLOTS）：技能（gem）、主手 wl、副手 wr、盾牌 shield、头冠 core、遁靴 engine、法阵 hub；另有印记 chip。**没有手套、胸甲、项链、戒指。**
- 遁靴存在，带冲刺（`50_combat.js` “冲刺即技能”），有些遁靴自带伤害。
- 有闪避（`P.dodge`，有上限 dodgeCap）和格挡（盾牌在手时 block）。
- 紫色 HUD 球是**灯火**（`player.soul` / `STATS.soulMax`），不是通用能量：
  - 推关时**持续燃烧**（每层加快），击杀回复，是推关的“生存时钟”；
  - 天梯里不燃烧，按 `soulRegen` 回复（击杀不回）；
  - 霜环、寒魄、陨火这几个符文技能已经按次消耗灯火，不够时退化为普通版本。
- 结论：触发**不**统一扣灯火（会和推关时钟冲突）；只有本来就耗灯火的技能石继续耗。防循环主要靠冷却和预算（第 6 节）。

## 0.5 命名（三种“石头”分开叫）
| 名字 | 是什么 | 放在哪 |
|---|---|---|
| **技能石** | 一个技能（旋风斩、陨火……） | 技能盘格的下半 |
| **辅助符文** | 改技能的支援（多重投射、范围……）——沿用“符文”二字，不叫宝石 | 技能石自带的孔 |
| **属性石** | 纯数值（增伤、减伤、攻速……） | 装备的镶孔 |
| 触发器 | 触发条件物品（不是石头） | 技能盘格的上半 |
- UI 文案统一：“孔”只用于属性石镶孔，技能石上的叫“符文槽”。

## 1. 核心规则
- 角色自带一块**技能盘**，和装备无关；换装备不影响技能盘。
- 每个**盘格 = 1 个触发器 + 1 颗技能石**。触发器条件满足 → 施放这颗石头一次（常驻类除外）。
- **没有主攻石**：角色只做**武器普攻**（按主手武器和攻速自动打）。“攻击时”只是触发器的一种，由普攻触发。
- 所有技能石都放在盘格里。空触发器或空石头的格子不生效。
- 支援符文仍然插在技能石上（1–5 孔，`fit` 看石头标签）。副手仍按原规则支援，改成支援“全部盘格石头”中标签匹配的那些。
- 原来的 `gem` 装备格取消。

## 2. 普攻（新的基础引擎）
- 伤害 = 主手基础伤害 × (1 + 增伤) × 暴击；频率 = 武器攻速 × (1 + 攻速%)。
- 形态由武器类别决定（不需要技能石）：
| cat | 普攻 | 目标 |
|---|---|---|
| melee 近战 | 前方弧形挥砍，半径 1.2 格 | 最近的敌人 |
| bow 弩 | 单发骨矢，可穿透 1 | 最近 |
| gun 铳 | 3 颗散弹 | 最近 |
| caster 法器 | 法球，小范围爆炸 | 最密集处 |
- 普攻吃“武器类别对口加成”的 100%；盘格技能吃 50%（见第 9 节）。
- 普攻的命中 / 暴击 / 击杀会喂“攻击时 / 暴击时 / 击杀时”触发器，所以攻速词条有两份价值：自己的伤害 + 触发频率。
- 普攻占整体 DPS 的目标比例：前期 50%，满盘 20–30%。

## 3. 触发器物品
### 3.1 种类（第一版 10 种）
| id | 名字 | 条件 | 基础触发率 | 内置冷却 ICD | 品质加成（每 1% q） |
|---|---|---|---|---|---|
| tAttack | 攻击时 | 普攻命中 | 20% | 0.6 秒 | 触发率 +0.5% |
| tCrit | 暴击时 | 普攻或技能暴击 | 100% | 1.2 秒 | ICD −0.5% |
| tKill | 击杀时 | 任意击杀（规则见第 6 节） | 100% | 0.8 秒 | ICD −0.5% |
| tStruck | 受击时 | 受到命中（含被格挡） | 25% | 1.0 秒 | 触发率 +0.5% |
| tDodge | 闪避时 | 闪避或格挡成功 | 100% | 1.5 秒 | ICD −0.5% |
| tDash | 冲刺时 | 遁靴冲刺 | 100% | 跟随冲刺冷却 | 伤害 +1% |
| tLow | 低血时 | 生命 < 35% 进入时，之后每 3 秒 | 100% | 3 秒 | 阈值 +0.25% |
| tTimer | 每 N 秒 | 固定节拍，N 随稀有度 4/3.5/3 秒 | 100% | = N | N −0.5% |
| tElite | 遇精英时 | 精英或首领进入 8 格内 | 100% | 6 秒 | ICD −0.5% |
| tAlways | 常驻 | 光环、环绕、随从持续存在，不施放 | — | — | 范围 +1% |
### 3.2 属性
- `q` 品质 0–20%：掉落时 0–10%，铁砧“打磨”用碎片 +1%，规则和技能石一致。
- 稀有度：普通 / 魔法（+1 条小词条：触发率 +x%、ICD −x%、被触发技能伤害 +x%）/ 稀有（+2 条）/ 独特（固定特殊效果，见第 9 节）。
- `lvl` 不需要：触发器不升级，只靠品质和词条。
### 3.3 掉落与分解
- 来源：普通怪极低（0.2%）、精英 3%、首领必掉 1 个、天梯每 5 层奖励箱、营地分解坛不产出。
- 种类权重：攻击时 / 击杀时 / 受击时 / 每 N 秒 较常见（各 15）；暴击时 / 闪避时 / 冲刺时 / 低血时 较少（各 8）；遇精英时 6；常驻 4。
- 分解：同技能石的碎片规则；独特给对应的系碎片 ×3。

## 4. 盘格数量与解锁
- 最多 **6 格**。
- 解锁：开局 1 格（送一个普通“攻击时”）；天梯 5 层 2 格、10 层 3 格、20 层 4 格、35 层 5 格；第 6 格来自天赋树终点（“第六格”），避免全部靠爬层。
- 解锁和品质无关；格子本身没有属性，所有数值在触发器和石头上。
- 可以带多个相同种类的触发器，但同种触发器之间共用 **0.3 秒**的全局间隔，避免同一帧同时爆发。

## 5. 石头和触发器的匹配
- **不做惩罚**，但做**适配加成**：每颗石头有 `like`（1–2 个推荐触发器），匹配时伤害 +20%，UI 显示“契合”。
- 理由：惩罚会让新手不敢尝试；加成只是鼓励。
- 常驻触发器只能放 `orbit` 类的石头（瘟疫光环、游雷），其他石头放进去 UI 直接提示不可用。这是唯一的硬限制。

## 6. 防止无限循环
1. 盘格技能造成的事件**不能触发**攻击时 / 暴击时 / 受击时 / 闪避时 / 冲刺时；它们只能由普攻或敌人行为触发。
2. 击杀时例外：盘格技能的击杀**可以**触发击杀时，但击杀时格子自己的技能击杀不行（标记 `src`），而且最多传 1 层。
3. 每个格子有 ICD，每颗石头最快 0.25 秒一次；全局每秒最多 12 次触发，超出的直接丢弃。
4. 灯火：不额外扣。霜环、寒魄、陨火保持原有的每次消耗；被触发时灯火不够就放普通版本（沿用现在的逻辑）。
5. 有持续施放的石头（旋风斩、圣光束、喷火）被触发时改成“持续 2 秒”的一段，而不是一直开着。

## 8. 装备的触发词条
装备不提供盘格。触发相关的加成**保留为装备词条**（决定见 14.7），属性石里只放少量触发石：
| 部位 | 词条（例） |
|---|---|
| 主手 | 攻速 +x%；攻击时触发率 +x%；普攻暴击率 +x% |
| 副手 | 盘格技能伤害 +x%；指定系 +x% |
| 盾牌 | 受击时触发率 +x%；闪避 / 格挡时 ICD −x% |
| 头冠 | 每 N 秒间隔 −0.25 / −0.5 秒；暴击时 ICD −x% |
| 遁靴 | 冲刺时技能伤害 +x%；冲刺冷却 −x% |
| 法阵 | 击杀时触发 ICD −x%；常驻范围 +x%；低血阈值 +x% |
- 数值上限：触发率 +15%、ICD −20%、间隔 −1 秒，叠加后封顶（触发率 ≤ 60%，ICD ≥ 基础的 50%）。

## 9. 独特装备 / 天赋 / 武器类别
- **武器类别**：对口加成普攻吃 100%；盘格石头只要有对口标签就吃 50%。
- **大天赋**（旋风之心、织雷之心、星坠雨、碎冰、碎冰连锁、回响圣盾）：条件改成“盘上**任意**石头有该标签 / 是该石头”，效果只给对应石头。
- **新天赋**：“第六格”；“连锁”：击杀时可以传 2 层；“稳定节拍”：每 N 秒触发器 −0.5 秒。
- **独特装备**：原条件“技能石有 X”改为“盘上任意石头有 X”。新增 4 件触发主题独特装备：受击时触发的技能必定暴击；冲刺时触发两次；击杀时不受全局上限；普攻每第 5 下视为暴击。
- **独特触发器**（掉落）：比如“回声”（触发其左侧格子的技能，ICD 3 秒）、“猎首”（遇精英时 + 击杀精英重置）。

## 11. 存档迁移（S.gemV = 2）
- 头冠 / 遁靴上现有的辅助符文槽 → 改为同数量的属性石镶孔；插着的符文退回背包（符文本来就该插技能石）。

- 已经过天梯里程碑的玩家，按进度直接解锁对应的格子数，格子空着；另外按每格送一个随机普通触发器，避免空盘。
- 背包里的其他技能石不动。
- 用 gemV 保护，可以重复执行。

## 12. 平衡与模拟
- 属性石总贡献：满孔中阶（T3）约等于一件好装备的词条量 30–40%；防御石让推关承伤下降不超过 25%。
- 目标：满盘（6 格）的总 DPS ≈ 现在单石的 1.7 倍；怪物血量曲线整体 ×1.4，前 20 层体感不变。
- 第 1 格阶段（只有攻击时 + 1 石头）DPS 应等于现在的 0.9–1.0 倍，不能让开局变弱。
- 模拟器（`design/sim`）：加入普攻模型（4 类）、事件流（命中 / 暴击 / 击杀 / 受击 / 闪避 / 冲刺 / 计时 / 精英）、ICD 和全局上限。
- 跑 4 套示例搭配 × 天梯 1–60 和推关 1–80，检查：
  - 每秒触发 p50 / p99（目标 p99 ≤ 10，打满上限的时间 < 5%）；
  - 每个触发器种类的贡献占比（单个触发器种类 < 40%）；
  - 灯火：推关里因触发耗灯火导致见底的时间 < 10%；
  - 和现有天梯基线对比在 ±10% 以内。
- 手机性能：200 只怪 + 满盘时帧时间增加 ≤ 1 ms。

## 13. 已定决策（Sean，2026-10-26）
- 方案 3：技能盘绑角色，不跟装备走。
- 没有主攻石；角色普攻，攻击时是普通触发器。
- 触发**不耗灯火**；霜环 / 寒魄 / 陨火保留原有的灯火消耗。
- 盘格上限 **6**。
- 石头和触发器不契合**不惩罚**，契合 +20%。
- 普攻按 **4 种武器类别**。
- 装备孔镶**属性石**（增伤、减伤等），和技能石分开。

## 14. 装备镶嵌：属性石
### 14.1 孔数
现有代码：头冠、遁靴掉落时带 1–6 个符文槽（`loot.json sockets.weapon` 权重），武器在技能石改版后已经没有槽，法阵有自己的领域符文升级槽。改为：
| 部位 | 孔数上限（普通 / 魔法 / 稀有 / 独特） | 掉落权重 |
|---|---|---|
| 主手 | 1 / 2 / 3 / 固定 0–2 | 沿用 `sockets.weapon` 前 3 档 [1000, 800, 600] |
| 副手 | 1 / 1 / 2 / 固定 | 同上 |
| 盾牌 | 1 / 2 / 3 / 固定 | 同上 |
| 头冠 | 1 / 2 / 3 / 固定 | 同上 |
| 遁靴 | 1 / 1 / 2 / 固定 | 同上 |
| 法阵 | 0（继续用领域符文槽） | — |
- 掉落孔数 = 权重抽取，再按稀有度上限截断。最多全身 13 孔。
- **开孔符**：现在只给技能石 +1 符文槽，扩展为“技能石或装备 +1”（装备不超过上限）。掉落率不变；铁砧多一个“开孔”按钮。
- 独特装备的孔数是固定的（写在 uniques.json），不能开孔。

### 14.3 等级与品质
- 5 阶：碎裂 / 粗糙 / 普通 / 无瑕 / 完美（T1–T5），数值大约 1 : 1.8 : 2.7 : 3.8 : 5。
- 没有 q 品质（避免和技能石、触发器的打磨重复），阶就是品质。
- 合成：铁砧“合成”，3 颗同种同阶 → 1 颗高一阶（D2 方式）。T4 → T5 额外要 10 个对应系碎片。
- 拆卸：免费，石头退回背包（手游上减少挫败感）。

### 14.4 掉落
- 普通怪 1%（T1 为主），精英 6%，首领必掉 1–2 颗；层数越高高阶权重越大（T1 在 1 层占 80%，60 层占 10%）。
- 天梯每 10 层奖励箱固定 1 颗 T3+。
- 寻宝石不会自己掉 T5。

### 14.5 分解
- 属性石分解成对应系碎片（攻 → 动能 / 爆，守 → 圣 / 冰，用和触发 → 电 / 疫），数量 = 阶 × 2。
- 装备分解时，镶着的属性石自动退回背包，不会被一起分解（分解确认框里写清楚）。

### 14.6 和辅助符文的关系
- 辅助符文**只**插在技能石上，不能镶到装备孔里；属性石不能插技能石。两套孔完全分开，`fit` 各查各的。
- 副手的“支援”规则保持不变，和副手上的属性石叠加。

### 14.7 触发词条放在哪（决定）
- **推荐：触发词条大部分留在装备词条上**（第 8 节），属性石里只有 2 种触发石（回响、钟摆）并限制全身 2 颗。
- 理由：装备词条决定“这件装备适合什么搭配”，刷装备有目标；如果全部搬进属性石，装备只剩基础数值，掉落就没有惊喜了。属性石留作“微调”。

### 14.8 手机 UI
- 装备详情弹窗：在词条下面加一行孔（像素方框，空孔是暗色描边，有石头显示图标和阶数点）。
- 点孔 → 底部弹出选择器：列出背包里的属性石，按“镶在这里的效果”排序显示，比如“赤焰石 T3 · 伤害 +18%”。
- 点选后弹模态确认（“镶入 赤焰石 T3？”），确认按钮在右下。替换已有石头时，确认框说明旧石头会退回背包。
- 背包增加“属性石”页签；铁砧增加“合成”。
- 桌面版暂不改布局，数据共用。
