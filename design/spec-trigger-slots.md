# 设计规格：技能盘（触发器 + 技能石）与装备镶嵌（属性石）

> 状态：设计稿（方案 3，Sean 已定），未实现。取代 spec-skill-gems.md 里的“技能格”。参考 Hero Siege 遗物触发。

## 0. 代码核对（2026-10-26）
- 装备部位（`src/10_data.js` SLOTS）：技能（gem）、主手 wl、副手 wr、盾牌 shield、头冠 core、遁靴 engine、法阵 hub；另有印记 chip。**没有手套、胸甲、项链、戒指。**
- 遁靴存在，带冲刺（`50_combat.js` “冲刺即技能”），有些遁靴自带伤害。
- 有闪避（`P.dodge`，有上限 dodgeCap）和格挡（盾牌在手时 block）。
- 紫色 HUD 球是**灯火**（`player.soul` / `STATS.soulMax`），不是通用能量：
  - 推关时**持续燃烧**（每层加快），击杀回复，是推关的“生存时钟”；
  - 天梯里不燃烧，按 `soulRegen` 回复（击杀不回）；
  - 霜环、寒魄、陨火这几个符文技能已经按次消耗灯火，不够时退化为普通版本。
- 结论：触发**不**统一扣灯火（会和推关时钟冲突）；只有本来就耗灯火的技能石继续耗。防循环主要靠冷却和预算（第 6 节）。

## 0.5 命名（三种“石头”分开叫）
| 名字 | 是什么 | 放在哪 |
|---|---|---|
| **技能石** | 一个技能（旋风斩、陨火……） | 技能盘格的下半 |
| **辅助符文** | 改技能的支援（多重投射、范围……）——沿用“符文”二字，不叫宝石 | 技能石自带的孔 |
| **属性石** | 纯数值（增伤、减伤、攻速……） | 装备的镶孔 |
| 触发器 | 触发条件物品（不是石头） | 技能盘格的上半 |
- UI 文案统一：“孔”只用于属性石镶孔，技能石上的叫“符文槽”。

## 1. 核心规则
- 角色自带一块**技能盘**，和装备无关；换装备不影响技能盘。
- 每个**盘格 = 1 个触发器 + 1 颗技能石**。触发器条件满足 → 施放这颗石头一次（常驻类除外）。
- **没有主攻石**：角色只做**武器普攻**（按主手武器和攻速自动打）。“攻击时”只是触发器的一种，由普攻触发。
- 所有技能石都放在盘格里。空触发器或空石头的格子不生效。
- 支援符文仍然插在技能石上（1–5 孔，`fit` 看石头标签）。副手仍按原规则支援，改成支援“全部盘格石头”中标签匹配的那些。
- 原来的 `gem` 装备格取消。

## 2. 普攻（新的基础引擎）
- 伤害 = 主手基础伤害 × (1 + 增伤) × 暴击；频率 = 武器攻速 × (1 + 攻速%)。
- 形态由武器类别决定（不需要技能石）：
| cat | 普攻 | 目标 |
|---|---|---|
| melee 近战 | 前方弧形挥砍，半径 1.2 格 | 最近的敌人 |
| bow 弩 | 单发骨矢，可穿透 1 | 最近 |
| gun 铳 | 3 颗散弹 | 最近 |
| caster 法器 | 法球，小范围爆炸 | 最密集处 |
- 普攻吃“武器类别对口加成”的 100%；盘格技能吃 50%（见第 9 节）。
- 普攻的命中 / 暴击 / 击杀会喂“攻击时 / 暴击时 / 击杀时”触发器，所以攻速词条有两份价值：自己的伤害 + 触发频率。
- 普攻占整体 DPS 的目标比例：前期 50%，满盘 20–30%。

## 3. 触发器物品
### 3.1 种类（第一版 10 种）
| id | 名字 | 条件 | 基础触发率 | 内置冷却 ICD | 品质加成（每 1% q） |
|---|---|---|---|---|---|
| tAttack | 攻击时 | 普攻命中 | 20% | 0.6 秒 | 触发率 +0.5% |
| tCrit | 暴击时 | 普攻或技能暴击 | 100% | 1.2 秒 | ICD −0.5% |
| tKill | 击杀时 | 任意击杀（规则见第 6 节） | 100% | 0.8 秒 | ICD −0.5% |
| tStruck | 受击时 | 受到命中（含被格挡） | 25% | 1.0 秒 | 触发率 +0.5% |
| tDodge | 闪避时 | 闪避或格挡成功 | 100% | 1.5 秒 | ICD −0.5% |
| tDash | 冲刺时 | 遁靴冲刺 | 100% | 跟随冲刺冷却 | 伤害 +1% |
| tLow | 低血时 | 生命 < 35% 进入时，之后每 3 秒 | 100% | 3 秒 | 阈值 +0.25% |
| tTimer | 每 N 秒 | 固定节拍，N 随稀有度 4/3.5/3 秒 | 100% | = N | N −0.5% |
| tElite | 遇精英时 | 精英或首领进入 8 格内 | 100% | 6 秒 | ICD −0.5% |
| tAlways | 常驻 | 光环、环绕、随从持续存在，不施放 | — | — | 范围 +1% |
### 3.2 触发器是刷的东西（概要，细节见第 16 节）
- 每个触发器 = **底子**（3.1 的种类，决定条件和基础触发率 / ICD）+ **物品等级 ilvl** + **稀有度** + **随机词条**。
- 品质 q 0–20% 保留：放大底子的数值（表里最后一列）。
- 掉落、重铸、分解、比较 UI 见第 16 节。

## 4. 盘格数量与解锁
- 最多 **6 格**。
- 解锁：开局 1 格（送一个普通“攻击时”）；天梯 5 层 2 格、10 层 3 格、20 层 4 格、35 层 5 格；第 6 格来自天赋树终点（“第六格”），避免全部靠爬层。
- 解锁和品质无关；格子本身没有属性，所有数值在触发器和石头上。
- 可以带多个相同种类的触发器，但同种触发器之间共用 **0.3 秒**的全局间隔，避免同一帧同时爆发。

## 5. 石头和触发器的匹配
- **不做惩罚**，但做**适配加成**：每颗石头有 `like`（1–2 个推荐触发器），匹配时伤害 +20%，UI 显示“契合”。
- 理由：惩罚会让新手不敢尝试；加成只是鼓励。
- 常驻触发器只能放 `orbit` 类的石头（瘟疫光环、游雷），其他石头放进去 UI 直接提示不可用。这是唯一的硬限制。

## 6. 防止无限循环
1. 盘格技能造成的事件**不能触发**攻击时 / 暴击时 / 受击时 / 闪避时 / 冲刺时；它们只能由普攻或敌人行为触发。
2. 击杀时例外：盘格技能的击杀**可以**触发击杀时，但击杀时格子自己的技能击杀不行（标记 `src`），而且最多传 1 层。
3. 每个格子有 ICD，每颗石头最快 0.25 秒一次；全局每秒最多 12 次触发，超出的直接丢弃。
4. 灯火：不额外扣。霜环、寒魄、陨火保持原有的每次消耗；被触发时灯火不够就放普通版本（沿用现在的逻辑）。
5. 有持续施放的石头（旋风斩、圣光束、喷火）被触发时改成“持续 2 秒”的一段，而不是一直开着。

## 8. 装备上的触发相关词条（缩减）
触发器本身成了刷的主体，装备上只保留**泛用**的两条，避免重复：
| 部位 | 词条 | 范围 |
|---|---|---|
| 主手 | 攻速 +x%（喂攻击时） | 原有词条，不变 |
| 副手 / 头冠 | 盘格技能伤害 +x% | 4–12% |
- 原来按种类的词条（受击触发率、每 N 秒间隔、冲刺 ICD、击杀 ICD……）**全部移到触发器词条池**（16.3），装备上不再出现。
- 老装备上已有的这类词条保留数值但改成“盘格技能伤害 +5%”（迁移见 11）。

## 9. 独特装备 / 天赋 / 武器类别
- **武器类别**：对口加成普攻吃 100%；盘格石头只要有对口标签就吃 50%。
- **大天赋**（旋风之心、织雷之心、星坠雨、碎冰、碎冰连锁、回响圣盾）：条件改成“盘上**任意**石头有该标签 / 是该石头”，效果只给对应石头。
- **新天赋**：“第六格”；“连锁”：击杀时可以传 2 层；“稳定节拍”：每 N 秒触发器 −0.5 秒。
- **独特装备**：原条件“技能石有 X”改为“盘上任意石头有 X”。新增 4 件触发主题独特装备：受击时触发的技能必定暴击；冲刺时触发两次；击杀时不受全局上限；普攻每第 5 下视为暴击。
- **独特触发器**（掉落）：比如“回声”（触发其左侧格子的技能，ICD 3 秒）、“猎首”（遇精英时 + 击杀精英重置）。

## 11. 存档迁移（S.gemV = 2）
- 头冠 / 遁靴上现有的辅助符文槽 → 改为同数量的属性石镶孔；插着的符文退回背包（符文本来就该插技能石）。
- 法阵的升级槽和领域符文不动。
- 每件已有装备按 14.1 的上限截断孔数（超出的孔删掉，上面没有东西可退）。
- 现有 `eq.gem` 的技能石 → 盘格 1，配一个普通“攻击时”触发器（q = 10%），符文保留。
- 已经过天梯里程碑的玩家，按进度直接解锁对应的格子数，格子空着；另外按每格送一个随机普通触发器，避免空盘。
- 背包里的其他技能石不动。
- 送出的触发器统一是 ilvl = 当前天梯最高层、普通稀有度。
- 装备上按种类的触发词条（如果实现前已经出现过）→ “盘格技能伤害 +5%”。
- 用 gemV 保护，可以重复执行。

## 12. 平衡与模拟
- 属性石总贡献：满孔中阶（T3）约等于一件好装备的词条量 30–40%；防御石让推关承伤下降不超过 25%。
- 触发器贡献：同一格从普通 T1 换到稀有 T5（满词条），这一格输出 ≈ ×2.2；独特触发器按“改变玩法”设计，数值不超过同阶稀有的 1.3 倍。
- 目标：满盘（6 格）的总 DPS ≈ 现在单石的 1.7 倍；怪物血量曲线整体 ×1.4，前 20 层体感不变。
- 第 1 格阶段（只有攻击时 + 1 石头）DPS 应等于现在的 0.9–1.0 倍，不能让开局变弱。
- 模拟器（`design/sim`）：加入普攻模型（4 类）、事件流（命中 / 暴击 / 击杀 / 受击 / 闪避 / 冲刺 / 计时 / 精英）、ICD 和全局上限。
- 跑 4 套示例搭配 × 天梯 1–60 和推关 1–80，检查：
  - 每秒触发 p50 / p99（目标 p99 ≤ 10，打满上限的时间 < 5%）；
  - 每个触发器种类的贡献占比（单个触发器种类 < 40%）；
  - 灯火：推关里因触发耗灯火导致见底的时间 < 10%；
  - 和现有天梯基线对比在 ±10% 以内。
- 手机性能：200 只怪 + 满盘时帧时间增加 ≤ 1 ms。

## 13. 已定决策（Sean，2026-10-26）
- 方案 3：技能盘绑角色，不跟装备走。
- 没有主攻石；角色普攻，攻击时是普通触发器。
- 触发**不耗灯火**；霜环 / 寒魄 / 陨火保留原有的灯火消耗。
- 盘格上限 **6**。
- 石头和触发器不契合**不惩罚**，契合 +20%。
- 普攻按 **4 种武器类别**。
- 装备孔镶**属性石**（增伤、减伤等），和技能石分开。

## 14. 装备镶嵌：属性石
### 14.1 孔数
现有代码：头冠、遁靴掉落时带 1–6 个符文槽（`loot.json sockets.weapon` 权重），武器在技能石改版后已经没有槽，法阵有自己的领域符文升级槽。改为：
| 部位 | 孔数上限（普通 / 魔法 / 稀有 / 独特） | 掉落权重 |
|---|---|---|
| 主手 | 1 / 2 / 3 / 固定 0–2 | 沿用 `sockets.weapon` 前 3 档 [1000, 800, 600] |
| 副手 | 1 / 1 / 2 / 固定 | 同上 |
| 盾牌 | 1 / 2 / 3 / 固定 | 同上 |
| 头冠 | 1 / 2 / 3 / 固定 | 同上 |
| 遁靴 | 1 / 1 / 2 / 固定 | 同上 |
| 法阵 | 0（继续用领域符文槽） | — |
- 掉落孔数 = 权重抽取，再按稀有度上限截断。最多全身 13 孔。
- **开孔符**：现在只给技能石 +1 符文槽，扩展为“技能石或装备 +1”（装备不超过上限）。掉落率不变；铁砧多一个“开孔”按钮。
- 独特装备的孔数是固定的（写在 uniques.json），不能开孔。

- 限制：同一件装备上同种属性石只生效一颗。

### 14.3 等级与品质
- 5 阶：碎裂 / 粗糙 / 普通 / 无瑕 / 完美（T1–T5），数值大约 1 : 1.8 : 2.7 : 3.8 : 5。
- 没有 q 品质（避免和技能石、触发器的打磨重复），阶就是品质。
- 合成：铁砧“合成”，3 颗同种同阶 → 1 颗高一阶（D2 方式）。T4 → T5 额外要 10 个对应系碎片。
- 拆卸：免费，石头退回背包（手游上减少挫败感）。

### 14.4 掉落
- 普通怪 1%（T1 为主），精英 6%，首领必掉 1–2 颗；层数越高高阶权重越大（T1 在 1 层占 80%，60 层占 10%）。
- 天梯每 10 层奖励箱固定 1 颗 T3+。
- 寻宝石不会自己掉 T5。

### 14.5 分解
- 属性石分解成对应系碎片（攻 → 动能 / 爆，守 → 圣 / 冰，用和触发 → 电 / 疫），数量 = 阶 × 2。
- 装备分解时，镶着的属性石自动退回背包，不会被一起分解（分解确认框里写清楚）。

### 14.6 和辅助符文的关系
- 辅助符文**只**插在技能石上，不能镶到装备孔里；属性石不能插技能石。两套孔完全分开，`fit` 各查各的。
- 副手的“支援”规则保持不变，和副手上的属性石叠加。

### 14.7 触发加成放在哪（更新）
- 触发加成**集中在触发器本身**（第 16 节）。装备只保留攻速和盘格技能伤害两条泛用词条；属性石里**去掉**回响石和钟摆石，不做触发类属性石。
- 理由：同一个数值三处都能堆，封顶很难控，刷的目标也会分散。触发器成为唯一的“触发调节”来源，装备和属性石负责基础数值。

### 14.8 手机 UI

- 点孔 → 底部弹出选择器：列出背包里的属性石，按“镶在这里的效果”排序显示，比如“赤焰石 T3 · 伤害 +18%”。
- 点选后弹模态确认（“镶入 赤焰石 T3？”），确认按钮在右下。替换已有石头时，确认框说明旧石头会退回背包。
- 背包增加“属性石”页签；铁砧增加“合成”。
- 桌面版暂不改布局，数据共用。

## 16. 触发器掉落层（刷的内容）
### 16.1 物品等级和阶
- ilvl = 掉落的层数（推关）或天梯层数。
- 5 阶，按 ilvl 决定能出的最高阶：T1（1+）、T2（10+）、T3（25+）、T4（40+）、T5（60+）。阶决定词条数值档位。
- 底子数值（基础触发率 / ICD）不随阶变化，只随品质 q；这样“攻击时 20%”永远可读。

### 16.2 稀有度
| 稀有度 | 词条数 | 掉落占比 | 颜色 |
|---|---|---|---|
| 普通 | 0 | 60% | 灰白 |
| 魔法 | 1–2 | 30% | 蓝 |
| 稀有 | 3–4 | 9% | 黄 |
| 独特 | 固定 2–3 条 + 特殊效果 | 1%（只在 T3+） | 金 |
| 传奇 | — | 第一版不做 | — |
- **不做传奇**：独特已经承担“改变玩法”，再加一层只会让平衡和背包更乱。以后可以把传奇做成“独特 + 1 条随机词条”。

### 16.3 词条池（T1 → T5 范围）
| id | 词条 | T1 | T5 | 限制 |
|---|---|---|---|---|
| aRate | 触发率 +% | +3% | +15% | 只出现在触发率 < 100% 的底子（攻击时、受击时） |
| aIcd | 内置冷却 −% | −4% | −20% | 不出现在常驻 |
| aInt | 间隔 −秒 | −0.1 | −0.5 | 只出现在每 N 秒 |
| aDmg | 被触发技能伤害 +% | +8% | +40% | — |
| aArea | 被触发技能范围 +% | +5% | +20% | — |
| aExtra | 额外施放 1 次的几率 | 3% | 12% | 额外那次不计 ICD，但计全局上限 |
| aTag | 【标签】技能伤害 +%（投射物 / 范围 / 近战 / 持续 / 新星） | +10% | +50% | 技能石没有这个标签时不生效（UI 灰显） |
| aEl | 某系技能伤害 +% | +10% | +45% | 同上 |
| aCrit | 被触发技能暴击率 +% | +3% | +12% | — |
| aChain | 触发时，相邻格（左右）也触发的几率 | 2% | 8% | 稀有 / 独特才有；相邻格自己的 ICD 照算；**不再传递** |
| aSoul | 被触发时回复灯火 | +0.2 | +1 | 只出现在击杀时、遇精英时 |
| aLow | 低血阈值 +% | +3% | +10% | 只出现在低血时 |
- 每个触发器同一词条只出现一次；稀有最多 1 条 aChain / aExtra（二选一）。
- **硬封顶**（所有来源叠加后）：触发率 ≤ 60%（攻击时）/ 70%（受击时）；ICD ≥ 基础的 50%；每 N 秒 ≥ 1.5 秒；额外施放 ≤ 25%。第 6 节的全局限制不变。

### 16.4 独特触发器（10 个）
| 名字 | 底子 | 效果 | 推荐搭配 |
|---|---|---|---|
| 回声 | 每 N 秒（4 秒） | 触发**左侧格**的技能（不走左侧格的条件，只走它的 ICD） | 把好用的技能复制一份 |
| 猎首 | 遇精英时 | 击杀精英 / 首领时立即重置并再触发一次 | 首领战 |
| 血誓 | 低血时 | 阈值改为 50%；触发时消耗 5% 当前生命，技能伤害 +80% | 高回血、圣盾反击 |
| 雷鸣之心 | 暴击时 | 暴击时触发的技能必定暴击，ICD +50% | 雷符、散射 |
| 尸山 | 击杀时 | 每次触发叠 1 层（最多 20），每层被触发技能伤害 +3%，5 秒不击杀清零 | 击杀连爆 |
| 回旋之刃 | 攻击时 | 触发率固定 100%，但只在每第 4 次普攻 | 快攻速近战 |
| 不动 | 受击时 | 站着不动 1 秒以上时触发率 ×2 | 盾、陷阱 |
| 残影 | 冲刺时 | 冲刺终点留下残影，1 秒后再触发一次 | 冲撞、旋风 |
| 永夜灯 | 常驻 | 常驻技能范围 +40%，灯火燃烧 +10% | 瘟疫光环（推关有代价） |
| 双生 | 闪避时 | 同时触发两侧格子（各自 ICD），自身没有技能槽效果 | 圣盾、新星 |
- “回声”“双生”属于跨格效果，算第 6 节第 1 条的例外：它们本身是“源头”，被它们触发的技能**不能**再触发别的格子。

### 16.5 掉落来源
| 来源 | 几率 | 备注 |
|---|---|---|
| 普通怪 | 0.3% | 只出普通 / 魔法 |
| 精英 | 4% | |
| 首领 | 必掉 1 个，25% 再掉 1 个 | 有偏好（下表） |
| 天梯宝箱 | 每 5 层 1 个，每 20 层保底稀有 | |
| 推关首通 | 每 10 层首通保底 1 个魔法 + | |
- **定向刷**：每个首领偏好 2 种底子（权重 ×4），例如：霜冻王座 → 受击时 / 低血时；火焰首领 → 击杀时 / 每 N 秒；雷首领 → 暴击时 / 攻击时。在图鉴“手册”里列出。
- 独特触发器绑定首领或天梯段（比如“猎首”只在天梯 30+ 首领）。

### 16.6 制作
- **重铸**（铁砧）：花 1 个“重铸符”（新符文道具，天梯和精英掉）重新随机全部词条，稀有度不变；独特不能重铸。
- **定向改一条**：花 10 个对应系碎片，锁住其他词条，只重随一条（每个触发器最多 3 次，次数写在物品上）。
- **升阶**：花 20 个碎片 + 同底子同稀有度的另一个触发器，把 T 提高一阶（不超过当前天梯最高层对应的阶）。
- **打磨**：品质 q +1%，沿用技能石规则。
- **分解**：普通 1 碎片、魔法 2、稀有 5、独特 15（独特给特殊“残响”碎片，用于重铸符兑换）。

### 16.7 背包与经济
- 触发器单独一个背包页签，容量 60。
- **自动分解**：设置里按稀有度勾选（默认：普通自动分解，ilvl 低于当前天梯 −15 的魔法也自动分解）。独特永不自动分解。
- **叠放**：普通触发器同底子同阶叠放成一格（显示 ×N）；魔法以上不叠。
- 每局结束弹一次“本局获得：触发器 ×N（自动分解 ×M → 碎片 +K）”，不逐个提示。
- 碎片总产出按现在的 1.3 倍调整，因为触发器制作是新的碎片出口。

### 16.8 手机比较 UX
- 拾取提示上显示稀有度色和底子图标；点开详情：
  ```
  ┌ 稀有 · 击杀时 · T3 · q12% ────┐
  │ 触发率 100%  ICD 0.75 s        │
  │ + 被触发技能伤害 +24%          │
  │ + 范围技能伤害 +30%  (火油罐 ✓) │
  │ + 相邻格触发 4%                │
  │ ── 对比 第 2 格（击杀时 T2）── │
  │ 输出估算  +18%  ▲               │
  │ [装到第 2 格] [选别的格] [分解] │
  └────────────────────────────────┘
  ```
- 默认和“同种底子的格子”比较；没有同种底子时和输出最低的格子比较。“输出估算”用最近 60 秒的事件统计算。
- 装入 / 替换 / 分解都弹模态确认，确认按钮在右下；替换时说明旧触发器退回背包。
- 技能盘格子上半显示触发器的稀有度边框颜色和阶数点。

### 16.9 平衡补充
- 稀有度带来的输出：魔法 ≈ 普通 × 1.3，稀有 ≈ × 1.7，独特看效果但不超过同阶稀有 × 1.3。
- 阶带来的输出：T1 → T5 约 × 1.6（只在词条上）。
- 模拟器加入“触发器配置”：每套示例搭配分别跑全普通、全魔法 T3、全稀有 T5 三档，检查满盘稀有 T5 时：
  - 每秒触发 p99 仍 ≤ 10，全局上限命中时间 < 5%；
  - aChain + aExtra 叠满时每秒施放次数不超过不带时的 1.35 倍；
  - 回声、双生不会让单格贡献超过总输出 45%。
- 掉落经济模拟：60 层天梯一轮预计拿到稀有 6–10 个、独特 0–1 个，背包（开自动分解）不超过 25 格。
