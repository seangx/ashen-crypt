# 设计规格：触发器（独立物品 · 随机孔 · 插技能石和辅助石）

> 状态：设计稿，未实现（2026-10-26，Sean 第 4 次修正）。
> 效果图：`design/mockups-v5/`。装备、元素、防御、灯火的配套设计见 system-v2.md（冲突处以它为准）。不兼容老存档。

## 1. 一句话
角色普攻自动打；身上带 1–4 个**触发器**；每个触发器是一件独立装备，带随机数量的**孔**，孔里插**技能石**和**辅助石**；触发条件满足 → 施放里面的技能。

## 2. 命名
| 名字 | 是什么 | 插在哪 |
|---|---|---|
| **触发器** | 独立物品：条件 + 稀有度 + 阶 + 词条 + 孔 | 角色的触发器栏（1–4） |
| **技能石** | 一个技能（19 颗） | 触发器的孔 |
| **辅助石**（原“辅助符文”） | 改技能的支援（多重投射、范围…） | 触发器的孔 |
| **属性石** | 纯数值（增伤、减伤…） | 装备的孔（第 9 节，不变） |
- 技能石**不再有自己的符文槽**。

## 3. 普攻
- 没有主攻石。普攻按 4 种武器类别：近战挥砍 / 弩单发 / 铳 3 散弹 / 法器小爆。伤害和攻速来自主手。
- 普攻命中、暴击、击杀产生“攻击时 / 暴击时 / 击杀时”事件。
- 武器类别对口加成：普攻 100%，触发器里的技能 50%。

## 4. 触发器
### 4.1 条件（底子）
| 底子 | 条件 | 基础触发率 | 内置冷却 |
|---|---|---|---|
| 攻击时 | 普攻命中 | 20% | 0.6 s |
| 暴击时 | 普攻或技能暴击 | 100% | 1.2 s |
| 击杀时 | 任意击杀 | 100% | 0.8 s |
| 受击时 | 被命中 | 25% | 1.0 s |
| 闪避时 | 闪避 / 格挡 | 100% | 1.5 s |
| 冲刺时 | 遁靴冲刺 | 100% | 跟冲刺冷却 |
| 低血时 | 生命 < 35% | 100% | 3 s |
| 每 N 秒 | 节拍 4 / 3.5 / 3 s | 100% | = N |
| 遇精英时 | 精英 / 首领 8 格内 | 100% | 6 s |
| 常驻 | 光环、环绕、随从一直在 | — | — |

### 4.2 孔
- 孔数随机，按稀有度：
| 稀有度 | 孔数 | 权重 |
|---|---|---|
| 普通 | 1–2 | [70, 30] |
| 魔法 | 2–3 | [60, 40] |
| 稀有 | 2–4 | [30, 50, 20] |
| 独特 | 固定（写在数据里，3–5） | — |
- 阶加成：T4+ 的稀有，4 孔权重 ×2。上限 **5 孔**。
- **开孔符**（沿用现有道具）：触发器 +1 孔，不超过“稀有度上限 +1”（普通 3、魔法 4、稀有 5）；独特不能开。
- 孔不分颜色，任何石头都能插（手机上少一层规则）。

### 4.3 孔里的规则（推荐）
1. **每个触发器最多 2 颗技能石**，其余孔放辅助石。
2. 辅助石作用于**同一触发器里所有** `fit` 的技能石（看技能石标签，规则沿用现在的 fit）。
3. **两颗技能石时：同时施放**，但两颗都 **−30% 伤害**（“分流”），共用这个触发器的冷却。
   - 理由：一条件两技能很爽，但不能比两个触发器各放一颗更强；−30% 让它成为“孔多 / 栏位少”时的选择。
4. 没有技能石的触发器不生效（UI 显示“空”）。
5. 持续类技能（旋风斩、圣光束、喷火）被触发时只持续 2 秒。
6. 常驻触发器只能插常驻类技能石（瘟疫光环、游雷），这是唯一的硬限制。
7. 契合：技能石的推荐触发条件 = 这个触发器 → +20%，不契合不惩罚。

### 4.4 稀有度、阶、词条
- ilvl = 掉落层数；阶 T1（1+）/ T2（10+）/ T3（25+）/ T4（40+）/ T5（60+）。品质 q 0–20% 放大底子数值。
- 普通 0 词条，魔法 1–2，稀有 3–4，独特固定 + 特殊效果，第一版不做传奇。
- 词条池（T1 → T5）：触发率 +3–15%｜冷却 −4–20%｜间隔 −0.1–0.5 s｜被触发技能伤害 +8–40%｜范围 +5–20%｜额外施放 3–12%｜某标签伤害 +10–50%｜某系伤害 +10–45%｜技能暴击 +3–12%｜触发时回灯火 +0.2–1｜低血阈值 +3–10%｜**+1 辅助石等级**（稀有 / 独特才有）。
- 去掉旧版“相邻格触发”（没有格子了）。改由独特“回声”实现跨触发器。
- 硬封顶：触发率 ≤ 60%（攻击时）/ 70%（受击时）；冷却 ≥ 基础 50%；每 N 秒 ≥ 1.5 s；额外施放 ≤ 25%。

### 4.5 独特触发器（10 个）
| 名字 | 底子 / 孔 | 效果 |
|---|---|---|
| 回声 | 每 N 秒 4 s / 1 孔 | 同时触发**另一个**触发器（从左到右下一个），对方冷却照算 |
| 猎首 | 遇精英 / 3 | 击杀精英立即重置 |
| 血誓 | 低血 / 3 | 阈值 50%，耗 5% 当前生命，技能 +80% |
| 雷鸣之心 | 暴击 / 3 | 必定暴击，冷却 +50% |
| 尸山 | 击杀 / 4 | 叠层：每层 +3%，最多 20 层，5 秒不击杀清零 |
| 回旋之刃 | 攻击 / 3 | 每第 4 次普攻 100% 触发 |
| 不动 | 受击 / 4 | 站立 1 s 以上触发率 ×2 |
| 残影 | 冲刺 / 3 | 1 s 后在终点再触发一次 |
| 永夜灯 | 常驻 / 4 | 常驻范围 +40%，灯火燃烧 +10% |
| 双子 | 闪避 / 5 | 可以插 3 颗技能石，分流只 −15% |

## 5. 触发器栏（角色带几个）
- 开局 **1 个**，最多 **4 个**。两条路：
| 来源 | 栏位 | 说明 |
|---|---|---|
| 角色等级 | 等级 15 → 第 2 个；等级 35 → 第 3 个 | 每个人最终都有 3 个 |
| 装备 | 稀有装备词条“+1 触发器栏”（只出在主手 / 法阵，T4+，约 3% 出现）；或独特装备自带 | **装备最多 +1**，叠加不超过 |
- 总上限 4 = 等级 3 + 装备 1。等级 35 以前靠装备也能提前多 1 个（比如 Lv20 有 2 + 1 = 3）。
- 脱下给栏位的装备：多出来的触发器**暂停**（灰显，不掉、不退），重新穿上就恢复。
- 换装备不影响触发器本身。

## 6. 防止无限循环（不变）
1. 被触发的技能不能产生攻击时 / 暴击时 / 受击时 / 闪避时 / 冲刺时事件。
2. 被触发技能的击杀可以触发击杀时，但击杀时触发器自己的击杀不行，只传 1 层。
3. 回声：被回声带动的触发器**不能**再带动别的。
4. 每个触发器有冷却；每颗技能石最快 0.25 s 一次；全局每秒最多 12 次。
5. 触发**不耗灯火**（霜环、寒魄、陨火也不耗）。

## 7. 19 颗技能石的推荐条件和示例
| 系 | 技能石（推荐条件） |
|---|---|
| 物理 | 旋风斩（攻击 / 冲刺）、突刺（攻击）、冲撞（冲刺）、骨矢（每 N 秒）、飞镰（攻击）、散射（暴击） |
| 闪电 | 雷符（暴击）、游雷（常驻 / 击杀） |
| 火焰 | 火油罐（击杀）、陨火（每 N 秒 / 精英）、陷阱（受击 / 冲刺） |
| 瘟疫 | 疫星（击杀）、瘟疫光环（常驻） |
| 圣光 | 圣光束（精英）、新星（受击）、圣盾掷（闪避） |
| 寒霜 | 霜环（受击 / 低血）、寒魄球（每 N 秒） |
- 共鸣：见 system-v2 §6.2（技能石本源元素 = 主附加元素时每颗 +12%，最多 3 颗）。
- 示例「旋风近战」（4 栏满）：
  - 攻击时（稀有 4 孔）：旋风斩 + 范围 + 攻速 + 余震
  - 击杀时（尸山 4 孔）：火油罐 + 范围 + 热能
  - 受击时（魔法 2 孔）：霜环 + 范围
  - 冲刺时（普通 2 孔）：冲撞 + 近战

## 8. 装备上的触发相关
- 只保留：主手攻速；副手 / 头冠“触发技能伤害 +4–12%”；主手 / 法阵稀有“+1 触发器栏”。
- 按种类的触发率、冷却词条都只在触发器上。

## 9. 装备孔和属性石（沿用上一版）
- 孔数：主手 / 盾牌 / 头冠 1 / 2 / 3（普通 / 魔法 / 稀有），副手 / 遁靴 1 / 1 / 2，法阵 0；独特固定。开孔符也能用在装备上。
- 属性石的种类和数值见 gear-v2.md §7。
- 5 阶，3 合 1；拆卸免费；同件装备同种只生效一颗；没有触发类属性石。
- 属性石、辅助石、技能石三套孔完全分开：触发器的孔不收属性石，装备的孔不收技能石和辅助石。

## 10. 掉落、制作、背包
- 触发器：普通怪 0.3%（普通 / 魔法）、精英 4%、首领必掉 1 个（25% 再 1 个，偏好 2 种底子 ×4，手册公开）、天梯每 5 层 1 个（每 20 层保底稀有）。
- 辅助石：从现有辅助符文掉落表改名沿用；等级经验照旧（插在触发器里也吃击杀经验）。
- 制作（铁砧）：重铸（重随词条，稀有度和孔数不变）｜改一条（碎片，最多 3 次）｜升阶（同底同稀有 + 碎片）｜打磨 q｜**开孔**（开孔符）｜**重随孔数**（新：花 1 个“重铸符”，只在稀有度范围内重随）。
- 分解：普通 1 碎片、魔法 2、稀有 5、独特 15；分解时孔里的石头自动退回背包。
- 背包：触发器页签 60 格；默认自动分解普通、低 15 层以上的魔法；普通同底同阶同孔数叠放。

## 11. 手机 UI（见 mockups-v5/index.html）
只有一个主界面，没有总览页/详情页/确认弹窗：
- 顶部：触发器栏 1–4 个大图标（条件图标 + 稀有度底色）。未解锁只显示 🔒 + "Lv15"/"Lv35"。点一下 = 选中。
- 中部：选中触发器的孔位一排（技能石 = 方形橙底，辅助石 = 圆形蓝底，空孔 = 虚线 ＋）。只显示一个战力数字。
- 辅助是否生效：生效的辅助石和技能石之间连线发光；不生效则变灰，不出文字。
- 规则（分流 −30%、标签匹配、条件 +20% 等）全部收进右上角小 ⓘ。
- 底部：宝石背包条（全部/技能/辅助 筛选）+ "触发器 N" 按钮进触发器背包。
- 操作：点宝石 → 可放的空孔绿色高亮、不能放的宝石变暗 → 点孔放入；或再点一次宝石 = 自动放进第一个合适空孔。点已镶嵌宝石 = 直接取回背包。全程无确认弹窗（取回不消耗）。
- 掉落新触发器：弹一个对比卡（当前 vs 新：图标、孔数圆点、战力 ▲/▼ 百分比），按钮只有 分解 / 替换；替换时宝石自动搬到新触发器，放不下的回背包。
- 分解/开孔符等制作操作放在长按触发器图标的小菜单里。

- 底部导航：装备 / 触发器 / **战斗（中间）** / 天赋 / 铁砧；天梯从战斗页进入，设置/手册在左上 ⚙。每个页签 = 自制大图标 + 两字标签；选中项放大、上浮、黄色 3D 按钮，其余去饱和；有新东西显示红点（新装备、未用天赋点、新触发器）；未解锁的显示 🔒 + 解锁条件，点一下 toast 提示。

## 13. 平衡与模拟
- 目标：4 栏满（每栏 3–4 孔、稀有 T5）总输出 ≈ 现在单石满符文的 1.7 倍；怪物血量整体 ×1.4。
- 开局（1 栏，开局送的那个）输出 = 现在的 0.95–1.0 倍。
- 一栏两技能（分流 −30%）应比“两栏各一颗”低 15–25%。
- 模拟器：普攻 4 类 + 事件流 + 冷却 + 全局上限 + 孔里辅助石；跑示例搭配 × 天梯 1–60 / 推关 1–80：触发 p99 ≤ 10 次/秒；单个触发器 ≤ 45% 输出；回声搭配不超过不带的 1.3 倍；与现有天梯基线差 ±10%。
- 掉落经济：60 层一轮 6–10 个稀有、0–1 独特，开自动分解背包 ≤ 25 格。
