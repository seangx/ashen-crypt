# 设计规格：触发器槽位（技能石 → 触发槽）

> 状态：设计稿，未实现。基于 spec-skill-gems.md（单技能石 + 支援符文）。参考 Hero Siege 遗物（击杀时 / 攻击时 / 施放时 / 受击时 / 环绕 / 随从）。

## 1. 概念
- 游戏没有主动技能，全部自动施放。现在只有一颗技能石在“技能格”里持续释放。
- 改成：**装备部位提供“触发槽”，每个槽自带一个触发条件**；技能石放进槽，条件满足就施放一次。
- 主技能仍是一颗“主攻石”（自动攻击，按攻速循环），其余技能石都靠触发。玩法从“选一个技能”变成“搭一套连锁反应”。

## 2. 触发条件（第一版 8 种）
| id | 名称 | 条件 | 默认触发率 | 内置冷却 ICD |
|---|---|---|---|---|
| onHit | 攻击时 | 主攻石命中 | 25% | 0.5 秒 |
| onCrit | 暴击时 | 主攻石暴击 | 100% | 1 秒 |
| onKill | 击杀时 | 任意来源击杀 | 100% | 0.8 秒 |
| onStruck | 受击时 | 受到命中 | 30% | 1 秒 |
| onLow | 低血时 | 生命 < 35%，进入时触发，之后每 4 秒 | 100% | 4 秒 |
| onDodge | 闪避后 | 闪避 / 格挡成功 | 100% | 1.5 秒 |
| timer | 每 N 秒 | 固定节拍，N 由部位决定（3–6 秒） | 100% | = N |
| orbit | 常驻 | 环绕 / 光环 / 随从类，持续存在，不需要触发 | — | — |

## 3. 槽从哪来
| 部位 | 槽 | 固定条件 | 备注 |
|---|---|---|---|
| 主手 | 主攻格 ×1 | 自动攻击 | 必有，就是现在的技能格 |
| 头盔 | 1 | timer（4 秒） | |
| 胸甲 | 1 | onStruck | |
| 手套 | 1 | onHit | |
| 靴子 | 1 | onDodge | |
| 项链 | 1 | onKill | |
| 戒指 ×2 | 各 1，**条件随机词条** | 从 8 种里随机 | 刷装备的目标之一 |
| 副手 | 不给槽，保持“支援” | — | 规则照旧 |
- **解锁**：开局只有主攻格 + 手套槽；天梯 5 层开项链，10 层开头盔 / 胸甲，20 层开靴子，30 层开戒指。最多 8 格（1 主攻 + 7 触发）。
- 槽属于**部位**而不是装备实例：换装备不丢槽，石头留在槽里。戒指例外，条件跟着戒指走（换戒指时条件变化，石头保留）。
- 传奇 / 独特装备可以改槽，例如“该槽 onKill 触发率 +50%”或“把条件改成 onCrit”。

## 4. 支援符文挂哪
- **挂在石头上（维持现状）**：符文插在技能石自带的 1–5 个槽里，`fit` 检查石头的标签。石头换槽，符文跟着走。
- 不做“按槽挂符文”：会出现两套插槽，UI 也会翻倍。
- 新增一类“触发符文”（只能插在被触发的石头上）：触发率 +x%、ICD −x%、“触发时额外 +1 次”（ICD ×2）。

## 5. 防止无限循环
1. **触发的技能不能再触发别的槽**（标记 `src: 'trigger'`）。只有主攻石、受击、计时、低血这类“源头事件”才能触发。onKill 例外：被触发技能造成的击杀可以触发 onKill，但 onKill 槽本身的击杀不行。
2. 每个槽有自己的 ICD（见表），每颗石头还有全局下限 0.25 秒。
3. **能量消耗**：右边紫色能量球就是资源。被触发施放每次花 `cost = 4 + 石头等级 × 0.3`，能量不够就跳过。主攻石不耗能量。
4. 每秒最多触发 12 次，超出的丢弃，防止大量怪物时卡帧。

## 6. 19 颗石头和六系的对应
- 每颗石头加字段 `role`：`main` 适合做主攻、`proc` 适合被触发、`orbit` 常驻。可以混放，但放错位置有 −30% 伤害（提示“不适合”）。
| role | 石头 |
|---|---|
| main（持续 / 高频） | 旋风斩、突刺、骨矢、雷符、飞镰、散射、圣光束、喷火 |
| proc（爆发 / 一次性） | 冲撞、火油罐、疫星、新星、霜环、陨火、寒魄球、陷阱、圣盾掷 |
| orbit（常驻） | 瘟疫光环、游雷（作为常驻随从） |
- 六系（kin 动能 / ele 电 / exp 爆炸 / nuc 核疫 / pla 等离子圣光 / cold 冰）不改。新增**同系共鸣**：主攻石和触发石同系时，触发石伤害 +15%，每多一颗同系触发石主攻再 +5%（上限 +20%）。这样鼓励按系配，但不强制。
- 推荐起手示例：旋风斩（主）+ 手套 onHit 冲撞；骨矢（主）+ 项链 onKill 火油罐；圣光束（主）+ 胸甲 onStruck 新星 + 头盔 timer 圣盾掷。

## 7. 与独特装备 / 天赋 / 武器类别的关系
- **武器类别**：对口加成只作用于主攻石；被触发的石头吃 50%。
- **大天赋**：条件从“技能石有 X 标签”改成“**任意已装备**的石头有 X 标签”。效果只作用于带标签的那颗石头。
- **独特装备**：生效条件由“技能石”改为“对应标签的任意石头”。新增 4–6 件触发主题独特装备（例如“击杀时触发的技能必定暴击”“受击触发不耗能量”）放在第二批做。
- 回响圣盾等特定石头的天赋保持指向具体石头。

## 9. 存档迁移（S.gemV = 2）
- 现有技能石 → 主攻格，符文不动。
- 背包里的其他技能石保持原样，按天梯进度自动解锁对应的槽，槽留空。
- 戒指老存档：没有条件词条的，补一条随机条件（种子 = 物品 id，保证确定）。
- 迁移可重复执行，用 gemV 版本号保护。

## 10. 平衡与模拟计划
- 目标：满配（1 主 + 7 触发）的总 DPS 约等于现在单石的 **1.6–1.8 倍**；同时把怪物血量曲线整体 ×1.5，让第 1–20 层体感不变，后期留出成长空间。
- 单颗被触发石头的期望贡献控制在主攻石的 10–20%。
- 模拟器 `design/sim`：加入触发事件流（命中 / 暴击 / 击杀 / 受击 / 闪避 / 计时）和能量模型。跑 6 系 × 3 套推荐搭配 × 天梯 1–60 层，检查：
  - 每秒触发次数中位数和 p99（目标 p99 < 10）；
  - 能量是否长期见底（见底时间 < 20%）；
  - 和现有天梯结果的差距（圣盾掷 42 层等基线），在 ±10% 以内再进入实现。
- 手机性能：怪物 200 只时，帧时间增加不超过 1 ms。

## 11. 待 Sean 确认的问题
1. **主攻石还要不要保留？** 推荐：**保留**。没有主攻，onHit / onCrit 没有源头，手感会变成纯被动挂机。
2. **槽的条件是部位固定，还是全部随机词条？** 推荐：**部位固定 + 戒指随机**。容易上手，又给刷装备留了目标。
3. **触发是否消耗能量？** 推荐：**消耗**，这是最直接的防爆炸手段，也让能量相关词条和天赋有意义。另一种做法是只靠 ICD，更简单但上限难控。
