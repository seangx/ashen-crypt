## 2. 分配原则
1. **伤害在手上，生存在身上，形态在石头上。**
   - 技能形态类词条（投射物数、弹射、派生、叠层上限、延迟、投射物速度 / 持续 / 减速）**全部从装备上拿掉**，交给辅助石。
   - 装备只给数值。
2. **攻击三件套分散**：
   - 基础暴击率：副手（主）、头冠（小）。
   - 暴击伤害：副手（主）、头冠（小）。
   - 攻速：主手（基础攻速）、副手（攻速提高）。攻速只决定出手次数（system-v2 §4.1）。
3. **每个部位都有通用填充**：生命、生命提高、护甲、魂力。权重合计约占该部位词条池的 30%，所以一件 4 条词条的装备平均有 1 条“不太合适”。
4. **元素只留两处**：攻击端只有“附加 X 伤害”（6 族），防御端只有单抗（6 族）和全抗。基础伤害提高、穿抗、异常效果都不分元素。

## 5. 副手
- 删除隐性“主手技能总增 70–110%”。副手是普通的攻击装备，不戴也能玩。
- 五种副手共用 §4 的副手词条池，靠隐性区分。隐性强度约等于一条中档词条：

| 副手 | 隐性（品质 0 → 10） |
|---|---|
| 骨羽箭袋 | 攻击速度提高 8–15% |
| 幽魂法源 | 附加伤害：武器基础伤害的 15–30%，元素跟主附加元素 |
| 焚骨香炉 | 范围提高 12–25% |
| 骸铃图腾 | 触发技能伤害提高 10–20% |
| 冥火提灯 | 基础暴击率 +3–5% |

- 词条池权重目标：攻击类约 65%，填充类约 35%。
- 一件副手大概长什么样：
  - **普通掉落（物品等级 30，稀有）**：基础暴击 +3%、暴击伤害 +35%、附加 8–15 火焰伤害、生命 +40。三条攻击，一条填充。
  - **好的（物品等级 70）**：基础暴击 +8%、暴击伤害 +60%、技能伤害总增 15%、附加伤害高档。四条全中，值得用铁砧补。

## 6. 独特（参考暗黑 3 传奇装备）
- **组成**：独特规则（数值在区间内随机）+ 1–2 条固定词条 + **2–3 条随机词条**（从该部位 §4 的池里掷，前后缀不限，档位按物品等级）。
  - 现在 24 件没有固定词条的独特，各补 1 条，从该部位招牌里选一条和规则最搭的。
  - 随机词条数：普通掉落 2 条；天梯宝箱和 Boss 宝箱 3 条。
- **打造**：随机词条可以用铁砧“洗数值”和“改一条”（每件最多 2 次）。固定词条和规则只能用希望符重掷数值。
- **熔铸传奇**（天梯 40）：独特 + 稀有，在上面的基础上再带上稀有装备的词条。
- **效果**：同一件独特有好坏之分，“刷一件词条好的同款”是毕业阶段的追求。装备对比卡要给随机词条一个评分（按该部位最高档的百分比）。
- **代码**：`newUnique`（src/30_items.js:99）里 `newItem(..., 0)` 改成按 §4 的池再掷 2–3 条；`uniques.json` 每件补 `fixed` 和 `randN`（默认 2）。
- 现有独特里用到已删除词条或机制（闪避、抗性上限、叠层上限等）的，规则按本文改写：闪避类改成格挡版本，形态类保留在规则里（独特规则可以改形态，词条不行）。
- 新增独特：元素专属的见 system-v2 §6.5，灯火相关的见 lamp-v2 §5.5。

## 8. 打造和追求（不变的部分，只列要点）
- 铁砧：碎片加词条、升一档；高级铁砧（第 20 层）洗数值、移除、改一条。
- 溢彩：有 5 档以上的词条族，最高两档只能掉落，铁砧打不出来。
- 誓约（天梯 30）：每件一条“一正一负”。
- 熔铸（天梯 40）：独特 + 稀有 → 传奇。
- 毕业装 = 对的独特规则 + 溢彩词条 + 随机词条掷得好，最后插满 5 阶属性石。
