## 1. 营地主页
- 营地是一个场景，不是菜单页：地窖题材的空地，中间是地窖入口（台阶 + 火盆），周围摆着几个设施。角色在营地里站着或闲逛。
- 一趟灯火下行结束后回到营地，显示结算小结；挂机时停留 `camp.idleStay` = 4 秒后自动出发。手动模式下点地窖入口出发。
- 设施和对应窗口（点设施打开原有窗口，原来的底栏按钮保留作为快捷方式）：

| 设施 | 窗口 | 什么时候出现 |
|---|---|---|
| 地窖入口 | 出发 / 选层 / 锁层 | 一开始就有 |
| 储物箱 | 背包和装备 | 一开始就有 |
| 天赋石像 | 天赋树 | 一开始就有 |
| 铁砧 | 做装 | unlocks.craft |
| 分解祭坛 | 分解规则（见下） | 和铁砧一起 |
| 符文台 | 符文 / 喂养 | 一开始就有，喂养按 unlocks.feed |
| 墓图台 | 墓图 / 命盘 | unlocks.atlas |
| 天梯石碑 | 天梯 | unlocks.ladder |

- 没解锁的设施不画，或画成被碎石盖住的样子。新解锁时在营地里亮一下，并提示一次。
- 天梯：从天梯石碑出发，打完回营地。

## 2. 分解祭坛（自动分解）
- 每次回营地，先按规则把这一趟带回的装备自动分解成词条碎片（沿用 craft.shatter 的产出规则），再显示小结：“分解 N 件，得到碎片 M 个”。
- 规则（存档 S.salvage，窗口里可调）：
  - 按稀有度：普通 / 魔法 / 稀有，各一个开关。默认普通和魔法开，稀有关。
  - 物品等级低于“当前最深层 − `camp.salvageIlvlBack`(10)”的装备全部分解。开关默认开。
  - 保留规则：带有“收藏词条”的装备不分解。收藏词条是一个词条族列表，玩家在窗口里勾选；默认取当前主武器流派的做装词条（旋风斩就是 whirl.craftPref 的前 6 个）。
  - 独特装备、印记、符文、墓图永远不自动分解。
- 窗口里有“现在分解背包”按钮，按同样的规则手动跑一次。
- sim：--craft auto 时启用默认规则。

## 3. 层内紧急撤回
- 在最深层附近（层 ≥ prevMax − 1），血量（按护甲比例）低于 `soul.returnHpNow` = 20% 时，立刻平安返回，不等打完 Boss。和现有撤回一样：东西全带走，推层不算失败。
- 小结写“紧急撤回 · 第 N 层”。
