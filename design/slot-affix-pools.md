# 灰烬地窖 · 部位词条池重分配（副手主攻，参考暗黑 3）

2026-10-26 · 设计线程 · 状态：**方案稿，未开工**
基于 main 105540b。现状词条池是在游戏里实际导出的（每个部位“能掷出来”的词条，已排除 off 和权重 0）。

用户：
- 01:52：“我昨天玩了玩，感觉副手的设计好硬”。
- 02:36：“感觉副手应该给暴击爆伤基础伤害之类的攻击词缀，池子里应该还有些生命之类不太合适的词缀，参考下暗黑 3 的词缀池子分配”。

## 1. 暗黑 3 是怎么分的（凭记忆整理，细节以游戏为准）
1. **每个部位有自己的“招牌”词条**，只在少数部位出现，所以玩家要凑齐整套：
   - 武器：武器伤害、攻速。
   - 副手（法源、咒物、箭袋）：暴击率、伤害范围（附加伤害）、元素或技能伤害。箭袋自带攻速。
   - 手套、戒指、项链：暴击率、暴击伤害、攻速。
   - 头盔：暴击率。
   - 鞋：移速。
   - 护腕：元素伤害。
   - 肩、腰、披风：防御。
2. **所有部位都能出“通用词条”**：主属性、体能 / 生命%、全抗、护甲。对某个流派来说，它们常常是“不太合适的”那一条。所以同一个底子，词条好坏差别很大，这正是刷的动力。
3. **攻击的三件套（暴击率、暴击伤害、攻速）分散在好几个部位**，每个部位贡献一部分，没有哪一件是“戴上翻倍”的。

## 2. 现在的问题

### 2.1 副手
| 问题 | 说明 |
|---|---|
| 隐性固定“主手技能总增 70–110%” | 五种副手都有，戴上 ×1.7–2.1，不戴伤害砍半。副手是必戴的，种类之间的差别只是附带的那一两条。 |
| 词条池是“技能机制”，不是“攻击” | 18 条里有 11 条是叠层、投射物数、弹射、范围、投射物速度 / 持续 / 减速、延迟、派生，和技能石上的辅助符文重复。 |
| 没有暴击率、没有附加伤害 | 用户要的“暴击、爆伤、基础伤害”，现在只有暴击伤害一条。 |
| 没有填充词条 | 没有生命、护甲，掉一件副手基本都“全是有用的”，没什么可比。 |

### 2.2 其他部位
| 部位 | 现在几条 | 问题 |
|---|---|---|
| 主手 | 28 | 正常：伤害、基础攻速、标签伤害。缺少通用填充（生命）。 |
| 盾牌 | 29 | 主要是防御，正常。【持续施放】叠层上限放在盾上不合适。 |
| 头冠 | 31 | 太杂。机制、标签伤害、暴击、爆伤、防御、灯火都有，什么都能出，所以什么都不稀罕。 |
| 遁靴 | 18 | 攻击速度、持续时间放在靴子上不合适。冲刺槽的说明显示成“+undefined”（显示 bug）。 |
| 法阵 | 42 | 抗性、异常、穿抗、控场，像暗黑 3 的项链，方向对。攻击速度放在这里不合适。 |

### 2.3 暴击本身太弱
- 暴击率 = 武器基础暴击（大多 5%）× (1 + 暴击率提高%)，暴击倍率基础 1.5。
- 头冠满档“提高 55%”也只是 5% → 7.75%，暴击这条线几乎不存在。
- 所以要有暗黑 3 那样的**基础暴击率（直接加百分点）**，暴击才成为一个能追的方向。

## 3. 新的分配原则
1. **伤害在手上，形态在头上，生存在身上。**
   - 主手：基础伤害、攻速。
   - 副手：暴击、附加伤害、技能伤害。
   - 头冠：技能形态（投射物数、弹射、范围、持续时间、派生等）和暴击率提高。
   - 盾牌、遁靴、法阵：防御、走位、抗性和异常。
2. **攻击三件套分散**：
   - 基础暴击率：副手（主）、头冠（小）。
   - 暴击伤害：副手（主）、头冠（小）。
   - 攻速：主手（基础攻速）、副手（技能攻速）。
3. **每个部位都有通用填充**：生命、生命提高、护甲、魂力、元素抗性。权重合计占该部位词条池约 30–35%。也就是说，一件 4 条词条的装备平均有 1 条“不太合适”的。

## 4. 副手（重点）

### 4.1 隐性效果：去掉固定的 ×2，改成小而有特色的一条
| 副手 | 现在 | 改成（品质 0 → 10） |
|---|---|---|
| 骨羽箭袋 | 总增 70–110% + 投射物 +1–2 + 弹射 +1–3 + 投射物伤害 25–70% | 技能攻速总增 8–15%；主技能带【投射物】时投射物 +1 |
| 幽魂法源 | 总增 70–110% + 伤害提高 20–60% + 额外获得元素伤害 0–10% | 附加伤害 +15–30%（按武器基础伤害的百分比，元素跟技能石走） |
| 焚骨香炉 | 总增 70–110% + 范围 15–40% + 范围伤害 30–80% | 范围 +12–25% |
| 骸铃图腾 | 总增 70–110% + 攻速总增 15–35% | 技能攻速总增 10–20% |
| 冥火提灯 | 总增 70–110% + 暴击率提高 + 爆伤 + 异常 | 基础暴击率 +3–5% |

- 去掉箭袋“只有投射物技能才能出词条”的限制。五种副手共用同一个词条池，靠隐性区分。
- 隐性的强度大约相当于一条中档词条，不再是“必戴的乘区”。

**从副手池移除**：
- 【持续施放】叠层上限、投射物 +1、弹射 +1、范围提高、投射物速度、投射物持续时间、投射物减速、延迟伤害、派生 +1。这些交给头冠和辅助符文。
- 副手专属的“投射物 +1”（`OffExtraProj`）：并进箭袋隐性。
- `mechanics.offhand.weaponAffixes` 关掉，武器非局部词条不再自动加到副手。

**权重目标**：攻击类约 65%，填充类约 35%。

### 4.3 一件副手大概长什么样
- **普通掉落（物品等级 30，稀有）**：基础暴击 +3%、暴击伤害 +35%、附加 8–15 伤害、生命 +40。三条攻击，一条填充。
- **好的（物品等级 70）**：基础暴击 +8%、暴击伤害 +60%、主技能伤害总增 15%、附加伤害高档。四条全中，值得用铁砧去补。

## 6. 强度迁移
- 去掉副手隐性总增 70–110%，平均少了约 ×1.9。
- **补偿**：所有技能石倍率 ×1.5（`mechanics.gems` 的 mul）。剩下的差距由新副手词条补上：好副手大约 ×1.3–1.5，主要来自暴击。
- **验收**（`tools/bis.js`，物品等级 30 / 70 / 100，六个流派）：
  - 毕业装备 DPS 和现在相差 ±10% 以内。
  - 不戴副手时，DPS 是戴好副手的 65–80%（现在是约 50%）。
  - 暴击流（提灯 + 爆伤）和非暴击流（法源 + 附加伤害）在物品等级 70 时相差 ±15% 以内。
- **老存档**：已有的副手重掷隐性（按新表、保留品质）。词条里已被移除的那些，换成同前后缀的一条新池词条（同档位比例），并弹出一次说明。

## 7. 待定
1. 基础暴击率的上限：暗黑 3 副手最多 10%。我们只有六个部位，副手 10% + 头冠 4% + 武器 5% = 19%，配“提高”后在 30% 左右。是否要更高？建议先这样，模拟后再看暴击流够不够强。
2. 附加伤害按“武器同档 60%”是否合适：副手如果也出武器级的平加，就是第二把武器，所以先打六折。
3. 要不要再加暗黑 3 那种“冷却缩减 / 资源消耗降低”：我们对应的是魂火消耗降低，现在在盾、头冠、遁靴、法阵都有。建议副手不加，保持“副手 = 攻击”。
