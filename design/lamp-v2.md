# 灰烬地窖 · 灯火 v2（参与构筑、看得见）

2026-10-27 · 设计线程 · 状态：**方案稿，未开工**
基于 main 5b07dac，接 design/system-v2.md（触发器体系）。
用户 06:38：“灯火系统也需要再设计一下，参与 bd 构筑，现在玩起来完全没存在感”。

## 1. 现在为什么没存在感
（数值见 data/mechanics.json `soul`）
- 灯火只是一个倒计时：上限 100 + 魂力 × 5，每秒燃烧 2 + 层数 × 0.1，击杀回 1 / 8 / 30，归零就安全回营地。
- 玩家对它能做的事只有两件：堆“魂火回复 / 消耗降低”让它烧得慢；看着它见底。灯火是满是空，打起来没有任何区别。
- 触发器体系里技能已经不耗灯火（system-v2 §5），连唯一的“花灯火”也没了。
- 画面上只是左下角一个紫色瓶子。

## 2. 目标
1. **看得见**：灯火多少，直接决定屏幕有多亮。
2. **有状态**：灯火高和低时，打法和收益不一样。
3. **能构筑**：有专门围绕灯火的触发器、属性石、天赋、独特。“满灯流”和“残灯流”是两条真的流派方向，不只是“续航好一点”。
4. **有取舍**：花灯火换强度 = 这一趟走得更短。挂机游戏需要这种一个旋钮的决定。

## 3. 看得见：灯火 = 光照半径
- 地窖本身是黑的，角色身边有一圈光。**光照半径跟着灯火走**：满灯约 180 像素（差不多半个屏幕），空灯约 50 像素。
- 光圈外面不是全黑，是暗色加雾，怪物只显示轮廓和眼睛。光圈内正常显示。
- 已有的光照图（V31 的 colored light map）直接用这个半径，不是新系统。
- 灯火瓶旁边显示当前**灯态图标**（§4），切换时瓶子闪一下，并在角色头顶飘一行字（“残灯”）。

光照只影响画面和下面写的几条机制，**不限制攻击距离**：远程流派不会因为灯暗而打不到人。

## 4. 有状态：三档灯态

| 灯态 | 灯火 | 效果 |
|---|---|---|
| **明灯** | ≥ 70% | 光照大；护盾每秒回复 +30%；拾取范围 +50% |
| **昏灯** | 30–70% | 中性 |
| **残灯** | < 30% | 光照小；**伤害总增 +25%**、基础暴击率 +5%；**受到的伤害 +20%**；掉落稀有度 +25% |

- 残灯是“冒险换收益”：更痛、更脆、掉得更好。灯快灭的最后几十秒，正好是一趟的高潮。
- 阈值和数值都放在数据里：`soul.states: [{id:'bright', min:0.7, ...}, {id:'dim', ...}, {id:'ember', max:0.3, ...}]`。
- 这三档对所有人都生效。所以即使不专门构筑，玩家也能感觉到“灯快灭了，打得更狠，也更危险”。

## 5. 能构筑：灯火进入触发器、属性石、天赋、独特

### 5.1 触发器（新底子 2 个，新词条 1 条）
| 新底子 | 条件 | 基础 | 内置冷却 |
|---|---|---|---|
| **明灯时** | 处于明灯，每 3 秒 | 100% | 3 s |
| **残灯时** | 处于残灯，每次普攻命中 | 35% | 0.8 s |

| 新词条（触发器） | 效果 | 档位 T1 → T5 |
|---|---|---|
| **燃灯** | 每次触发消耗灯火，本次技能伤害提高 | 消耗 1 → 3；伤害 +40% → +120% |

- 燃灯是“花灯火换伤害”的主要开关。只出在稀有和独特触发器上。
- 触发器默认仍然不耗灯火（system-v2 §5 不变），燃灯是玩家主动选的。

### 5.2 回灯火的来源（让续航变成构筑方向）
现在只有击杀回灯火。新增几个来源，每个流派都能找到适合自己的：

| 来源 | 在哪 | 适合谁 |
|---|---|---|
| 击杀回灯火（已有） | 灯芯石（武器类）、遁靴词条、天赋 | 清怪快的流派 |
| **暴击回灯火**：每次暴击 +0.2（每秒最多 3） | 副手词条、鹰眼石（新档） | 暴击流 |
| **受击回灯火**：被命中时 +1（每秒最多 2） | 盾牌词条 | 坦克流 |
| **触发回灯火**：触发时 +0.2–1（spec-trigger-slots 已有这条触发器词条） | 触发器 | 触发器多的流派 |
| **灯油罐**：每层地图随机 2–4 个可打碎的罐子，+8% 灯火 | 地图物件 | 所有人（走位有理由） |

### 5.3 灯火当护盾：一个防御方向
- **天赋大天赋“以灯代血”**：受到的伤害有 30% 先扣灯火（1 点灯火抵 4 点伤害）。代价：生命上限 −20%。
- 这样灯火同时是“时间”和“血条”，坦克流会想要高灯火上限和受击回灯火。

### 5.4 天赋树灯火区（现在几乎是空的）
小节点：灯火上限、燃烧降低、各种回灯火、灯态效果提高。

大天赋（都是通用的，不按技能、不按元素）：

| 大天赋 | 效果 | 代价 |
|---|---|---|
| **将熄之焰** | 残灯阈值 30% → 50%；残灯效果 ×1.5 | 永远进不了明灯 |
| **长明** | 明灯阈值 70% → 50%；明灯时燃烧 −50% | 残灯时伤害总降 20%（残灯的加成没了） |
| **燃魂** | 所有触发器都带燃灯（按 T1 档） | 灯火上限 −30% |
| **以灯代血** | 见 §5.3 | 生命上限 −20% |

### 5.5 独特
| 独特 | 部位 | 规则 |
|---|---|---|
| 永夜灯（已有触发器独特） | 触发器 · 常驻 | 保留；补一条：残灯时常驻技能范围再 +40% |
| 回光之冠 | 头冠 | 灯火第一次降到 10% 时回满到 60%，每趟一次 |
| 噬光之刃 | 主手 | 普攻命中吸取 0.3 灯火；光照半径固定为最小 |
| 灯奴之链 | 法阵 | 灯态固定为昏灯；灯火燃烧 −40% |
| 黑暗行者 | 遁靴 | 光圈外的敌人受到的伤害 +30%（配合残灯小光圈：只打黑暗里的怪） |

### 5.6 怪物
- 精英新词缀 **噬光**：命中时吸走 3 灯火。让灯火在战斗中也会被打掉，不只是按时间烧。
- 暗处的怪：光圈外的普通怪移速 +15%（营造“从黑暗里扑过来”的感觉），不加伤害。

## 6. 天梯里的灯火
- 现在天梯里灯火自然回复，不燃烧，所以灯态基本恒为明灯，灯火流派在天梯没用武之地。
- **改成**：天梯开局灯火 100%，按天梯层数燃烧（同推层公式），击杀照常回复。
- 灯火归零时**不结束**天梯（天梯本来就是 240 秒限时），而是进入**熄灭**：受到伤害 +50%，没有残灯的伤害加成。
- 这样天梯里也要管理灯火：残灯流想停在 5–30% 之间，长明流想保持在高位。

## 7. 和 system-v2 的关系
- **魂力**仍是唯一的主属性，管灯火上限、护盾、冲刺回复（不变）。
- **灯芯石**（system-v2 §7.2）：武器类 = 击杀回灯火，防具类 = 燃烧降低（不变）；鹰眼石新增“暴击回灯火”档。
- **成长四段**：残灯 / 长明的大天赋在“成型”阶段出现，燃灯词条在“精修”阶段（稀有触发器）。
- **解锁**：灯态在开局就生效（它是核心手感）；灯油罐在第 2 层开始出现；天梯的灯火规则随天梯解锁。

## 8. 数据和实现要点
- `soul.states`（三档）、`soul.lightR: [50, 180]`、`soul.ladderBurn: true`、`soul.extinguish: { takenMore: 50 }`。
- 新 stat：`lampOnCrit`、`lampOnHit`（受击）、`lampShield`（以灯代血比例）、`stateMul`（灯态效果提高）、`lightOutMore`（黑暗行者）。
- 触发器：新底子 `bright` / `ember`，新词条 `burnLamp`。
- 光照：现有光照图的玩家光源半径读 `lightR`，按灯火比例插值；光圈外的怪改成轮廓 + 眼睛（复用受击闪白的着色器反过来做暗化）。
- 模拟：`tools/sim.js` 输出每趟“明 / 昏 / 残灯”的时间占比和残灯里的击杀占比。

## 9. 验收
1. 不做任何灯火构筑时：一趟里大约 40% 时间明灯、40% 昏灯、20% 残灯；残灯阶段的掉落占全趟 30% 左右。
2. 残灯流（将熄之焰 + 燃灯 + 暴击回灯火）和长明流（长明 + 受击回灯火 + 以灯代血）在 `bis.js` 物品等级 70 时，推层深度相差 ±15%，玩法明显不同。
3. 截图对比：满灯和残灯的画面一眼能分出来。
