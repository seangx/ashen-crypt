# 技能变体 v1（2026-11-12）

> 背景：用户定下当前优先级是“丰富玩法和 BD，以及 BD 的丰富度、爽度和差异化”，平衡和 UI 往后放。
> 判断：现在选好一颗技能石后，剩下的只是堆数值，同一颗技能石只有一种打法。所以先做技能变体（类似暗黑 3 的技能符文），让 24 颗输出技能石各自多出 3 种打法。

## 1. 规则

- 每颗输出技能石除了原版还有 3 个变体，技能石到 4 / 8 / 12 级依次解锁；升到解锁等级时，拾取记录里提示“解锁变体”。
- 在魂龛里点技能石 → “变体”，营地或层间整备时随时换，不花钱；战斗中不能换。
- 变体存在技能石物品上（字段 v），技能石换到别的魂龛也带着。
- 变体分三类：
  1. **换元素**：主效果（破甲 / 灼烧 / 感电 / 疫病 / 冰缓 / 审判）和能走的套装一起换。比如旋风斩·霜旋能走凛冬套。
  2. **加机制**：内置一颗符文（回旋、多重投射、分裂、穿透、击退、斩杀），按技能石等级算，不占孔。
  3. **改打法**：流星雨（一次落一片小陨石）、命中留地面（火地 / 冰地 / 毒地）、牵引（把怪拉过来）、余震（再结算一次）、巨陨（更大更慢更重）。

## 3. 实现

- 数据：game/data/variants.json。启动时每个变体合成一份完整定义，以“原 id#变体 id”登记进 GEM_BY（不进 GEMS，所以不会单独掉落）；按 id 查定义的地方（套装判定、范围判定）自动认得变体。
- 入口：gid(g) / gdef(g)（10_data.js）；gemBase、gemTags、套装的 mainSet / mainSets 改用它们。
- 变体效果：内置符文和变体自己的 fx 作为虚拟符文，排在形态符文后面（40_stats.js activeRunes）。新开关：starfall、pull、vGround（命中留地面，同一技能有冷却）、delayAdd。
- 顺带修好：圣盾掷以前拿不到套装的“技能伤害总增”（它的定义里没有记技能石 id）；陨火落地的火地在非火元素时改按元素颜色画。
- 自检：tools/smoke.js 每个变体实战 6 秒，要放得出来、打得出伤害、元素和定义一致。

## 4. 数值

没有细调（当前优先级不在平衡）。只把明显坏掉的拉回正常：流星雨类变体伤害 ×1.6（不然只有原版的三到五成），焚风火地每跳比例降到 0.12，吸魂旋伤害 ×0.7（牵引让旋风斩伤害翻了几倍）。6 秒单次测试噪声很大，各变体相对原版大致在 0.5–2 倍之间。
