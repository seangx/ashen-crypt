## 原则

1. **装备分三层**
   - 形态件：底子或独特，决定技能长什么样。
   - 标签件：词条只写标签，多个流派都能用。
   - 誓约件：带代价的词条，制造取舍。
2. **文字只写标签，不点名流派。** 每件独特至少对两个流派有用。只做一个流派的形态独特例外，它绑在该流派的底子上。
3. **每个部位有自己的职责。** 毕业时每一格都能说出“为什么是这件”。
4. **毕业是一条看得见的路。** 开荒 → 成型 → 精修 → 毕业，每一段都有一次画面上的变化，不只是数字变大。

## 部位分工和新词条

| 部位 | 职责 | 新增标签词条（前缀 P / 后缀 S） |
|---|---|---|
| 武器（左右手） | 形态和基础伤害 | P：投射物 / 范围 / 近战伤害提高；S：投射物 +1（只出高档，直接加颗数）、弹射 +1（碰屏幕边反弹）、派生 +1、延迟伤害提高、投射物速度降低 |
| 头冠 | 标签核心 | P：投射物 +1、范围提高、暴击率（从印记挪一部分过来）；S：冻结的敌人受到的伤害提高、每次弹射伤害 +%、延迟伤害提高 |
| 盾 | 防御，也是圣盾掷的武器 | P：护甲 / 护盾 / 生命（现有）、盾牌伤害提高（新，只对“盾”标签生效）；S：格挡（盾在手时护甲额外减伤） |
| 遁靴 | 速度、冲刺、灯火 | P：移速；S：灯火燃烧降低、击杀回灯火、魂火回复（现有） |
| 法阵 | 元素和异常 | P：元素伤害提高（六选一）；S：六种抗性（含寒霜，现有的挪到这里为主）、异常效果（冰缓 / 感电 / 点燃 / 疫病强度）、穿抗 |

- **防具上的抗性大幅减少**，主要留在法阵和盾上。盾、头冠、遁靴空出来的位置给标签词条。
- **清理空词条**：质量、时间、召唤物、冲刺伤害等换成上面的新词条。老存档按 id 映射。

**誓约词条（新，每件最多一条）**：一正一负，正面大于普通词条。来源是天梯宝箱，或者用天梯铸符“立誓”打上去（会占锻造潜力）。例子：
- 满护盾时伤害总增 25%；护盾回复 −40%。
- 冻结的敌人受到的伤害总增 30%；冰缓效果 −30%。
- 每次弹射伤害 +10%；投射物数 −1。
- 延迟 +0.3 秒；延迟类伤害总增 30%。
- 范围提高 40%；移速 −15%。
- 投射物 +2；投射物伤害总降 30%。

另外现有的武器底子每把补一个**隐性标签倾向**：比如穿心弩自带穿透、雷灵自带弹射 +1、回旋骨刃自带范围提高。这样同部位的不同底子才有区别。

## 六个流派的装备

每个流派写四件事：形态件（独特或底子）、关键标签词条、建议的誓约词条、传奇目标（天梯 40 层后，用独特 + 稀有融合成传奇）。

### 旋风斩（近战、范围、持续施放）
- **形态件**：回旋骨刃，以及头冠风暴之眼（范围 +，大旋风吸怪）。
- **关键词条**：近战伤害、范围提高、叠层上限、命中回护甲。
- **誓约**：范围 +40% / 移速 −15%。
- **传奇目标**：风暴之眼 + 一件出了“范围提高、近战伤害”高档词条的稀有头冠。
- **新独特（遁靴）旋涡之履**：【持续施放】叠满层时移速 +30%，持续施放期间受到的伤害 −10%；代价是不叠层时移速 −20%。旋风斩和霜环（永冬）都能用。

### 游雷（投射物、弹射、闪电）
- **形态件**：雷灵，以及头冠雷冠（弹射 +1，弹射后打中的敌人感电）。
- **关键词条**：投射物 +1（直接加颗数）、弹射 +1（碰屏幕边反弹）、投射物持续时间 / 速度、闪电伤害、感电效果。
- **誓约**：投射物 +2 / 投射物伤害总降 30%。
- **传奇目标**：雷冠 + 投射物 +1 的稀有头冠。
- **共享**：百骨冠（投射物 +2）。

### 陨火（范围、延迟、持续、火焰）
- **形态件**：坠星杖，以及头冠**末日冠**（新）：【延迟】每多 0.1 秒延迟，伤害总增 +12%；延迟 +1 秒；范围 +30%。陨火和以后的延迟引爆类流派都能用。
- **新独特（法阵）焦土法阵**：【持续】你的地面效果可以叠 3 层；持续时间 −30%。陨火的火地、永冬的冰地、瘟疫的毒池都能吃。
- **关键词条**：范围提高、延迟伤害提高、火焰伤害、点燃效果、持续时间。
- **誓约**：延迟 +0.3 秒 / 延迟类伤害总增 30%。
- **传奇目标**：末日冠 + 范围提高 / 延迟伤害高档的稀有头冠。

### 圣盾掷（投射物、弹射、盾、圣光）
- **形态件**：圣徽盾（或任何盾）+ 圣盾掷符文；独特**殉道者之盾**（新，盾）：【弹射】弹射次数 ×2，每次命中回 2% 护盾；代价是盾飞出去时不吃盾的护甲。
- **新独特（头冠）回音冠**：【弹射】每次弹射（碰屏幕边反弹）后的命中在命中点留一个范围 ×0.3 的小爆，弹射次数 −1。圣盾掷和游雷都能用。
- **关键词条**：盾的护甲（越高伤害越高）、盾牌伤害提高、弹射 +1、每次弹射伤害 +%、圣光伤害、致盲。
- **誓约**：满护盾时伤害总增 25% / 护盾回复 −40%（盾流本来就回护盾，这条是正收益最大的地方）。
- **传奇目标**：殉道者之盾 + 高护甲、盾伤害的稀有盾。
- **特点**：攻防一体。把防御堆高本身就是加伤害，是六个流派里最“肉”的。

### 寒魄球（投射物、派生、持续、寒霜）
- **构筑方向**：投射物数量 × 投射物持续时间 × 投射物速度减缓（冰片总数 = 存在时间 ÷ 0.15 秒，越慢越集中在怪群里）。
- **形态件**：寒魄宝珠；武器独特**冬之心**（新，寒魄宝珠底）：冰球速度 −70%，持续时间 +100%，冰片频率 ×1.5。冰球变成一团缓慢碾过怪群的冰暴。
- **新独特（头冠）碎晶冠**：【派生】派生物再派生一层（每层伤害 ×0.5）；投射物速度 −20%（对寒魄球反而是好处）。寒魄球、霜环（碎冰）、旋风斩（小旋风算派生）都能用。
- **关键词条**：投射物 +1、持续时间提高、**投射物速度降低**（新词条，后缀；对其他投射物流派是坏处，所以只有这一系会去刷）、派生 +1、寒霜伤害、冻结的敌人受到的伤害提高。
- **誓约**：投射物 +2 / 投射物伤害总降 30%（冰片数翻倍，单片变弱）。
- **传奇目标**：冬之心 + 投射物 +1、持续时间高档的稀有武器；或者碎晶冠 + 投射物 +1 的稀有头冠。

### 霜环（范围、新星、寒霜）
- **形态件**：霜钟；法阵独特**永冬法阵**（新）：【新星】你的新星每 0.5 秒自动脉冲一次，并留下冰地；移速 −15%。霜环和圣钟都能用。
- **新独特（盾）冰棺盾**：【寒霜】每冻结一个敌人回 1% 护盾；冻结时间 +30%；火焰抗性 −20%。两个冰系流派都能用。
- **关键词条**：范围提高、寒霜伤害、冰缓效果、冻结的敌人受到的伤害提高、护盾。
- **誓约**：范围 +40% / 移速 −15%（永冬已经慢了，这条是赌命）。
- **传奇目标**：永冬法阵 + 寒霜伤害、冰缓高档的稀有法阵。

## 毕业体验

### 四段路

| 阶段 | 大概时间 | 推层 / 天梯 | 你在追什么 | 画面上的变化 |
|---|---|---|---|---|
| 开荒 | 0–1 小时 | 推层 1–15 | 一把对口的底子 + 流派符文 | 技能形态出现（第一次跃迁） |
| 成型 | 1–4 小时 | 推层 15–35，天梯 10–25 | 大天赋；防具开始刷标签词条；天梯 20 解锁形态独特 | 第二、三次跃迁：星坠雨、回响圣盾、碎冰、冬之心 |
| 精修 | 4–15 小时 | 天梯 25–50 | 铁砧把标签词条打到高档；誓约词条；天梯 40 传奇融合 | 数字跃升，清屏变快，开始挑战更深的天梯 |
| 毕业 | 15 小时以后 | 天梯 50 以上 | 溢彩顶档（只从天梯宝箱出）；传奇潜力 3–4 的融合；完美誓约 | 每个流派的“满配画面”（见下） |

### 毕业画面（每个流派的终点长什么样）
- **旋风斩**：人卷成一团红色风暴，越转越大，把整片怪吸进来，身后甩出一串小旋风。
- **游雷**：满屏电球在墙间乱弹，每弹一次就更痛。
- **陨火**：每次施放落下三颗巨陨，落地连成一片叠了三层的火海。
- **圣盾掷**：一面盾在怪群里弹二十多下，每一下都炸开圣光，人站在原地几乎不掉血。
- **寒魄球**：冰球一路扫进怪群，停下变成冰暴，几个冰暴同时往外喷冰片，冰片再碎出冰片。
- **霜环**：不用施放，脚下一圈一圈自动冻住整屏，冻住的怪成片碎掉、再连锁。

### 毕业以后追什么
- **天梯排名**：毕业构筑之间只差溢彩顶档和传奇潜力，这是长期的追求。
- **第二个流派**：标签件可以共用（比如百骨冠同时喂游雷、圣盾掷、寒魄球），所以练第二个流派比第一个快很多。这是我们没有转生时的“重开感”。
- **配装存档**：每个流派一套装备方案，在营地一键切换（需要仓库支持，作为后续项）。

### 数值目标（沿用 BD 体系稿）
- 毕业构筑的秒伤 × 有效生命是乱配的 30–100 倍。成型阶段（物品等级 30）至少 3 倍。
- 六个流派毕业时的天梯层数相差 ≤10%。
- 传奇融合前后，同一流派的天梯层数差距约 +15–25%。
- 溢彩顶档前后，约 +10%。这是“毕业后还在追”的那一截。
- 模拟验证：bis.js 下，每个流派最优装备应明显不同；换掉流派的形态件后，天梯层数下降 ≥30%。
