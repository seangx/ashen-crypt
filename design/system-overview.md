## 一句话
自动战斗的刷宝挂机游戏。
- **核心**：做装 + 爬天梯（用户 10-22 定）。
- **推层**提供材料。
- **天梯**检验构筑。
- **营地**是两者之间的整备点。

## 核心循环

```
营地 ──下行──▶ 推层（灯火下行：一层接一层，直到灯灭或阵亡）
  ▲              │ 每层：怪海 → Boss → Boss 宝箱集中掉落 → 整备界面（5 秒后自动继续）
  │              ▼
  ├──── 回营地：自动分解、铁砧打造、换装、点天赋、插符文
  │
  └──── 天梯（240 秒限时，选层数，只给通关宝箱）──▶ 宝箱：独特、溢彩、铸符、誓约
```

## 系统清单

状态说明：**上线** = 在 main 里能玩；**文档** = 只有设计稿，未开工；**遗留** = 早期从 Astroloot 搬来、和现在方向关系不大。

### 战斗与怪物（上线）

**场地和刷怪**
- 无限场地，镜头跟随。
- 怪海：每群 6–12 只，数量 ×6，每只血 ×0.19、伤害 ×0.25；按视野面积补怪；同屏上限 150。

**怪物**：7 种，分别是骷髅、盗贼、重甲、法师（火圈）、尸犬、骨弓手（预判）、霜魂（冰缓）。

**精英和 Boss**
- 精英：带预警红圈的重击。
- Boss：4 种招式 + 重击 + 疲劳机制。

**自动战斗**
- 按流派切换近战 / 远程 AI。
- 自动躲重击。
- 鼠标或摇杆接管，松手几秒后恢复自动。

**特效**：后处理光晕、光照、打击停顿。陨火、冰封球都单独做过特效。

### 推层：灯火下行（上线）
- **出发和结束**
  - 进入时灯火 = 魂火上限，每秒燃烧（越深越快），击杀回灯火。
  - 灯灭：安全返回，战利品全部带走。
  - 阵亡：每件战利品 50% 几率保留。
- **10-25 新增**
  - 怪不再在战斗中掉装备，每层的装备在 Boss 宝箱里一次性喷出。
  - 宝箱之后进入**整备界面**：暂停，可以速览战利品，并直接打开装备 / 符文 / 天赋 / 铁砧。
  - 战斗中可以**提前返回**（点两下确认）。
  - 前沿生命低时会紧急返回。
- **魂火 = 灯火**：所有流派共用一条资源条，技能消耗也从这里扣。

### 天梯（上线）
- 个人天梯，层数自选，限时 240 秒。
- 怪物：生命 +40%、伤害 −35%，精英 ×2。
- 不掉装备、不给经验，只有通关宝箱。
- 各系统按天梯层数解锁：喂养 20、立誓 30、熔铸 40。
- 记录格式已经可以上线，排行榜还没做。

### 营地（上线）
- **设施**：地窖入口、储物箱、天赋石像、铁砧、分解祭坛、符文台、墓图台、天梯石碑。
- **分解祭坛**：返回时按规则自动分解（稀有度、旧装备、收藏词条）。10-25 加了**批量拆解**：按品质多选，也可以单件点选。

### 角色与天赋（上线）
- 等级：每级 1 点天赋。
- **天赋树**
  - 六个区：近战、范围、投射物、持续、守备、灯火。
  - 内圈是元素环（6 种元素），外圈是交界。
  - 约 30 个改规则的大天赋。
  - 10-24 通用防御已实现（b298aa6），遗留节点已清理。
- **印记**（遗留，从 Astroloot 来）：天赋树桥上有 12 个印记槽，插 chip / chipE。暴击伤害、各元素的“总增”主要在这里。

### 技能与流派（上线）
- **主手决定技能**：武器底子决定攻击形态，共 28 种形态。
- **流派**：形态符文把形态改成流派技能。
- **副手**（10-25 新，bdb42b0）：改成支援槽，不再有第二个技能。共 5 种，都只强化主手技能：
  - 箭袋：多射、多弹
  - 法源：通用放大
  - 香炉：范围
  - 图腾：攻速
  - 提灯：暴击、异常
- **六个成型流派**：旋风斩、游雷、陨火、圣盾掷、寒魄球、霜环。
  - 每个都有毕业存档，用 `?demo=名字` 打开。
  - 其余形态（散射、喷火、陷阱、光束等）有基础玩法，没有成型路线。
- **元素**：6 种，含寒霜。每种有自己的异常：碎骨、余震 / 灼烧、感电、致盲、疫病、冰缓 / 冻结。

### 装备（上线）
- **部位**：主手、副手、盾、头冠、遁靴、法阵，另有印记。
- **词条**
  - 词条改版已上线：标签词条、抗性收拢到法阵和盾、空词条映射。
  - 誓约、底子隐性倾向已上线。
  - 稀有度：普通 / 罕见 / 稀有，每件前缀 2、后缀 2。溢彩是顶 2 档，只从天梯宝箱出。
- **独特和传奇**
  - 独特约 41 件，按标签写。
  - 天梯 40 层后可以把独特和稀有熔铸成传奇。
- **符文**：51 个，分三类：
  - 形态符文 6 个
  - 辅助符文约 34 个
  - 法阵的“力场”10 个

### 打造（上线）
- **碎片**：分解装备获得，也会掉落。
- **锻造潜力**：每件装备的打造次数上限。
- **铁砧**：加词条、升一档、洗数值、移除。
- **铸符**：希望、混沌、洗练、剥离、立誓。

### 防御（上线）
**底层**
- 结算顺序：闪避 → 抗性 → 护甲减伤 → 流派减伤 → 护盾 → 生命。
- 护盾：每秒回复 8%，从不停止回复。
- 生命：只靠吸血（有上限）和击杀 Boss 回复。

**通用防御**：控场、贴身、远离、续航四种，配 4 个大天赋和 4 条词条。

### 墓图 / 命盘 / 轮换 Boss（遗留，v8）
- **墓图**：有词条的地图。
- **命盘**：弹珠台，加掉落和经验。
- **轮换 Boss**：4 个，按击杀次数给祝福。
- 开局就开放，天梯里不生效。

## 问题清单（按优先级）

1. **技能石方案和刚上线的“副手支援”冲突。**
   - 技能石方案按“左右手各一个技能”写，而 10-25 已经改成只有主手有技能、副手是支援。
   - 建议：技能石方案改成**一个主技能格 + 副手支援**。副手的支援效果正好对应“武器类别倾向”，比原方案更简单。
   - 盾技能格（圣盾掷）也要重新确认：现在等于第二个技能，和“单技能”方向矛盾。

2. **遗留系统太多，和核心循环重叠。**
   - **墓图 / 命盘 / 轮换 Boss**：做的是“刷更难的图拿更多奖励”，和天梯、灯火下行重叠，而且天梯里不生效。建议并进天梯（墓图词条改成天梯层的随机词缀），或者整个下线。
   - **印记**：最大的乘区（元素总增、暴击伤害）藏在天赋树的 12 个插槽里，和装备、技能石、副手抢同一件事。
   - **法阵力场**：铁骨、流沙、魂涌、回息这几个还是质量、时间这类遗留属性。
   - **装备和独特上的遗留属性**：三相之盾、巴鲁之石、攻城骨弩还在用质量、时间。

3. **渐进式披露几乎没做。** 解锁表里天赋、符文、印记、墓图、副手都是 0（开局就有），只有铁砧、天梯、喂养、熔铸分阶段。

4. **平衡没跟上。**
   - 上独特和通用防御之后，没有跑过六个流派的模拟。
   - 10-25 的副手改版和怪海加密都改变了强度。
   - 上次的数据：新流派落后旋风斩、游雷约 25%。

5. **新流派的生存和灯火来源一直延后。** 规格里写的“先不调”，到现在还没调。

6. **天梯是核心，但只有个人天梯。** 没有排行榜、赛季，也没有“和别人比”的东西。记录格式已经可以上线，作为后续项。

7. **横屏代码和竖屏原型并行。** 要定什么时候、按什么方式迁移，否则 UI 改动会做两遍。

## 建议的下一步顺序

2. 决定遗留系统怎么处理：墓图 / 命盘 / 轮换 Boss、印记、力场。
