# 旋风斩第三版：照经典野蛮人旋风斩重做形态（设计线程）

用户 2026-10-22 13:07：旋风斩要像经典野蛮人的旋风斩，视觉和机制都是；分裂出去的应该是小旋风。现在的“三片刃绕身转 + 甩刃风”更像电球法师。
数值和规则仍放在 mechanics.json 的 `whirl`，名字和文字全部是原创地窖题材。

## 参考：经典旋风斩是什么样（凭对暗黑系列的了解整理，细节以程序线程的调研为准）
- 暗黑 2：角色举着武器原地高速自转，同时朝目标点直线移动，路径上和身边的敌人被反复砍中。打击频率取决于武器速度。每次施放消耗法力，转的时候不能被打断。
- 注意（用户 2026-10-22 13:10）：只有人物的大旋风能吸人，小旋风只造成伤害。
- 暗黑 3：变成持续施放（按住就一直转），一边转一边走。每秒消耗怒气，伤害按武器伤害结算，周围敌人每隔一小段时间被砍一次。常见的变化有：转的时候不断甩出小旋风（尘魔），小旋风朝外乱跑并伤害碰到的敌人；把敌人往身边吸；每砍中一个敌人回怒气，怪越多越能一直转；暴击回血。成型装备主要是两类：放大小旋风伤害，和转的时候减伤。
- 暗黑 4：仍是持续施放、每秒耗怒气、边转边走。强化版本是“连续转满几秒后伤害更高”，或者让被砍的敌人流血。

## 我们的版本
**形态**
- 去掉“三片刃绕身转”。旋风斩是角色本人在转：武器挥成一个完整的圆，身边有一圈刀光和风纹，角色贴图本身在旋转（或用 4 方向帧快速切换做出转身效果）。
- 伤害判定：以角色为中心、半径 = 武器范围的圆，按攻速每隔一段时间砍一次圈内所有敌人。这就是现在 orbit 的判定，只换视觉。
- 转的时候一直在移动：自动战斗沿用近战 AI 的“穿过怪群”路线；手动时朝鼠标方向走。转的时候移速 ×`whirl.spinMoveMul` = 0.8。

**三次形态跃迁**（替换原来的刃数 / 刃风 / 龙卷风拖尾）

| 阶段 | 来源 | 画面 | 机制 |
|---|---|---|---|
| 0 挥砍 | 回旋骨刃（建议改名“回旋骨斧”，换成双手斧贴图） | 普通横扫 | 没有旋身符文时，就是身边一圈普通近战 |
| 1 旋风 | 旋身符文 | 角色开始自转，刀光成圈 | 旋势层数（沿用现在的层数：连续命中每秒 +1，每层总增 ×1.06–1.12，范围 +1%（rngPer，原来 5%，太大））；转圈每秒耗灯火，每砍中一个敌人回灯火 |
| 2 尘旋 | 旋风之心（大型天赋） | 转的时候每隔一段时间甩出小旋风，朝外乱跑 | 每 `whirl.devilEvery` = 0.6 秒生成 1 个小旋风；层数满时间隔减半。小旋风飘 `devilLife` = 2.5 秒，从角色身边朝外散开，路线带随机偏转（暗黑 4 的做法；暗黑 3 是顺着移动方向走）。参数 devilR 10、devilSpeed 70、devilTurn 3、devilTick 0.25；碰到的敌人每 0.25 秒受一次伤害 = 旋风单次伤害 × `devilMul` = 0.35；同屏最多 `devilMax` = 8 个 |
| 3 风暴之眼 | 独特头冠风暴之眼 | 角色自己的旋风变成大旋风，把周围的敌人卷进来；小旋风更多、更久 | 角色旋风半径 +`eyeRng` 40%，并把 `pullR` 2 倍旋风半径内的敌人以 `pull` 40 像素/秒吸向角色（Boss 不吸）。小旋风持续 +`eyeLifeAdd` 1 秒，同屏上限 +`eyeMaxAdd` 4；小旋风大小不变，也不吸人（用户 13:10：只有人物的大旋风能吸人） |

**资源（灯火）**：照暗黑 3 的思路，每秒固定消耗，砍中敌人回复。
- 转的时候每秒消耗 `whirl.soulPerSec` = 6，并取代按层数消耗。
- 每砍中一个敌人回 `whirl.soulPerHit` = 0.35；同一次挥砍最多按 6 个敌人算。
- 小旋风打中的敌人不回灯火，避免后期无限续航。
- 结果：打怪堆能一直转，打单个 Boss 会慢慢烧完灯火。魂火词条（回复、消耗降低）就是旋风斩的资源端。

**防御**：不变。保留近战守势（命中后 1 秒受伤 −45%）、旋势减伤（每层 −1%，最多 40%）和命中回护甲，这正对应暗黑 3 旋风套装“转的时候减伤”的思路。

**删除**：刃数和 bladeMore、刃风（gust*）、风暴之眼原来的移动拖尾龙卷风（vortex*）。数值上用小旋风顶替：刃数原来能给 ×1.1^5 左右，加上刃风，小旋风大致对应这部分伤害。

## 交给程序
1. 视觉：角色自转 + 刀光圈，替换三片环绕刃；小旋风是独立的小龙卷风贴图（灰白风纹 + 骨屑）。
2. 机制：按上表实现尘旋和风暴之眼的新效果，删掉 blade / gust / vortex 相关规则。
3. 资源：soulPerSec / soulPerHit 替换现在的 soulPerStack / soulPerSpin。
4. 模拟：`--seeds 1,2,3`，跑 90 分钟和 600 分钟，whirl 对 random；bis 跑物品等级 30/70/100。另外报告小旋风伤害占旋风斩总伤害的比例。
