## 1. 总规则

| 项 | 现在 | 改成 |
|---|---|---|
| 技能从哪来 | 主手武器的形态（form）+ 形态符文 | 技能格里的**技能石** |
| 辅助符文插在哪 | 主手武器的槽 | 技能石自带的槽（1–5） |
| 主手武器 | 决定技能 + 数值 | 只给数值：基础伤害、攻速、暴击、词条，外加类别对口加成 |
| 副手 | 支援主手 | 不变，改成支援技能石（规则照旧，只是“主手标签”改读技能石的标签） |
| 形态符文（旋身、游雷、陨火、寒魄、霜环、圣盾掷） | 插在武器上 | 并进对应的技能石，不再作为符文掉落 |

- 技能格只有一个，位置在装备页主手旁边。
- 换主手武器时，技能石和上面的符文都不动。

## 2. 伤害公式

```
单次伤害 = 主手基础伤害（min~max 随机）× 技能石倍率 mul(等级) × (1 + 品质%) × (1 + 提高) × 总增 × 对口
出手频率 = 主手攻速 × 技能石速度 spd
元素     = 技能石的 el（主手和其他来源的平加元素伤害照常加）
对口     = 主手类别的对口标签 ∩ 技能石标签 非空时 ×1.2（mechanics.json `gems.affinity`），否则 ×1
```

- 暴击率 = 主手暴击 + 技能石 `critAdd`（默认 0）。
- 异常几率 = 技能石的 `ail`（取代旧武器的 `ail_*`）+ 主手隐性 + 其他来源。
- **盾技能**（标签带 Shield，即圣盾掷）：不读主手基础伤害，改用盾的护甲 × throwK（同现在）。要求装备了盾，没装盾时技能格显示“需要盾牌”，并改用主手的普通攻击：骨矢 1 级，无辅助。主手的非局部词条照常生效。

## 3. 数据

### 3.1 新文件 `data/gems.json`

```json
{ "_说明": "...",
  "list": [
    { "id": "GemWhirl", "n": "旋风斩", "ic": "g_whirl", "form": "orbit", "el": "kin",
      "tags": ["Melee","AoE","Attack","AttackSpeed","Hit","Channel"],
      "mul": [1.0, 2.2], "spd": 1.0, "req": 6, "w": 600,
      "fx": { "whirl": 1, "spinMore": ["lp",1.06,1.12,3], "meleeGuard": 1, "armorOnHit": ["lp",1,6,2] },
      "ai": "melee" }
  ] }
```

- `form`：沿用现有的攻击形态代码（proj / beam / orbit / nova / meteor / orb / mine / aura / ram / stab / cone / shieldThrow …）。战斗代码改成从技能石取 form，不再从武器底子取。形态参数（blast、pellets、wide、spiral、wander、pool、shoot、fast、dpsMul、rngMul）从 items.json 的武器条目搬到技能石上。
- `mul`：[1 级, 20 级]，中间线性。
- `fx`：原形态符文的 fx 原样搬过来，`lp` / `step` 的等级改读技能石等级。普通技能石没有 fx。
- `range` / `aoe` / `aps`：
  - 原来写在 astro.json 的武器上，现在搬到技能石的 `range`、`aoe` 和 `spd`。
  - 换算：`spd` = 旧武器 aps ÷ 所在类别主手的平均 aps。
  - 主手的 range 不再使用。

### 3.3 主手武器归类（items.json 的 weapons 每条加 `cat`）

| cat | 名字 | 对口标签 | 保留的底子（w 不变） | 停止掉落（w → 0，只为老存档保留） |
|---|---|---|---|---|
| melee | 近战 | Melee | 回旋骨刃、撞城骨锤、骨刺 | 荆棘甲 |
| bow | 弩 | Projectile | 骨弩、穿心弩 | 雷符、飞镰、雷灵 |
| caster | 法器 | AoE、Nova、Delayed、DoT | 坠星杖、圣钟、寒魄宝珠、圣光杖 | 霜钟、瘟疫香炉、喷火颅、五种陷阱 |
| gun | 铳 | Projectile | 散骨铳、疫孢囊 | 火油罐、回旋火轮、疫星仪、圣焰铳、圣光镰刃 |

- 武器底子的 `form` 和形态参数删掉（搬到技能石）。
- `el` 保留：它决定武器自带基础伤害的元素。和技能石元素不同时，按“额外获得”算，不转换。
- 隐性倾向（mechanics.json `implicit`）保留。
- **武器不再有符文槽**：items 生成时 weapon 的 sockets 为 0。头冠、遁靴的槽不变。

### 3.4 技能石的属性和掉落

| 字段 | 值 |
|---|---|
| `lvl` | 1–20。经验沿用符文经验（astro.json modXp 曲线）：装备中的技能石吃击杀经验；天梯 20 解锁后可以喂养 |
| `q` | 品质 0–20%。掉落时 0–10 随机；铁砧新动作“打磨”：花 5 个随机碎片 +1%，最高 20 |
| `sockets` | 1–5。掉落权重 `[1000, 800, 600, 300, 100]`（mechanics.json `gems.sockW`） |
| 辅助符文 | 插在技能石上，`fit` 检查技能石的 tags（原来检查武器 tags） |

- **掉落**：和符文同一次判定（loot.drop.mod）。命中后 `gems.dropShare` 30% 是技能石，否则是符文。技能石按 `w` 抽。
- **新铸符“开孔” `socket`**：技能石 +1 槽，上限 5。天梯宝箱 4% 掉一个（loot 或 craft.json `glyphs` 加一条）。
- **重复技能石**：喂给同 id 的技能石 = 经验 ×2（只在喂养解锁后）。

### 3.5 形态符文
Whirl、Spark、Meteor、FrostOrbRune、FrostNova、ShieldThrow 的 `w` 改成 0，不再掉落。它们的 fx 已经搬进技能石。

## 5. 老存档迁移（S.craftV 或新的 S.gemV = 1）
1. **装备中的主手**
   - 按它的底子生成对应技能石：辅助槽 = min(5, 旧槽数)，旧槽里的辅助符文搬进去。
   - 形态符文不占槽：并进技能石，技能石等级 = 该符文等级。其余技能石等级 = 1。
   - 品质 = 旧武器品质 ÷ 2。
   - 放进技能格。
2. **主手武器本身**
   - 底子保留（停止掉落的底子也照样能用）。
   - 槽清空，词条、品质、溢彩、誓约、传奇都保留。
3. **背包里的武器**：同样拆成武器 + 技能石。技能石进背包，符文跟着走。
4. **背包里的形态符文**：转成对应技能石，等级 = 符文等级，1 槽。
5. **毕业存档**：saves/*.json 用新 bis 重新生成。

## 6. 验收
- 迁移后六个流派的毕业存档：秒伤和迁移前相差 ≤5%（bis 前后各跑一次）。
- `sim --build random`：技能石随机，主手随机。90 分钟推层和迁移前相差 ≤10%。
- 换主手武器时技能不变；没装盾时，圣盾掷的提示正确。
