# 技能石 / 符文交互（手机版）

范围：只改手机界面（`src/87_gemrune_mobile.js` + `86_ui_mobile.js` 少量接线），桌面不动；存档结构不变（堆叠只是显示分组）。

## 堆叠
- 符文：同 `mid` + 同等级 = 一叠，格子右上角 `×n`。点一叠 = 操作其中最早的一枚（新标记先清）。
- 技能石：同底材 + 等级 + 品质 + 槽数、且没插符文 = 一叠。插了符文的单独显示。
- 新获得的物品左上角有橙点；一叠里有新的就显示。

## 筛选 / 排序（符文页、技能石页顶部的筛选小按钮）
- 符文：全部 / 适用（能在当前部位生效）/ 新 / 力场；排序：等级↓ ⇄ 名称。
- 技能石：全部 / 新 / 当前技能同形态；排序：等级↓ ⇄ 品质↓。
- 空状态：每种筛选给一句说明（例如“没有能在头冠上生效的符文”）。

## 详情 + 对比
- 点一叠符文 → 详情弹窗：符文说明、数量、在当前部位是否生效；若当前部位已插同名符文，显示其等级；
  有空槽或可替换时显示预估变化“秒伤 12.3K → 13.1K (+6%)”（临时插入后重算属性再还原）。
- 操作：镶嵌（有空槽）/ 替换（槽满：换掉预估最差的那枚）/ 拆解 1 枚 / 喂养（已解锁时）。
- 点槽里的符文 → 详情：卸下 / 换一个（打开选择器）。

## 从技能石一侧镶嵌
- 点空槽 → 选择器弹窗，只列能在这里生效的符文（按预估秒伤增益排序，标出增益），点一下镶入。
- 「一键镶嵌」：空槽按预估增益逐个贪心填入；法阵按等级填力场符文。「全部卸下」。

## 批量拆解（符文 + 技能石）
- 弹窗：符文按等级段 1–5 / 6–10 / 11–15 / 16–20 多选，技能石按同样等级段多选；显示数量和预计碎片。
- 只动库存里的（未镶嵌的符文、背包里的技能石），身上和槽里的绝不动；确认弹窗后执行。
- 产出（默认，待 Sean 定）：符文 1+⌊等级/5⌋ 个随机词条碎片；技能石 2+⌊等级/5⌋ 个；技能石上插的符文退回库存。

## 容量
- 符文库存软上限 150：超过时符文页顶部红字提示 + 批量拆解入口（不删任何东西）。技能石占背包格，沿用背包上限。

## 旧存档
- 不改数据结构，无需迁移；`isNew` 缺省视为旧物品。
