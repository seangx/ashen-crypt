# 技能系统 v3（2026-11-10 用户定稿方向）

## 原则
1. **三层标签**：元素（系）· 形态 · 机制。每个技能 1 个元素、1 个形态、0–2 个机制。旧的“攻击 / 攻速 / 命中 / 可弹射…”只当内部开关（辅助石适配、属性适用），不再显示。
2. **一个技能只有一种元素**：技能石固定元素；别的元素的附加伤害并进技能元素。旧的“附加元素 / 附加特效 / 共鸣”三套规则取消。
3. **元素 = 主效果 + 副效果**。主效果人人有、对 Boss 也有用、六系强度相当，只是“伤害的形状”不同；副效果（清场 / 控制 / 保命）放到传奇词条和神话装备上。

## 六系主效果
| 元素 | 触发 | 主效果 | 副效果（装备给） |
|---|---|---|---|
| 物理 · 破甲 | 打得多 | 每次命中叠一层（上限 10），目标受到的所有伤害 +3% / 层，6 秒 | 碎骨：命中在周围炸开 |
| 火焰 · 灼烧 | 打得重 | 火焰伤害的一部分进灼烧池，持续烧 | 爆燃：烧着的怪死时波及周围 |
| 闪电 · 感电 | 打得重 | 按这一下相对目标血量的轻重给层数，层数降全抗（= 更脆），2 秒窗口 | 电弧：一部分伤害电到周围 |
| 瘟疫 · 疫病 | 打得多 | 每次命中叠一层持续伤害，不设上限 | 传染：带疫病死的怪把层数传给周围 |
| 寒霜 · 冰缓 | 打得多 | 叠层减速；叠满“碎冰”：结算这轮累计寒霜伤害的一部分，重新叠 | 冻结 |
| 圣光 · 审判 | 打得重 | 斩杀：目标血量低于一条线直接处决（越重线越高；精英、Boss 线更低） | 致盲 |

精英 / Boss 的“轻重”按血量折算（精英 ×4、Boss ×20），不然对 Boss 永远是最轻的一下。

## 形态和机制
- 形态：近战 / 投射物 / 范围。
- 机制（≥2 个技能有才算）：弹射、穿透、分裂、持续、延迟、派生。
- 打得多：弹射、分裂、派生、持续；打得重：延迟、穿透。

## 分期
1. 标签、单元素、六系主效果、5 个新技能和新特效、界面显示。← 本期
2. 传奇词条 / 神话按系重新归类，副效果只从装备来；专精里按旧元素系统生效的大天赋改写。
3. “系”的回报（同系凑齐给什么）、数值平衡（六个主效果同价）。

## 功能技能和魂龛分工（2026-11-10 用户补充）
- **输出技能**只插出手类魂龛（出手、命中、暴击、残灯）和常驻。
- **功能技能**（不造成伤害）只插响应类魂龛（击杀、受击、格挡、冲刺、定时、明灯、低血、遇精英）。
- 第一批 6 个：防御——骨盾（回护盾）、回春（回生命）、石肤（短时减伤）；增益——战吼（短时增伤）、疾步（攻速和移速）；资源——聚火（回灯火）。数值按技能石等级和品质成长。
- 旧存档：响应类魂龛里的输出技能退回背包。

## 已知遗留（第二期处理）
- 冻结还留在寒霜的基础效果里（霜环、冰棺盾、碎冰等现有内容依赖它），没有挪到装备上。
- 依赖旧“附加特效 / 共鸣”的神话、传奇词条和专精大天赋暂时没有效果：双生冠、棱镜法阵、纯色之心、余烬之握、裂骨之锤、焚野法阵（传播部分）、雷链冠、霜棺之心（射冰片部分）、审判之盾、瘟潮靴；专精的纯色、杂糅、异变、余波。
- 装备上“某异常几率”的词条 / 隐性：灼烧、感电、疫病、冰缓的几率现在折算成该系主效果的强度加成；碎骨、致盲仍是几率（副效果）。文字还没改。
- 六个主效果的强度还没按“同价”校准。

## 第二期（2026-11-10）：副效果挂到装备上
- 副效果只从装备来：带“某系之力”传奇词条（规则键 `fx:元素`）或对应的神话才有。技能是这个元素才触发，基数 = 这一下该元素伤害 × sideK（0.3）。
- 六条副效果传奇词条：碎骨（主手）、引燃（法阵）、雷爆（头冠）、霜结（副手）、致盲（盾）、疫染（遁靴）。
- 六条主效果强度传奇词条（`efx:元素` 15–30%）：断甲（副手）、炽燃（主手）、蓄雷（法阵）、凝霜（头冠）、圣裁（遁靴）、沉疫（盾）。
- 重新生效的神话 / 传奇词条：裂骨之锤、焚野法阵、雷链冠、霜棺之心、审判之盾、瘟潮靴各自带本系副效果再加自己的强化；余烬之握 = 命中总是额外引燃；双生冠 = 副效果触发两次；棱镜法阵 = 六种副效果轮流；纯色之心 = 主效果强度 +25%。
- 瘟疫“死亡传染一半层数”从基础效果挪成副效果（要疫染之力、瘟潮靴，或职业大天赋“传染”）。
- “某异常几率”文字：灼烧 / 感电 / 疫病 / 冰缓改成“效果”，碎骨 / 致盲仍是“几率”。
- 仍然遗留：冻结还在寒霜基础效果里；六个主效果没有按同价校准。
