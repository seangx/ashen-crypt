**影响玩法**
- Boss 招式连放、预警（defense-v3 §8.2 后三条）；天梯层词缀还没改用精英词缀表。
- 辅助石：分裂出来的每发触发系数 ×0.5（skills.md §3.1）。
- 魂龛普通同底同阶叠放（spec §10）；孔数权重和 spec §4.2 不一致（现在偏多）。
- 几件独特的代价或效果没生效：冬之心、永冬法阵、旋涡之履、永夜灯、符文教父、风暴之眼、三棱穿心弩（uniques-audit）。

**面板和界面**
- 坚韧 / 恢复两个大数、受伤来源统计（defense-v3 §4、§8.4）。
- 营地“当前目标”横幅（system-v2 §8）。
- 灯火面板只显示燃烧（lamp-v2 §5.0）；光圈外的怪只显示轮廓（lamp-v2 §3）。
- 小于 28 的按钮（review-open-design #3/#6）。

**灯火和天赋的小项**
- 灯油罐（lamp-v2 §5.2）。
- 天赋“充能获取”小节点；殉爆元素固定为火焰；传染、蚀骨只认瘟疫（tree-v3）。

**写法和文档不一致**（改文档或改代码都行）
- 近战底技能是突刺不是挥砍；对口倍率代码 1.2、文档 1.1；双生冠第二元素 ×1.0、文档 ×0.6；焚野法阵做成灼烧扩散、文档是火圈；陷阱还有 5 个元素版本。
