## 实现进度（2026-10-29 对照代码核对）
各文档开头原来写的“未开工”已过时：魂龛核心、元素、装备 v2、独特、天赋树 v3、防御的护甲 / 抗性 / 格挡、三档灯态、骸骨轮盘在 main 上已实现。

### feat/trig-econ 分支补上的
- **魂龛**：掉落（普通 0.3% / 精英 4% / 首领必掉 + 偏好 2 种底子 / 天梯每 5 层，每 20 层保底稀有）；打造（重铸、改一条、升阶、打磨、重铸符重随孔数）；背包上限 60、自动分解、普通魂龛叠放显示；孔数按 spec §4.2；防循环补齐；卡片加占总输出 / 充能速度 / 充能溢出；被触发的旋风斩直接带“阶 × 2”层。
- **技能石和辅助石**：圣盾掷可插魂龛；新增多重投射、灼烧、霜咬、节灯、燃芯、残焰；急蓄、连发改版；分裂出来的每发触发系数 ×0.5；旧符文和力场停掉；余震去掉火焰；辅助石在魂龛里吃经验。
- **防御**：精英词缀 14 种（头顶彩点 + 名字前缀；天梯每层固定一组）；预警会叠、被堵住时冲刺减半、光圈外的重击读条减半、AI 只躲光圈里的预警；面板“坚韧 / 恢复”（点开看每一层）；装备对比改成秒伤 / 坚韧 / 恢复；结算页受伤来源和建议；sim.js 输出受伤来源。
- **灯火**：明灯拾取 +50%、残灯宝箱稀有度 +25%、光圈外普通怪移速 +15% 并画成暗剪影；灯油罐；灯火瓶显示实际净消耗和倒计时，点开看分项；天梯文字去掉“限时”。
- **天赋和独特**：“充能获取 +5%”小节点；殉爆用主附加元素、传染认所有持续伤害、蚀骨认任何异常；冬之心、旋涡之履、风暴之眼、永夜灯、符文教父、三棱穿心弩、疫爆陷阱、末日瘴云、雷囚之盾、永冬法阵按 uniques-audit 修正。
- **界面**：页内按钮统一 28 高（review-open-design #6）。
- **其他**：营地“当前目标”横幅；旋风斩刀光换成层叠月牙；sim.js 在手机版上不再卡死。
