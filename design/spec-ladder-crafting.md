# 实现规格：天梯 + 新做装系统

设计依据：[做装与天梯核心方案](https://claude.ai/artifact/HkNajCe11KdZaGL47S6YZH)。用户确认于 2026-10-22。
分两期上线，每期一个版本。所有数值都放进 data/*.json，下面写的是初始值，之后由设计线程调。

## 第一期：天梯（个人）

**解锁**：推关第 10 层通关后（progression.unlocks.ladder = 11，按 maxDepth 判断）。

**状态**：`S.ladder = { unlocked: 1, best: 0, bestTime: 0, tiersHit: [], records: [] }`，进存档。

**挑战**
- 新运行模式 `RUN.mode = 'ladder'`，层数 N 从 1 到 `unlocked` 任选。不消耗任何东西。
- 怪物等级 = N，沿用 monHp / monDmg 曲线。密度：同屏上限和刷怪间隔各 ×1.5，精英率 ×2（data: ladder.density 1.5, ladder.eliteMul 2）。
- 进度条：普通怪 1 点，精英 5 点，满 `60 + 2N` 点后召唤守关 Boss（用当前轮换 Boss，bossFor(N)）。
- 限时 240 秒，界面顶部显示倒计时和进度条。死亡或超时 = 失败，没有损失。
- Boss 死 = 成功。按剩余时间跳层：≥120 秒 +3，≥60 秒 +2，其余 +1（data: ladder.jumps）。`unlocked = max(unlocked, N + jump)`。
- 墓图、命盘加成在天梯里不生效（只看装备、天赋、符文）。
- 可以随时手动接管，记录不区分自动和手动。

**和自动循环的关系**
- 底栏加“天梯”按钮：打开天梯窗口，选层，点“挑战”。当前推关这局打完后开始天梯。
- 天梯窗口里有“连打”开关：开着时，成功后接着打新的最高层；失败后回到推关循环。关着时，打一次就回推关。

**奖励**（成功时开宝箱，直接进背包和材料仓）
- 2 件装备，物品等级 = N + 3。
- 第二期上线前：按 N 给一批骰子，沿用现有骰子掉落权重，数量 3 + floor(N / 5)。第二期改成词条碎片和铸符。
- 段位首次达到奖励：段位门槛 [10, 20, 30, 40, 50, 60, 75]，名字 青铜、白银、黄金、铂金、钻石、大师、传说。第一期先给 1 件物品等级 N + 5 的稀有装备。

**记录**（每次成功存一条，最多保留 200 条）
```
{ v: 1, data: "<构建时 data/*.json 的哈希>", lvl, time, date: "ISO", jump,
  build: { equip: [{ slot, b, q, rar, u, affs: [[k, t]] }], keys: [大型天赋 id], dps, armor, deflect, elem: "主伤害元素" } }
```
以后上传在线排行时只需加 season 和 name，所以字段名要稳定。

**天梯窗口**（画布内，Noto Sans SC）：当前段位和最高层；选层（默认最高已解锁层）；挑战按钮和连打开关；按主伤害元素分的最好成绩；最近 20 条记录（层、用时、日期、主要装备）。

**模拟**：tools/sim.js 加 `--ladder every:K`，表示每 K 局推关打一次天梯最高层（带连打），输出天梯层随时间的变化。

## 第二期：新做装系统（参考《最后纪元》）

**删除**
- 骰子掉落、S.dice、骰子界面、“制造”窗口里的骰子操作。
- 墓图用骰子改造：墓图的稀有度和词条改成只在掉落时随机，暂不能改。
- 存档迁移：丢弃骰子；已有装备按稀有度补一个锻造潜力；超过 4 条词条的旧装备保留现状，但不能再加。

**词条上限**：魔法 1 前缀 + 1 后缀；稀有 2 前缀 + 2 后缀，一共 4 条。稀有装备掉落时 3 到 4 条（loot.affixCount）。

**锻造潜力**：`item.fp`，掉落时随机。普通 10–20，魔法 15–25，稀有 20–35；独特装备没有（loot.fp）。

**词条碎片**：`S.shards = { 词条族 key: 数量 }`。
- 来源一：拆解装备，每条词条给 1 个对应碎片，档位 ≥ T3 的再多给 1 个。
- 来源二：掉落。每只怪 4% 掉 1 个，在当前物品等级能出的词条里按权重抽。

**铁砧**（替代“制造”窗口）。操作对象是背包或身上的一件装备：

| 动作 | 条件 | 效果 | 花费 |
|---|---|---|---|
| 加词条 | 有空的前缀或后缀位；该词条能出在这件装备上；有它的碎片 | 加上该词条，从最低档开始 | 1 个碎片，潜力随机扣 1–4 |
| 升一档 | 下一档在物品等级允许范围内，且不是只能掉落的两档 | 档位 +1，重新随数值 | 1 个该词条碎片，潜力扣 1–4，再加 floor(新档位 / 3) |
| 拆解 | 无 | 毁掉装备，得到碎片 | 无 |
| 洗数值 | 有洗练符 | 选一条词条，在同档内重新随数值 | 1 张洗练符，潜力扣 1–3 |
| 移除 | 有剥离符 | 随机去掉一条词条 | 1 张剥离符，潜力扣 1–3 |

- 潜力不够扣时，动作仍然完成，潜力归 0，之后不能再改（照《最后纪元》）。
- 稀有度自动跟着词条数变：0 条普通，1–2 条魔法，3–4 条稀有（稀有时生成名字）。

**铸符**：`S.glyphs = { hope, chaos, refine, strip }`，主要从天梯宝箱出。
- 希望符：加词条或升档时可以附带一张，50% 几率这次不扣潜力。
- 混沌符：升档时附带一张，升档后把这条词条换成同类型（前缀或后缀）里随机的另一条，档位不变。
- 洗练符、剥离符：见上表。

**只能掉落的两档（溢彩）**
- 每个词条族最高的两档，铁砧做不出来。
- 普通掉落的词条档位上限 = 档数 − 3。
- 溢彩装备只从天梯宝箱出：N ≥ 30 时，每件宝箱装备有 (N − 30)% 的几率是溢彩，带 1 条顶两档的词条，最多 40%。溢彩装备的名字用另一种颜色。

**天梯宝箱（第二期）**：2 件装备（同第一期）；词条碎片 4 + floor(N / 5) 个；每种铸符各有 10% + N × 0.5% 的几率掉 1 张。段位首次达到奖励每种铸符各 2 张。

**传奇熔铸**（天梯铂金 40 层解锁）
- 独特装备掉落时带传奇潜力 0–2（天梯宝箱里的独特装备是 1–3）。
- 熔铸 = 一件独特装备 + 一件同部位的稀有装备。独特装备保留规则和固定词条，再从稀有装备上随机转移“传奇潜力”条词条（档位不变）。稀有装备被消耗。
- 熔铸出来的装备叫“传奇”，颜色和独特装备区分开。

**符文喂养**（天梯白银 20 层解锁）：把一枚符文喂给另一枚，被喂的符文获得前者累计经验的 80%（runes.feedMul）。

**解锁表**：按方案文档“解锁顺序”一节更新 progression.unlocks。
- 铁砧（加词条、升一档、拆解）：第 5 层
- 洗数值和移除：第 15 层
- 天梯：第 10 层
- 符文喂养：天梯 20 层
- 熔铸：天梯 40 层

**模拟**：tools/sim.js 加 `--craft auto`，策略是贪心：
- 不如身上的装备就拆掉；
- 有碎片时，给身上每件装备做“秒伤 × 有效生命”提升最大的那个加词条或升档动作；
- 打天梯同第一期。
