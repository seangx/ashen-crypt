# 灰烬地窖 · 技能石方案（技能和武器解绑）

2026-10-25 · 设计线程 · 状态：方案稿，未开工

用户 11:44：“感觉武器绑定技能有点不太好”。11:48 在三种方式里选了 **A 技能石（流放之路式）**。

## 现在的问题
- **流派被掉落卡住。** 想玩旋风斩得先掉回旋骨刃，想玩游雷得先掉雷灵；底子不对，词条再好也用不上。
- **刷装备和刷流派混在一起。** 一把好武器的价值取决于它是哪种形态，而不是它的数值。
- **底子太多、太散。** 28 种武器底子，大多只是同一种打法换个元素。

## 方案总览
1. **技能来自技能石。** 角色有一个技能栏：左手、右手各一格。盾有一格，只能放带“盾”标签的技能。技能石放在技能栏里，不插在武器上。换武器时技能不动。
2. **辅助符文插在技能石上。** 每颗技能石自带 1–5 个辅助槽，掉落时随机。现有的穿刺、连锁、扩散、连击等符文都变成辅助符文。换武器时，技能和符文都跟着走。
3. **武器只给数值和倾向。** 武器提供基础伤害、攻速、暴击和词条，再加一个类别倾向：武器类别和技能标签对口时，伤害 ×1.2。不对口也能用，只是没有这份加成。
4. **流派的核心符文并进技能石。** 旋身、游雷、陨火、寒魄、霜环、圣盾掷这几个“形态符文”不再单独存在，它们就是对应的技能石本身。符文等级变成技能石等级。

## 技能怎么算伤害

```
单次伤害 = 武器基础伤害 × 技能倍率 × (1 + 各种提高) × 各种总增 × 类别对口 1.2
出手频率 = 武器攻速 × 技能速度系数
元素 = 技能石的元素（武器上的平加元素伤害照常加上去）
```

- **技能倍率**和**速度系数**写在技能石上。随技能石等级成长，取代现在形态符文的 meteorMul、sparkMul、novaMul 等。
- **类别倾向**：

| 武器类别 | 对口标签 |
|---|---|
| 近战 | 近战 |
| 弩 | 投射物 |
| 法器 | 范围、新星、延迟、持续 |
| 铳 | 投射物、散射 |
| 盾 | 盾 |

- 双持两把武器，就是两个技能各用各的武器。盾技能用盾的护甲算伤害（同现在的圣盾掷）。

## 武器归类：28 种底子 → 5 类

每类保留 2–4 种底子，差别在数值（快慢、暴击）和隐性倾向，不再管形态。

| 类别 | 保留的底子（举例） | 去掉 / 并入 |
|---|---|---|
| 近战 | 回旋骨刃（快）、撞城骨锤（慢、重）、骨刺（暴击） | 荆棘甲 → 改成辅助符文“荆棘” |
| 弩 | 骨弩（均衡）、穿心弩（快弹、穿透倾向） | 雷符、圣焰铳、飞镰的形态并进技能石 |
| 法器 | 坠星杖（慢、高伤）、圣钟（均衡）、寒魄宝珠（快）、圣光杖 | 霜钟并入圣钟（元素交给技能石） |
| 铳 | 散骨铳（散射）、疫孢囊 | 疫星仪、回旋火轮的形态并进技能石 |
| 盾 | 现有的盾、圣徽盾 | — |

陷阱底子（五种）全部变成技能石，武器那边不再有陷阱。

- 技能倍率按“旧武器平均伤害 ÷ 所在类别平均伤害”换算，保证解绑当天强度不变，之后再用模拟调。

## 技能石本身是刷宝目标

| 属性 | 怎么来 | 作用 |
|---|---|---|
| 等级 1–20 | 打怪获得经验；可以喂同类技能石或符文（沿用符文喂养） | 技能倍率成长；8 / 16 级等节点开额外效果（沿用现在形态符文的分段） |
| 辅助槽 1–5 | 掉落时随机，权重沿用现在武器槽数的 `[1000, 800, 600, 300, 100]` | 能插几个辅助符文 |
| 品质 0–20% | 掉落随机；铁砧可以用碎片提升 | 技能倍率再 +品质% |

- **掉落**：技能石和符文同一个掉落池，权重 ×0.5。新流派的技能石有首次保底：推层 3 必掉一颗。
- **铸符“开孔”**（新）：给技能石 +1 辅助槽，上限 5。来自天梯宝箱。

**武器失去了槽，追求什么？** 武器仍然有词条、品质、溢彩、誓约、传奇融合。现在的“6 槽武器”这个追求，挪到技能石上。

## 对其他系统的影响
- **天赋树大天赋**：旋风之心、织雷之心、星坠雨、碎冰、碎冰连锁、回响圣盾，生效条件从“武器形态 / 底子”改成“技能石标签”。
- **独特装备**：绑定形态的武器独特（冬之心、李的风暴、锈骨弩、三棱穿心弩等约 17 件）改成“对某标签的技能生效”，底子换成所在类别的底子。比如冬之心变成法器，规则写【派生】。
- **AI**：近战或远程打法看技能石，不看武器。两个技能一近一远时，以左手技能为准。
- **模拟**：`--build whirl` 等于“旋风斩技能石 + 推荐辅助符文”，武器随便配。
- **营地**：铁砧加一个“技能石”页（提升品质、开孔、喂养）。

## 老存档迁移
1. 每把旧武器拆成两样东西：
   - 同类别的新底子武器，保留词条、品质、溢彩、誓约。
   - 一颗对应的技能石：辅助槽数 = 旧武器槽数；旧武器上的辅助符文搬进技能石。
2. 旧武器上插的形态符文（旋身、游雷等）并进技能石：符文等级就是技能石等级，不再占槽。
3. 装备中的两把武器生成的技能石，自动放进左右手技能栏。
4. 迁移一次性完成，存档版本号 +1。

## 渐进式披露（接上一轮讨论）

- 推层 3：保底掉第一颗新技能石，开右手技能格。
- 辅助槽在第一次掉辅助符文时才显示。
