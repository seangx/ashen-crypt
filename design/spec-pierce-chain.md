# 实现规格：穿透 / 弹射 / 反弹三分工，寿命不吃掉反弹（设计线程）

用户 2026-10-23：
- 14:25 “感觉穿透和弹射有点冲突”。
- 14:30 “投射物还有自己的 duration，往往我那么高的弹射次数还没完就消失了”。
- 14:34 “穿透我觉得可以先去掉穿几个敌人这种设计，能穿透就是无限穿透；敌人间反弹和墙壁反弹都存在；穿透和敌人间反弹互斥”。

## 三个属性
| 名字 | 数据 key | 是什么 |
|---|---|---|
| 穿透 | `pierce`（布尔：任何来源 > 0 就算有） | 无限穿透：打中敌人后不停，继续往前飞。同一颗对同一个敌人每 `proj.rehit` 0.5 秒最多打一次（游雷沿用自己的 rehit） |
| 弹射 | `chain`（次数） | 敌人之间转向：打中敌人后，转向 `proj.chainR` 90 像素内最近的、这一颗没打过的敌人，消耗 1 次。没有目标就按普通命中处理（消失） |
| 反弹 | `ricochet`（次数，新） | 撞墙反弹：碰到场边镜面反射，消耗 1 次（就是 854fd84 做的场边反弹，换个 key） |

- 打中敌人时：有穿透 → 穿过去；否则有弹射次数 → 转向下一个敌人；否则消失。
- 碰到场边时：有反弹次数 → 反射；否则飞出场外消失。
- **穿透和弹射互斥**：武器同时有穿透和弹射时，穿透生效，弹射不生效。不让点数白白浪费：每 1 点被压掉的弹射换成这把武器投射物伤害 +`proj.chainToDmg` 10%（提高，相加）。
  - 文案：符文 / 词条提示里写“和穿透互斥：有穿透时每点换成投射物伤害 +10%”。
  - 物品和符文界面在冲突时把弹射一行标灰，并显示换算后的数值。
- 闪电链类武器（现在走 chainHit 的，打中瞬间在敌人间连锁的那种）照旧用 `chain` 当连锁次数，不受穿透影响。

## 寿命
- 投射物还有弹射或反弹次数时，不计存在时间。两者都用完以后才开始倒数，倒数时长 = 原来的寿命（射程 / 弹速，游雷是 spark.life）× 持续时间提高。
- 安全上限：任何投射物最多存在 `proj.maxLife` 12 秒。游雷照旧有 maxAlive 160。
- 织雷之心和雷冠的 chainStep“每弹一次伤害 +15%”：弹射和反弹都算一次。
