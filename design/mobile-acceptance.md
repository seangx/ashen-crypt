# 手机版验收清单

## 打开方式
- 构建：`cd game && python3 tools/build.py`，产物是 `game/ashen-crypt-mobile.html`（桌面版：`game/ashen-crypt.html`）。
- 用手机浏览器打开，或在桌面 Chrome 的 DevTools 设备模式下以 390x844 / 360x780 打开。
- 想直接有装备、天赋、符文可看：在 手册 → 加载演示存档（有备份时可恢复）。

## 要测的内容
1. 底部导航：每个 tab 都能打开；中间凸起的是 战斗。
2. 营地：6 个设施按钮（地窖入口/墓图台/天梯石碑/分解祭坛/储物箱/手册）。
3. 战斗：浮动摇杆只控制移动。镜头跟随，宽 270；屏幕边缘有敌人方向箭头。
4. 设置 → 视野 跟随/全景：全景显示完整的 480 宽，上下留黑边。
5. 出发 → 战斗 → 放弃/死亡 → 结算页 → 返回营地。
6. 长按物品（约0.5秒）：弹出详情；长按铁砧里的词条：弹出词缀详情（数值、档位范围）。短按仍是选择。
7. 符文：拖进镶孔；点按的方式仍然可用。
8. 天赋树：双指缩放，单指拖动。
9. 其他弹窗：装备、改造、锻造（分页 < >）、天梯、分解、墓图（地图/石盘/恩赐）。
10. 字体要清楚；按钮要好点。

## 2026-10-25 试玩反馈改动（要复验）
- 点一下就出详情：装备、背包、符文、结算物品、铁砧词条、弹珠石盘节点都是点一下弹出详情，操作按钮在弹窗里（装备/拆解/铁砧、镶嵌/取下、选中这条、点亮/退还）。铁砧、熔铸、墓图里用来“选物品”的格子还是点一下就选中，因为详情已经显示在页面上。
- 天赋树：点节点弹出详情，点亮 / 退回 / 取下印记在弹窗里，不会误点；手指命中范围放大了。
- 提前返回：弹出确认窗（返回营地 / 取消）。拆解、熔铸、分解背包、丢弃墓图、重置石盘、载入或恢复存档都改成弹窗确认，不再是 3 秒内连点两次。
- 进出战斗都有像素方块过场：盖住画面 → 关掉营地界面、开打（世界暂停）→ 方块散开；回营地时同样处理。

## 第三轮：真实战斗区域 + 侧边收纳按钮
- 核心新增 AW/AT/AB/AVH（平台提供的战斗区域）；桌面取原值（VW/TOP_H/BOT_Y/VH），模拟逐字节一致。
- 手机端战斗区域 = 竖屏可见区域（270×490，顶栏下到导航栏上）：弹射、刷怪圈、离屏判定、弹体消失、自动驾驶活动框都按它算。
- 全景模式移除：区域已等于屏幕，跟随与全景完全相同；设置里的「视野」项删除。
- 底部按钮栏收进右侧 34px 像素齿轮按钮（灵魂球上方），点开面板：开始/继续/暂停、自动/手动、推层/锁层、菜单、提前返回（仍走确认弹窗）。点面板外关闭。摇杆区域保持空出。
