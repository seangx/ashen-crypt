## 1. 一句话
角色用主手**自动普攻**；身上带 1–4 个**触发器**，条件满足时自动施放里面的**技能石**；装备的孔里插**属性石**。
- **玩家做的决定**：带哪些触发器、往孔里插什么石头、装备往哪个乘区堆。
- **核心目标**：做装 + 爬天梯（10-22 定，不变）。

## 2. 核心循环（不变）
```
营地 ──下行──▶ 灯火下行：一层接一层，灯灭安全返回，阵亡保留一半战利品
  ▲              每层：怪海 → Boss → Boss 宝箱（装备、触发器、石头）→ 整备界面
  ├── 回营地：自动分解、铁砧、换装、换触发器、镶石头、点天赋
  └── 天梯（240 秒限时，层词缀）──▶ 宝箱：独特、溢彩、铸符、誓约、触发器
```

## 3. 角色由什么组成

```
主手 ───── 普攻（4 类：近战挥砍 / 弩单发 / 铳散弹 / 法器小爆），伤害和攻速的来源
副手 / 盾牌 / 头冠 / 遁靴 / 法阵 ── 词条 + 属性石孔
触发器栏 1–4 ── 每个触发器：条件 + 词条 + 1–5 孔（技能石 ≤ 2 颗，其余辅助石）
天赋树 ──── 通用标签与元素玩法，不按技能、不按元素分
```

| 东西 | 插在哪 | 数量 | 管什么 |
|---|---|---|---|
| **技能石** | 触发器的孔 | 19 种 | 技能形态 + 本源元素 |
| **辅助石**（原辅助符文） | 触发器的孔 | 约 35 种 | 改同一触发器里技能的形态（多投射、范围、弹射……） |
| **属性石** | 装备的孔 | 约 12 种 × 5 阶 | 纯数值：伤害、暴击、攻速、生命、抗性、附加元素…… |
| **触发器** | 触发器栏 | 10 种条件 + 10 个独特 | 什么时候放、放多快 |

- 三种石头的孔完全分开，不混用（spec-trigger-slots §9）。
- **副手的“技能”身份取消**：现在代码里副手的隐性“主手技能总增 70–110%”删除，副手成为普通的攻击装备（§7）。
- **技能格（S.equip.gem）删除**，由触发器取代（存档迁移见 spec-trigger-slots §12）。

## 4. 伤害模型（补 spec-trigger-slots 没写的部分）

### 4.1 两个伤害对象，一套乘区
```
普攻单次   = 主手基础伤害 ×           对口 1.2 × (1 + 提高) × 暴击期望 × 总增
技能单次   = 主手基础伤害 × 技能石倍率 × 对口 1.1 × (1 + 提高) × 暴击期望 × 总增 × 触发器加成
普攻频率   = 主手攻速 × (1 + 攻速提高)
技能频率   = 由触发器决定（条件发生率 × 触发率，受内置冷却封顶）
```
- **共用乘区**：提高、暴击、总增，对普攻和技能都生效。装备追求不会被拆成两套。
- **只属于普攻的**：攻速。
- **只属于技能的**：技能石倍率（等级、品质）、触发器词条（触发技能伤害、冷却、额外施放）。
- **对口**：武器类别和技能石标签对口时 ×1.1（普攻固定 ×1.2）。即 spec-trigger-slots §3 的“普攻 100%、技能 50%”，落成具体倍率。
- **技能不吃攻速**：攻速只通过“攻击时”触发器间接影响技能（普攻越快越容易触发），而内置冷却会封顶，所以不会双吃到失控。

### 4.2 面板（chase-clarity 的六乘区，改成两行输出）
- 顶部两行：**普攻秒伤**、**技能秒伤**（按每个触发器的期望频率算），合计是总秒伤。
- 下面列共用乘区：基础伤害、提高、暴击期望、总增，外加普攻专属的攻速、技能专属的平均技能倍率。每行显示“这一项 +10% 时总秒伤 +x%”，最大的那一项标“最缺”。
- 每个触发器的卡片上显示：**每秒期望触发次数**、占总输出的百分比，以及是否已经被冷却封顶。封顶了就标灰色“触发率已满”，告诉玩家这个触发器别再堆触发率。

### 4.3 总增只有四种来源（不变）
大天赋、独特（装备和触发器）、辅助石、副手顶级词条。其余一律是“提高”。

## 5. 触发器（采用 spec-trigger-slots 的设计）
条件、孔数、稀有度、阶、词条、10 个独特、防循环，全部按原文。这里只记采纳的决定和补充：

**四个待确认，按推荐采纳**（用户如有不同再改）
1. 每个触发器最多 2 颗技能石，两颗时各 −30%；独特“双子”3 颗、只 −15%。
2. 栏位：等级 15 开第 2 栏，等级 35 开第 3 栏；主手、法阵的稀有词条或独特给 +1，装备最多 +1，总上限 4。
3. 孔不分颜色。
4. 辅助石继续用经验升级（沿用符文经验）。

**补充**
- **触发器词条里的“某系伤害”删除**，改成“本触发器技能的本源异常效果 +15–60%”。这样元素加成不散在词条里（§6）。
- **持续类技能被触发时只放 2 秒**。下面几个流派技能要按“短时爆发”调整，否则叠不起来：

| 技能石 | 问题 | 被触发时的版本 |
|---|---|---|
| 旋风斩 | 旋势要好几秒叠满 | 被触发时直接带“触发器阶 × 2”层旋势，转 2 秒；放在“常驻”触发器里则是现在的持续版本（可以挂常驻，例外放开） |
| 游雷 | 靠数量成型 | 被触发一次放出 sparkN 颗；放在常驻触发器里时保持 N 颗在场（spec 原写法） |
| 喷火、圣光束 | 持续伤害 | 2 秒，伤害按持续秒数换算 |
| 霜环、寒魄球、陨火 | 原来按次耗灯火 | 被触发**不耗灯火**（spec §6.5 原写“保留消耗”，这里统一为不耗，否则灯火会被触发器偷偷烧光） |

- **常驻触发器**能插：瘟疫光环、游雷、旋风斩（新增）。

## 6. 元素（elements.md 并入触发器体系）

### 6.1 元素表：6 种，各一个身份
| 元素 | 异常 | 身份 |
|---|---|---|
| 物理 | 碎骨 | 清怪（溅射） |
| 火焰 | 灼烧 | 单体持续（打 Boss） |
| 闪电 | 感电 | 削抗增伤 |
| 寒霜 | 冰缓 → 冻结 | 控制 |
| 圣光 | 致盲 | 防御（削弱） |
| 瘟疫 | 疫病，死亡时传染 | 群体持续 |

- 火焰的余震拿掉，改成不分元素的辅助石“余震”。
- 取消“元素”分组（火、圣、电、冰）；“元素抗性”改成全抗。
- 文档和界面统一用这 6 个名字。spec-trigger-slots §7 的“动能 / 爆炸 / 核疫”分别对应物理 / 火焰 / 瘟疫。

### 6.2 元素放在哪里：普攻元素来自装备，技能元素来自技能石
- **技能石**：每颗固定一种本源元素（elements.md §3 的表）。辅助石里的 6 颗**转化石**（骨化 / 焚化 / 雷化 / 霜化 / 圣化 / 疫化）能把同一触发器里的技能整个换成别的元素。
- **普攻**：主手底子的元素 + 装备和属性石上的“附加 X 伤害”。**附加伤害最高的那种 = 主附加元素**，普攻每次命中挂上它的附加特效（Hero Siege 式）。六种特效的数值见 elements.md §4.2。
- **共鸣**（替代 spec §7 的“同系共鸣”）：触发器里本源元素 = 主附加元素的技能石，每颗伤害 +12%，全身最多算 3 颗。
  - 效果：装备选的元素会把你往同元素的技能石上引，构筑有了一条元素主线。
  - 混色也能玩：普攻挂火特效清怪，触发器放冰技能控场。

### 6.3 天赋树上的元素
只给通用的元素组合玩法（用户 10-26 定）：
- 大天赋：纯色、杂糅、异变、余波（elements.md §6）。
- 小节点：附加伤害提高、附加特效效果、本源异常效果。
- 元素专属的特效改造（焚地、连爆、冰棺……）放在独特装备上。

## 10. 掉落与经济（触发器部分按 spec §10）

- 石头掉落池：技能石、辅助石沿用现在的符文掉落表；属性石新增（1 阶为主，3 合 1 升阶）。

## 11. 存档迁移（合并为一次，S.sysV = 2）
1. 技能格里的技能石和它的辅助符文 → 一个普通“攻击时”触发器（spec §12）。
2. 副手隐性按新表重算；副手、头冠上已移除的形态词条换成同前后缀的新池词条。
3. 头冠、遁靴原来的符文孔 → 同数量的属性石孔；插着的符文退回背包变辅助石。
4. 法阵力场 → 对应属性石（§7.2），放进背包。
5. 元素词条：X 基础伤害提高 → 基础伤害提高；X 穿抗 → 穿抗；X 异常效果 → 异常效果；元素抗性 → 全抗（数值 ×0.5）。
6. 解锁：按进度补事件，等级 ≥ 15 / 35 直接开第 2 / 3 栏。
7. 弹一次说明面板，列出搬动了什么。
