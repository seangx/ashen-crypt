## 1. 一句话
角色按主手的攻速**自动出手**，每次出手都放一个技能：满足条件的【出手】魂龛覆盖这一下，否则放武器自带的底技能。身上带 1–4 个**魂龛**（设计和代码里叫“触发器”，trig），条件满足时自动施放里面的**技能石**；装备的孔里插**属性石**。

**显示名**（用户 10-27 07:34：“节拍”“触发器”都不好理解，触发器在游戏里是个实体）：
| 设计 / 代码用语 | 游戏里显示 | 说明 |
|---|---|---|
| 触发器 trig | **魂龛** | 一件骨制小龛，龛里有孔，插技能石和辅助石。备选名：咒匣、骨匣 |
| 触发器栏 | 魂龛位 | 角色身上能挂几个魂龛 |
| 节拍类触发器 | 【出手】魂龛 | 覆盖一次出手 |
| 事件类触发器 | 【响应】魂龛 | 在出手之外额外放 |
| 普攻 / 节拍 | 出手、底技能 | 攻速 = 每秒出手次数 |
| 触发系数 | 触发系数 | 武器属性，见 §4.1 |
- **玩家做的决定**：带哪些触发器、往孔里插什么石头、装备往哪个乘区堆。
- **核心目标**：做装 + 爬天梯（10-22 定，不变）。

## 2. 核心循环（不变）
```
营地 ──下行──▶ 灯火下行：一层接一层，灯灭安全返回，阵亡保留一半战利品
  ▲              每层：怪海 → Boss → Boss 宝箱（装备、触发器、石头）→ 整备界面
  ├── 回营地：自动分解、铁砧、换装、换触发器、镶石头、点天赋
  └── 天梯（灯灭即结束，层词缀，见 lamp-v2 §6）──▶ 宝箱：独特、溢彩、铸符、誓约、触发器
```

## 3. 角色由什么组成

```
主手 ───── 出手：攻速、触发系数、基础伤害，以及底技能（近战突刺 / 弩骨矢 / 铳散射 / 法器新星）
副手 / 盾牌 / 头冠 / 遁靴 / 法阵 ── 词条 + 属性石孔
触发器栏 1–4 ── 每个触发器：条件 + 词条 + 1–5 孔（技能石 ≤ 2 颗，其余辅助石）
天赋树 ──── 通用标签与元素玩法，不按技能、不按元素分
```

| 东西 | 插在哪 | 数量 | 管什么 |
|---|---|---|---|
| **技能石** | 触发器的孔 | 19 种 | 技能形态 + 本源元素 |
| **辅助石**（原辅助符文） | 触发器的孔 | 约 35 种 | 改同一触发器里技能的形态（多投射、范围、弹射……） |
| **属性石** | 装备的孔 | 约 12 种 × 5 阶 | 纯数值：伤害、暴击、攻速、生命、抗性、附加元素…… |
| **触发器** | 触发器栏 | 10 种条件 + 10 个独特 | 什么时候放、放多快 |

- 三种石头的孔完全分开，不混用（spec-trigger-slots §9）。
- **副手的“技能”身份取消**：现在代码里副手的隐性“主手技能总增 70–110%”删除，副手成为普通的攻击装备（§7）。
- **技能格（S.equip.gem）删除**，由触发器取代。

## 4. 伤害模型（补 spec-trigger-slots 没写的部分）

### 4.1 出手、充能和触发系数
用户 10-27 07:28–07:39：按触发做；武器提供基础攻速和触发系数；该触发的那一下覆盖普攻。触发是**充能**模式：“比如累计 100 分放火球术，命中时触发，单体技能命中和 AoE 命中加的分数肯定不一样，触发系数就是指这个”。

**出手**
- 出手速度 = 主手基础攻速 × (1 + 攻速提高)。每次出手**必定放一个技能**，没有空挥、没有单独的普攻伤害。
- 默认放主手的**底技能**（按武器类别：近战突刺 / 弩骨矢 / 铳散射 / 法器新星，倍率 0.7，不能插辅助石）。

**三种放法，按魂龛的底子定**（用户 07:41：“比如闪避时触发可能就每次都触发，可能需要看具体的触发器”）
- **充能型**：条件发生得很频繁（命中、暴击、击杀、受击）。每次发生加分，满了（默认 100）就放，溢出保留（最多再存 1 次）。
- **每次型**：条件本身就稀少（格挡、冲刺），或者本来就是每次都要放（出手时）。每次发生都放，只有一个最短间隔防止连发。
- **状态 / 时间型**：每 N 秒、低血、遇精英、明灯、常驻。按时间或状态放。

**充能和覆盖**
- 【出手】魂龛（出手时、命中时、暴击时、残灯时）：轮到它时，**这一次出手**放它的技能，覆盖底技能。
- 每次出手的优先级：① 充满的【出手】充能魂龛（命中时 / 暴击时 / 残灯时），按魂龛位从左到右，一次只放一个；② 出手时魂龛（每次型，等于你的主攻技能；多个时只认最左边的）；③ 底技能。
- 玩家可以拖动魂龛调整顺序。
- 【响应】魂龛（击杀、受击、格挡、冲刺、低血、每 N 秒、遇精英、明灯、常驻）：充满后**立刻**额外放，不占出手。
- 魂龛图标上有一圈充能环，满了发光。挂机时一眼能看出谁快满了。

**触发系数** = 一次命中给【命中时】魂龛加多少分
- **底技能**的触发系数来自主手：慢武器高、快武器低。例：重锤攻速 0.8 / 系数 30；长剑 1.2 / 20；连弩 1.8 / 13。乘起来每秒充能大致相同，武器只改变手感。
- **技能石**各有自己的触发系数，按“每命中一个敌人”算：
  - 单体（骨矢、雷符、圣光束、突刺）：约 25。
  - 少量目标（散射每发、飞镰、冲撞）：约 12。
  - 范围（新星、霜环、陨火、火油罐）：约 5。
  - 持续（旋风斩每跳、喷火、光环）：约 2。
  - 持续伤害的跳数（灼烧、疫病）不充能。
- **每次施放最多给 40 分**，这样范围技能打怪海时不会一下充满。
- 辅助石会改触发系数：多重投射每发 ×0.6，范围扩大不变。
- 主手词条“触发系数提高”只提高底技能的系数（gear-v2）。

**各底子的放法**（第一版，数据里可调，每个底子在数据里有 `mode: charge / each / timer / state`）
| 条件 | 每次加多少 | 容量 |
|---|---|---|
| 出手时【出手】 | **每次型**：每次出手都放（被充满的充能魂龛抢走的那一下除外） | — |
| 命中时【出手】 | 命中者的触发系数 | 100 |
| 暴击时【出手】 | 出手技能的每次暴击 30 | 100 |
| 残灯时【出手】 | 处于残灯时，命中充能 ×2（同命中时） | 100 |
| 击杀时 | 普通 10、精英 50、Boss 100 | 100 |
| 受击时 | 每损失 1% 生命 +3 | 100 |
| 格挡时 | **每次型**：每次格挡都放，最短间隔 1 s | — |
| 冲刺时 | **每次型**：每次冲刺都放，最短间隔跟冲刺冷却 | — |
| 每 N 秒 / 明灯时 | 时间型：每 N 秒（明灯时只在明灯时计时） | — |
| 低血时 / 遇精英时 / 常驻 | 状态型 | — |

**伤害**
```
技能单次 = 主手基础伤害 × 技能石倍率（底技能 0.7）× 对口 × (1 + 提高) × 暴击期望 × 总增 × 魂龛加成
```
- 对口：武器类别和技能石标签对口时 ×1.1，底技能固定 ×1.2。
- **攻速**只决定出手次数：出手越多，命中越多，充能越快；它不直接加快响应类技能。
- **充能来源**：只有出手放出的技能（含底技能）给命中、暴击充能；【响应】魂龛放出的技能只给击杀充能，且不给自己（防循环，spec §6）。

### 4.2 面板（两行输出 + 乘区“最缺”）
- 顶部两行：**出手秒伤**（底技能 + 【出手】魂龛）、**响应秒伤**（按每个【响应】魂龛的期望频率算），合计是总秒伤。
- 下面列共用乘区：基础伤害、提高、暴击期望、总增，外加出手速度、平均技能倍率。每行显示“这一项 +10% 时总秒伤 +x%”，最大的那一项标“最缺”。
- 每个魂龛的卡片上显示：**每秒期望触发次数**（【出手】魂龛另显示“占出手的百分比”）、占总输出的百分比，以及充能速度。【出手】魂龛如果比出手还快（每次出手都满），标灰色“充能溢出”，告诉玩家别再堆充能。

### 4.3 总增只有四种来源（不变）
大天赋、独特（装备和触发器）、辅助石、副手顶级词条。其余一律是“提高”。

## 5. 触发器（采用 spec-trigger-slots 的设计）
条件、孔数、稀有度、阶、词条、10 个独特、防循环，全部按原文。这里只记采纳的决定和补充：

**四个待确认，按推荐采纳**（用户如有不同再改）
1. 每个触发器最多 2 颗技能石，两颗时各 −30%；独特“双子”3 颗、只 −15%。
2. 栏位：等级 15 开第 2 栏，等级 35 开第 3 栏；主手、法阵的稀有词条或独特给 +1，装备最多 +1，总上限 4。
3. 孔不分颜色。
4. 辅助石继续用经验升级（沿用符文经验）。

**补充**
- **触发器词条里的“某系伤害”删除**，改成“本触发器技能的本源异常效果 +15–60%”。这样元素加成不散在词条里（§6）。
- **持续类技能被触发时只放 2 秒**。下面几个流派技能要按“短时爆发”调整，否则叠不起来：

| 技能石 | 问题 | 被触发时的版本 |
|---|---|---|
| 旋风斩 | 旋势要好几秒叠满 | 被触发时直接带“触发器阶 × 2”层旋势，转 2 秒；放在“常驻”触发器里则是现在的持续版本（可以挂常驻，例外放开） |
| 游雷 | 靠数量成型 | 被触发一次放出 sparkN 颗；放在常驻触发器里时保持 N 颗在场（spec 原写法） |
| 喷火、圣光束 | 持续伤害 | 2 秒，伤害按持续秒数换算 |
| 霜环、寒魄球、陨火 | 原来按次耗灯火 | 被触发**不耗灯火**，否则灯火会被触发器偷偷烧光 |

- **常驻触发器**能插：瘟疫光环、游雷、旋风斩（新增）。

## 6. 元素

### 6.1 元素表：6 种，各一个身份
| 元素 | 异常 | 身份 |
|---|---|---|
| 物理 | 碎骨 | 清怪（溅射） |
| 火焰 | 灼烧 | 单体持续（打 Boss） |
| 闪电 | 感电 | 削抗增伤 |
| 寒霜 | 冰缓 → 冻结 | 控制 |
| 圣光 | 致盲 | 防御（削弱） |
| 瘟疫 | 疫病，死亡时传染 | 群体持续 |

- 火焰只留灼烧。余震不再是火焰异常，改成不分元素的辅助石“余震”（命中有几率按比例重复命中）。
- 瘟疫新增“死亡时传染”：带疫病层死亡的敌人，把一半层数传给 60 像素内最近的 2 个敌人。
- 取消“元素”分组（火、圣、电、冰）；“元素抗性”改成全抗。
- 文档和界面统一用这 6 个名字。
- 带元素的词条只剩“附加 X 伤害”6 族和单抗 6 族 + 全抗（gear-v2 §2）。

**技能石的本源元素**（固定，决定伤害类型、本源异常基础几率、特效主色）

| 元素 | 技能石 |
|---|---|
| 物理 | 旋风斩、突刺、冲撞、骨矢、飞镰、散射、陷阱·射击 |
| 火焰 | 火油罐、喷火、陨火、陷阱·爆裂 |
| 闪电 | 雷符、游雷 |
| 寒霜 | 霜环、寒魄球 |
| 圣光 | 圣光束、新星、圣盾掷 |
| 瘟疫 | 疫星、瘟疫光环、陷阱·毒池 |

闪电、寒霜各只有 2 颗，用转化石弥补：任何技能都能转成任何元素。

### 6.2 元素放在哪里：技能元素来自技能石，附加特效来自装备
- **技能石**：每颗固定一种本源元素（§6.1 的表）。辅助石里的 6 颗**转化石**（骨化 / 焚化 / 雷化 / 霜化 / 圣化 / 疫化）能把同一触发器里的技能整个换成别的元素：伤害、本源异常、特效主色都换。
  - 例：旋风斩 + 焚化 = 火焰旋风，本源异常变成灼烧。
  - 现有的圣辉、雷纹、骨锻、骨钢符文并进对应的转化石，平加部分删掉（平加交给装备）。
  - 转化石占孔。纯净（只保留本源元素，总增 ×1.5–2.0）保留，和共鸣搭配是纯色路线的核心。
- **附加特效**：装备和属性石上的“附加 X 伤害”加到所有技能的基础伤害上。**附加伤害最高的那种 = 主附加元素**，**出手**放出的技能（含底技能）每次命中挂上它的附加特效（Hero Siege 式）；响应类技能不挂。六种特效的数值见 §6.4。平局时本源元素优先。
- **共鸣**（替代 spec §7 的“同系共鸣”）：触发器里本源元素 = 主附加元素的技能石，每颗伤害 +12%，全身最多算 3 颗。
  - 效果：装备选的元素会把你往同元素的技能石上引，构筑有了一条元素主线。
  - 混色也能玩：出手挂火特效清怪，响应魂龛放冰技能控场。

### 6.3 天赋树上的元素
只给通用的元素组合玩法，不给某一种元素（用户 10-26：“天赋环不该给这么限定的东西”）。
- 小节点：附加伤害提高、附加特效效果提高、本源异常几率 / 效果提高。
- 大天赋：

| 大天赋 | 效果 | 代价 |
|---|---|---|
| 纯色 | 共鸣每颗 +12% → +20%，最多算 4 颗 | 和本源元素不同的附加伤害只算一半 |
| 杂糅 | 附加伤害第二高的元素也挂特效（×0.6） | 不再有共鸣 |
| 异变 | 附加特效对目标同时触发本源异常（几率 = 本源异常几率） | 直接命中伤害 −20% |
| 余波 | 附加特效有 25% 几率再触发一次 | 附加伤害 −25% |

### 6.4 六种附加特效（只挂出手放出的技能，A = 该元素附加伤害的平均值）
| 主附加元素 | 附加特效 |
|---|---|
| 物理 | 碎骨溅射：命中点周围 40 像素造成 A × 0.6 物理伤害 |
| 火焰 | 点燃：灼烧池 + A × 0.5 |
| 闪电 | 雷爆：命中 0.5 秒后在目标处爆炸，50 像素内造成 A × 0.8 闪电伤害；同一目标每 0.5 秒最多一次 |
| 寒霜 | 霜咬：叠 1 层冰缓；冻结中的敌人额外受到 A × 1.5 寒霜伤害 |
| 圣光 | 圣印：致盲 2 秒；命中致盲敌人回复 A × 0.1 护盾（计入续航上限） |
| 瘟疫 | 疫种：叠 1 层疫病，每层每秒 A × 0.15，持续 4 秒 |

- 特效伤害吃提高和总增，**不吃暴击**：特效是稳定的底，暴击仍是副手和头冠的追求。
- 面板和装备说明显示“附加特效：火焰 · 点燃”；换装备会改变主附加元素时，对比卡写出来。
- 美术：6 套全技能共用的小效果（溅射骨片、火苗、电球、霜纹、光印、毒雾）。

### 6.5 元素独特（元素专属的改造只放在独特上）
| 独特 | 部位 | 规则 |
|---|---|---|
| 双生冠 | 头冠 | 附加伤害前两高的元素都挂特效（第二种 ×0.6） |
| 棱镜法阵 | 法阵 | 每次命中按顺序轮换 6 种附加特效，强度按附加伤害总和 ×0.4 |
| 纯色之心 | 副手 | 共鸣每颗 +12% → +25%，不限颗数；非主附加元素的附加伤害无效 |
| 余烬之握 | 主手 | 任何主附加元素都同时挂火焰特效 |
| 碎颅之锤 | 主手 | 骨裂：碎骨溅射命中的敌人有 30% 几率再溅射一次（×0.5） |
| 焚野法阵 | 法阵 | 焚地：点燃的敌人死亡时留下火圈，持续 3 秒 |

## 7. 装备
**见 gear-v2.md**（部位、招牌、约 60 族词条池、副手隐性、独特的随机词条、属性石）。要点：
- 伤害在手上，生存在身上，形态在石头上：技能形态类词条全部交给辅助石。
- 副手删除隐性总增 70–110%，改成暴击、附加伤害、触发技能伤害的攻击装备。
- 抗性拆成 6 单抗 + 全抗，所有防具类部位都能出；没有抗性上限。
- 独特 = 规则 + 固定词条 + 2–3 条随机词条。主线每 5 层的新纪录给一次骸骨轮盘（unique-reels.md）。

## 10. 掉落与经济（触发器部分按 spec §10）
- Boss 宝箱：装备 + 触发器（必掉 1 个）+ 石头。
- 石头掉落池：技能石、辅助石沿用现在的符文掉落表；属性石新增（1 阶为主，3 合 1 升阶）。
- 碎片来源不变；分解触发器给碎片，孔里的石头退回背包。
- 独特：随机掉落不变；另外主线最高层每推进 5 层，骸骨轮盘给一次三选一（unique-reels.md）。
- 目标：60 层一轮 6–10 个稀有触发器；开自动分解后背包 ≤ 25 格。
